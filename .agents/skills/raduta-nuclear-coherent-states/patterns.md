# Reasoning Patterns: Raduta 相干态与半经典相空间分析范式

提炼自 A. A. Raduta《Nuclear Structure with Coherent States》的 5 大相空间分离线分析、玻色展开、角动量投影与偶偶手征带推演范式。

---

## Pattern 1: 半经典相空间分离线临界能量计算与相轨道定域性分析范式

- **核心法则**：三轴刚性转子在相空间中的运动拓扑严格由总能量与三主轴转动惯量决定的分离线（Separatrix）控制。通过解析计算临界分离线能量，可无模型依赖地判定当前实验角动量与激发能处于稳定主轴进动（摆动模式）还是大振幅非平面环流（手征分岔）。
- **标准分析程序**：
  1. 确定三轴核芯三主轴有效转动惯量：按照长短轴几何排序为 $\mathcal{J}_m > \mathcal{J}_s > \mathcal{J}_l$（中间轴为最大惯量轴，短轴为中间惯量轴，长轴为最小惯量轴）；
  2. **计算分离线临界能量值 $E_n_{\text{crit}}(I)$**：
     对应角动量沿中间惯量轴（短形变轴 $s$ 轴）完全对齐的鞍点能量：
     $$E_n_{\text{crit}}(I) = \frac{I^2}{2 \mathcal{J}_s};$$
  3. **判定相轨道几何拓扑**：
     - **若系统总转动能量 $E(I) < E_n_{\text{crit}}(I)$**：
       相点局域在包围最大惯量轴（$m$ 轴）的椭圆闭合天平动轨道（Libration Orbit）内，运动表现为围绕主轴的小振幅稳态进动——**纯量子摆动运动 (Wobbling Motion)**；
     - **若系统总转动能量 $E(I) > E_n_{\text{crit}}(I)$**：
       相点冲破分离线马鞍点，进入包围长轴（$l$ 轴）的大振幅环流轨道（Circulation Orbit）；在奇奇核反冲力矩或高-$j$ 准粒子牵引下，系统失稳分岔进入三维非平面**静态手征取向相 (Chiral Phase)**。

## Pattern 2: Holstein-Primakoff 展开与高自旋摆动非简谐声子谱求解范式

- **核心法则**：在高自旋极限下，角动量矢量偏离主轴的偏角微小。采用 Holstein-Primakoff 玻色展开将非线性转动自旋哈密顿量映射为一维玻色子算符，可解析提取摆动零阶简谐频率与高阶非简谐四次恢复力。
- **标准求解程序**：
  1. 将主进动轴设为量子化轴（如 $z$ 轴），代入 Holstein-Primakoff 展开：
     $$\hat{I}_z = I - a^\dagger a, \quad \hat{I}_x \approx \sqrt{I} \frac{a + a^\dagger}{\sqrt{2}}, \quad \hat{I}_y \approx \sqrt{I} \frac{a - a^\dagger}{\sqrt{2} i};$$
  2. 代入三轴哈密顿量 $\hat{H} = \frac{\hat{I}_x^2}{2\mathcal{J}_x} + \frac{\hat{I}_y^2}{2\mathcal{J}_y} + \frac{\hat{I}_z^2}{2\mathcal{J}_z}$，保留至玻色子四阶项：
     $$\hat{H} = E_0(I) + \hbar\omega_w a^\dagger a + V_4 a^\dagger a^\dagger a a;$$
  3. **求解零阶简谐摆动频率 $\hbar\omega_w$**：
     $$\hbar\omega_w = I \sqrt{\left(\frac{1}{\mathcal{J}_x} - \frac{1}{\mathcal{J}_z}\right)\left(\frac{1}{\mathcal{J}_y} - \frac{1}{\mathcal{J}_z}\right)};$$
  4. **非简谐修正分析**：四阶非简谐系数 $V_4$ 决定了摆动能谱随多声子数 $n_w$ 增加时的非线性偏离：
     $$E(n_w) = E_0 + n_w \hbar\omega_w + V_4 n_w (n_w - 1).$$
     若 $V_4 < 0$，预示声子谱软化并向分离线不稳定边缘快速滑移。

## Pattern 3: 变形相干态三维角动量投影正规化积分反演范式

- **核心法则**：宏观变形平均场破坏了全空间的转动不变性，导致内禀相干态中混杂了所有不同自旋 $I$ 的成分。通过三维角动量投影算符，可将内禀四极相干态自洽解构为严格具有确定自旋、好宇称且彼此正交的正规化物理态。
- **标准反演程序**：
  1. 构建包含四极内禀形变参量 $d$ 与 $\gamma$ 的未正规化玻色相干态 $|\psi(d, \gamma)\rangle$；
  2. 计算投影重叠积分核（Overlap Kernel）：
     $$N_I^2(d, \gamma) = \frac{2I+1}{2} \int_0^\pi \sin\theta d\theta \, d_{00}^I(\theta) \langle \psi | e^{-i \theta \hat{J}_y} | \psi \rangle;$$
  3. 提取具有确定自旋 $I$ 的物理波函数：
     $$|I M, d, \gamma\rangle = \frac{1}{N_I(d, \gamma)} \hat{P}_{M0}^I |\psi(d, \gamma)\rangle;$$
  4. **电四极跃迁矩阵元严格求值**：在正交化投影基底上直接对五维四极电磁跃迁算符求矩阵元，完全根除经验模型必须人为引入可调唯象参数的严重理论弊端。

## Pattern 4: GCSM 偶偶核手征双重带带间 $B(M1)$ 跃迁与手征破缺裁决范式

- **核心法则**：偶偶核由于基态全部核子配对为 $J=0^+$，传统观点认为不可能具备手征性；Raduta 证明在第一带交叉后，两准粒子破对形成的费米子角动量与质子玻色子、中子玻色子三者可构成非共面三面体。其决定性实验判据是孪生两带之间存在极强的磁偶极 $M1$ 退激跃迁。
- **标准裁决程序**：
  1. 在偶偶核中辨识位于回弯（Backbending）自旋以上（$I \ge 10 - 12\hbar$）、能量近简并且具有相同正宇称的两条平行转动能带（Band 1 与 Band 2）；
  2. 测定带间退激跃迁（$\text{Band 2} \to \text{Band 1}$）的辐射能量与光子分支比；
  3. **计算带间 $B(M1; I \to I)$ 与 $B(M1; I \to I-1)$**：
     - 若实测带间跃迁表现为微弱阻碍（$B(M1) \ll 0.01\ \mu_N^2$），则两能带属于普通的形状共存或带交叉振动；
     - 若实测带间具有显著集体增强的磁偶极辐射（$B(M1) \sim 0.1 - 0.5\ \mu_N^2$），且 $B(M1)/B(E2)$ 展现特征的奇偶自旋交错振荡，**严格确认为偶偶核手征双重带**！

## Pattern 5: 梨形相干态与手征-八极宇称四重带交替宇称交错位移反演范式

- **核心法则**：在同时具备稳定四极长椭形变 $\beta_2$ 与八极梨形形变 $\beta_3$ 的重核（如镭、钍同位素与部分钡、钐同位素）中，原子核空间反演对称性自发破缺。正负宇称态在三维旋转下自发组织为交替宇称单重态或交错带。
- **标准反演程序**：
  1. 从在束谱学数据中提取相同内禀构型的正宇称能带（$I^\pi = 0^+, 2^+, 4^+, \dots$）与负宇称能带（$I^\pi = 1^-, 3^-, 5^-, \dots$）；
  2. 计算交错位移能量因子：
     $$\Delta E(I) = E(I^-) - \frac{1}{2} [ E((I+1)^+) + E((I-1)^+) ];$$
  3. **判定准则**：
     - 若随自旋上升，交错位移 $\Delta E(I) \to 0$ 且能量严格按 $0^+, 1^-, 2^+, 3^-, 4^+, 5^-, \dots$ 等间距交替排列，证明基态具有深八极极小势阱；
     - **若该系统同时伴随奇奇核手征双带结构**，则在能谱中形成四条相互平行的**手征-八极宇称四重带**，带间伴随巨大的 $E1$ 跃迁（$B(E1) \sim 10^{-2}\text{ W.u.}$），为原子核电偶极矩（EDM）实验提供核心结构依据。
