# translation-books — 书籍翻译与排版

## 目标与默认值

交付忠实于底本、读起来顺畅、可在电脑直接阅读并用 A4 打印的完整译本。
用户本轮要求和已有约定优先。没有版式要求时采用
[A4 阅读模板](references/layout-and-pdf.md)；没有目标语言要求时译为简体中文。
用户只是询问或要求规划时保持相应范围，不自行开始全书翻译。

默认只交付最终 PDF。内部保留可重建源码、素材来源、术语决策和检查点，
存放位置遵循当前项目规则，不将过程报告塞入交付目录。
不预填译者、邮箱或机构，不自动增加致谢；不把某次任务的署名推广成默认。

## 执行前置

1. 遵循当前项目指令，检查已有文件和修改；保护原件、历史译本及他人的工作。
2. 确定源书、版次、目标范围、目标文件名和输出目录。优先使用用户路径；
   未指定时使用项目规定的译本目录，无规定时使用源书旁的 `translations/`。
3. 调用前检查真实可用工具和语言审校技能，不假定当前项目继承了上一环境。
   可执行 `python3 scripts/preflight.py --source /path/to/book.pdf`，
   脚本路径相对于本技能目录。技能列表来自运行器时，也核实其中的实际资源。
4. 优先调用 `shuorenhua`（可能显示为 `shuorenhua:shuorenhua`）。先定位并读取
   它的 `SKILL.md`，再按其边界审校。缺失时明确告知，提示安装“说人话”或
   询问改用哪一个已安装的语言审校技能；不静默替换、不自动联网安装。
   可继续不依赖它的提取、翻译初稿、制图、转录与排版，待选择解决后完成该项审校。
   用户明确选择不用外部技能时可自行审校，并如实记录方式。
5. 其它学科读通用指南；核物理书籍再读
   [核物理专项](references/nuclear-physics.md)。专项不覆盖用户的术语偏好。

## 核心原则

- 翻译对象是原书的完整论述与组件关系；摘要、读书笔记和自行补写都不能代替译文。
- 正文、行内公式、行间公式、表格、图片、图表注、脚注和引用分别核查，再组装。
  PDF 能编译并不能证明没有漏掉组件。
- 术语以语境和学科惯例为依据。允许保留英文，不按单个词做全书机械替换；
  `scheme` 只是多义词的一个例子。详见[语言与术语](references/editorial.md)。
- 原文歧义和排印疑点回到原页核实，区分转录错误、原书错误及译者判断。
  不悄悄改写科学命题，不虚构缺失公式、数据、图注或文献。
- 工作按节保存检查点。长任务从已核验状态继续，已完成的转录、翻译及裁图不重做。
- 版式检查、逐图核对、公式表格核对和语言审校各有凭据；
  不把接触表快审称作逐字校译，不把自审称为人工审定。

## 工作流程

### 1. 核实底本并建清单

核查标题页、版次、出版信息、物理页和印刷页对应、扫描或可提取文字情况、
目录、前后置内容、章节边界。保存输入路径、大小和 SHA-256。
以节为单元记录原页范围、文本状态、公式/图/表/脚注清单、引用与复核状态。
用简单 JSON 或表格即可；用户要求全书时包含前言、致谢、注释、目录、正文、
附录、参考文献和索引，具体顺序以原书为准。

普通新书先在内部试排有代表性的正文、长公式、表格和复杂图片，检查工具链
及版式后继续全书。用户要求样章验收时才在样章边界等待。
不重新询问会话中已经决定的要求。

### 2. 按节识别、转录并翻译

先从原书提取文字及空间坐标；扫描页使用可用 OCR。提取结果仅作为辅助，
含公式和表格的页面需查看原页。直接整理为 LaTeX，不为同一内容再维护
Markdown 和 LaTeX 两套正式稿。

- 清理扫描页眉页脚、重复页码、断词、乱码及误入正文的目录标签。
  原书的有意留白提示按分页需要处理，不译成下一部分的正文。
- 先恢复段落与句子，再安放浮动体，防止一句话被图表切成两个段落。
- 行内和行间数学均原生转录，检查符号、上下标、字体、矩阵、对齐与编号；
  正文中的物理变量同样进入数学模式。
- 表格原生重建，逐格对照数值、单位、表头、合并关系和脚注，兼顾留白与分隔线。
- 正文和图表注忠实翻译，保留原文条件、归属与论证顺序；不将内部分析写成图注。

每节完成后更新清单，将发现的术语决定应用到相关上下文。
完整细则见 [editorial.md](references/editorial.md)。

### 3. 从原件提取并逐图核对

原 PDF 内的矢量图适合时保留矢量；扫描图直接从原页高分辨率提取或渲染，
按最终显示大小检查有效分辨率，约 450 dpi 可作为扫描图起点。
不靠放大旧低清裁图假装恢复细节。

每张图记录来源版次、物理页、原图号、裁框坐标及坐标单位、输出资产和图注。
对照原页确认多面板、坐标、图例和上下边界完整；允许外边留白，排除邻近正文。
短英文图例、坐标轴和模型名称可保留；完整句子和图注译成中文。
图号、图注与图像一一对应，不留下孤立“图 6.14.”之类标记。
占位符只能用于确有缺件的内部工作稿，未解决时不能称为完整成品。

### 4. 组装、编号与交叉引用

使用稳定的语义 ID 和 `\label`、`\ref`、`\eqref`、文献键；标签放在实际
章节命令、图表注之后或对应公式内。标题文本不再手写自动生成的章节号。
目录、正文和 PDF 书签共用标题来源。长页眉用短标题处理。

追踪引用到实际对象，不只检查目标存在。图、表、公式、章节、页码、文献及索引
都要核对；清查正文中手写号码和 `\textup{(6.17)}` 等包装后的字面引用。
原书页码引用要映射或明确注明“原书”，不能当成译本页码。
解析 `.aux` 标签时支持平衡花括号，避免漏掉 AMS 嵌套编号。

多版整合时按“版次 + 原对象 ID”区分来源，建立新增/修订/重复/移位/删除或取代
对应表，再统一编号。按用户指定的底本和版本优先级处理差异；未指定时先比较，
将结构底本、修订优先级和旧版独有内容的去留作为具体取舍说明。旧版被删除的内容
不自动恢复入正文，也不因未见直接矛盾便默认舍弃。取舍影响完整性且会话没有授权时，
询问具体未决项，同时继续清点、比对和独立工作。
用户只要求比较或先讨论时止于比较阶段；已明确整合政策时直接继续，不增加验收关口。
整合不等于 PDF 拼接，也不能将选择性增订称为完整新版翻译。

### 5. 审校、编译和实际成品检查

按节执行忠实性审校及已预检的语言审校，核查每项改写与原文含义一致。
使用 [layout-and-pdf.md](references/layout-and-pdf.md) 的模板和验收表。
编译至目录与引用稳定，解决错误、缺字、溢出、重号、缺图及未定义引用。

可运行：

```bash
python3 scripts/audit_pdf.py /path/to/final.pdf --log /path/to/build.log \
  --contact-dir /path/to/internal-review
```

该脚本检查可机械检查的项目并生成全页接触表，**不会证明翻译完整、图片正确、
公式正确或已完成视觉审阅**。逐图对照原件；检查全部表格和公式；
目视查看每张接触表，并对正文、页眉、复杂公式、密集表格、裁图和异常页放大审查。
修正后重新编译，并复查受影响页与后续浮动体、目录、编号。
最后再核对组件清单与成品中的实际数量、号码和引用目标。

### 6. 交付并保留续作基础

确认最终文件在用户要求目录，文件可打开、字体嵌入、元数据正确，
页数及 SHA-256 与验收对象一致。默认交付一个 PDF，简要说明路径和实际复核范围。
保留内部源码、素材来源、构建方式、术语表、检查清单和状态；
不要将唯一可重建内容只放在随时会清理的临时目录，按项目的持久化规则安置。
没有授权时不删除旧版、不覆盖原件、不公开原文材料、不向外发送文件。

## 与其他技能配合

语言审校按上述依赖预检查执行；学科知识、OCR、文献管理等技能仅在任务需要且
当前环境确实具备时调用。其它项目不需要存在 Wiki、核物理知识库或固定工具路径。
并行任务按章节或组件划分独立写入范围，共享术语及编号由一个整合者维护。

## 错误处理

| 情况 | 处理 |
| --- | --- |
| 语言审校技能缺失 | 说明缺失项，提示安装或征询替代；继续独立工作，保留未完成审校状态 |
| 工具链或字体缺失 | 报告实测缺项，选择现有可用同类工具；安装遵循当前环境授权 |
| 原件缺页或图表无法辨认 | 定位具体页与组件，记录缺口，不生成猜测内容冒充原文 |
| 只有少量版面变化 | 在现有源码定向修复，复查联动页，不重新 OCR 全书 |
| 输出检查失败 | 保留上一可用成果，在工作副本修正，验证通过后交付明确命名的新版本 |
