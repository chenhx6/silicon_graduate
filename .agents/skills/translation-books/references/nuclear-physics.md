# 核物理专项

本专项用于核物理教材、专著；其它学科跳过。它提供审校重点，
不能把某一本书中的模型条件推广为整个领域的事实。

## 术语偏好

| 原词 | 建议 | 注意 |
| --- | --- | --- |
| seniority | seniority | 不强译为“资深数”；保留原文符号 |
| Nilsson | Nilsson | 模型、轨道、图等接中文名词即可 |
| m-scheme | `$m$ 方案` | 不写 m 表象；不自动加首次出现的解释括号 |
| level scheme | 能级图 | 按语境区分能级体系等其它义项 |
| coupling scheme | 耦合方式、耦合方案 | 看原文是否特指角动量耦合顺序 |
| rotational/vibrational band | 转动带／振动带 | 不与能带、电磁波段混用 |

这些是默认偏好，用户指定的项目词表优先。
局部 Wiki、中文教材或已有核物理技能可辅助核实通行表达；
共享安装应在没有这些资源时仍能按源书开展工作。
查不到可靠译法就保留英文，不编造中文标准名。

## 数学与科学含义

- 区分总角动量及投影 `I,J,j,K,M,m`；保留原书约定，不随意统一大小写。
- 同位素质量数、质子数、中子数、自旋宇称、能级序号和轨道标签正确进入数学模式；
  `1/2^-`、`2_1^+`、`h_{11/2}` 等要核查上下标与前后对象。
- `B(E2)`、`B(M1)`、矩阵元、约化矩阵元、混合比和相位约定不能互换；
  检查 Wigner 符号、Clebsch-Gordan 系数、归一化和求和范围。
- 不合并静态与跃迁四极矩、运动学与动力学转动惯量、
  轴不对称与 gamma 软、实验指认与模型解释。
- 保留原作者对模型、适用核区、近似及争议的界定；语言审校不负责替作者裁决理论。

人名术语是否保留英文按项目词表判断，不要求把所有已有规范中文物理术语回退为英文。
审查要覆盖全文语义，不只搜索上表中的词。
