# A4 阅读版与 PDF 验收

## 默认排版

| 项目 | 默认 |
| --- | --- |
| 页面 | A4 纵向、单栏、无装订线；左右 30 mm，上下 25 mm |
| 正文 | 宋体 11 pt；西文 Times New Roman 或同类衬线体；基线 18 pt |
| 段落 | 两端对齐、中文标点挤压、标准中文字符间距、西文默认字偶距；缩进 2 字符、段后 6 pt |
| 标题 | 黑体；章 18/22.5 pt、节 14/17.5 pt、小节 12/15 pt；章从奇数页开始，节接排 |
| 数学 | 原生矢量；行内随文，行间自动容纳高公式、上下约 9 pt；编号靠右 |
| 图表 | 就近安放，图注下、表注上，9 pt 居中；列距与横线清晰，宽度不超正文 |
| 页眉 | 奇数页外侧章短题，偶数页外侧节短题；每页一项，9 pt 灰色，下线 0.25 pt |
| 页脚 | 外侧页码；章首页无页眉；真正的空白偶数页无页眉页脚 |
| 导航 | 可点击目录与章/节/小节三级书签；嵌入字体、正确标题元数据 |

左右边距 30 mm 的 A4 正文宽为 150 mm。
18 pt 是正文基线，不是对每个盒子强行裁切的高度。
表格可用 8.5–9.5 pt、清楚分组及重复表头；复杂表优先横排或拆分。
缺少宋体或 Times 时用可嵌入的同类字体，如 FandolSong 和 TeX Gyre Termes，
并记录实际字体；不通过缩小字号来掩盖溢出。

`assets/book.tex` 与 `assets/preamble.tex` 是可编译的版式起点，
使用 XeLaTeX 或 Tectonic；不绑定某一本书或某个绝对路径。
复制到工作区后改书名与内容，至少编译至目录和引用稳定：

```bash
xelatex -interaction=nonstopmode -halt-on-error book.tex
xelatex -interaction=nonstopmode -halt-on-error book.tex
```

若引用仍变化，继续到稳定；使用 Tectonic 时保留日志供检查。
原书前置部分的顺序按源书安排，模板不替所有书规定前言和致谢顺序。
中文标题与原书标题可按用户选择组织，不自动复制某次任务的英文书名页及白页。

## 机器检查的边界

`scripts/audit_pdf.py` 依赖 PyMuPDF；字体检查需要 `pdffonts`。
它检查 A4（含用于宽表的横向页面）、非空标题元数据、目录存在及层级上限、内部跳转范围、
缺字替换符和可疑控制字符，提供图像有效 DPI 线索和日志错误线索。
没有某一级标题的短书不必伪造三级层级；有三级标题时应核对相应书签覆盖。
横向页单独提示核查用途，正文仍以纵向为默认。
外部链接不自动联网，外部文件跳转及无法解析的命名目标要求另查。
脚本不检查段落语义、图表来源或全部 LaTeX 对象引用覆盖。

字体嵌入检查可能遇到只有 Type 3 图形字体的情况，需要按实际 PDF 分析；
不能把“能显示”当作“能复制”。数学字体可正确显示却有错误的 ToUnicode 映射，
造成复制时出现控制字符。修复应依据嵌入字体的真实编码，保留字形、矢量、
超链接、书签、元数据与版面；不要把整书栅格化来掩盖问题。

如果必须嵌入导入页的字体或修复 Unicode，先保存工作副本，
处理前后比较渲染、字体、目录和链接。不能默认所有书都需要这类后处理。

## 最终验收

1. 清单对账：章节、正文段落、公式、表格、图注、脚注、文献、索引在任务范围内齐全；
   图号、公式号、表号与编译结果一致，引用语义正确。
2. 构建稳定：无错误、缺字、溢出、重号、缺件、未定义引用或可见工作占位。
3. 全页视觉快审：实际打开每张接触表，检查空白、密度、图表位置和分页。
   接触表输出不等于已审阅。
4. 放大检查：逐图对原页检查裁框与对应；逐表逐式核查内容；
   对正文、前置内容、目录、章节开头、页眉页脚、复杂数学和长表放大查看。
5. 最终文件检查：字体嵌入、元数据、书签、目录链接、内部引用、页面尺寸、
   文件哈希均针对交付字节；源码和原件状态可追踪。

缩略图快审不能验证小字符或公式，随机抽样也不能宣称完成全书逐图对照。
