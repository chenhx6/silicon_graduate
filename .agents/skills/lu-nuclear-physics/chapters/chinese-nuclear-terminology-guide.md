# 中文核物理学术表达与专业术语规范指南

本指南基于卢希庭《原子核物理（修订版）》及全国科学技术名词审定委员会规范，为撰写中文学术论文、学位论文、开题报告及学术汇报提供权威术语翻译与表述对照。

---

## 1. 核心理论与模型术语规范

| 英文原名 | 规范中文推荐译名 | 台湾及历史习惯用法 | 严禁使用的不规范混淆译法 |
|---|---|---|---|
| Binding energy | **结合能** | 束缚能 | 绑定能 (非物理机翻) |
| Separation energy | **分离能** | 解离能 | 脱离能 |
| Semi-empirical mass formula | **半经验质量公式** | 半经验质量公式 | 半经验质量方程 |
| Liquid drop model | **液滴模型** | 水滴模型 | 流体滴模型 |
| Magic number | **幻数 / 魔数** | 幻数 | 奇异数 (奇异数专属夸克 Strangeness) |
| Intruder orbital | **侵入轨道 / 贯穿轨道** | 入侵轨道 | 插足轨道 |
| Superallowed transition | **超允许跃迁** | 超许可跃迁 | 超级允许跃迁 |
| Internal conversion coefficient | **内转换系数** | 内部转换系数 | 内换算系数 |
| Decoupled band | **解耦带** | 去耦带 | 脱耦带 |
| Signature partner band | **旋称伙伴带** | 签名伙伴带 | 宇称伙伴带 (混淆 Signature 与 Parity) |
| Alignment | **顺排 / 准直对齐** | 對準 | 排列 |
| Backbending | **回弯现象** | 倒彎 | 后弯 |
| Wobbling motion | **摆动运动** | 晃动运动 | 摇晃运动 |
| Chiral doublet bands | **手征双重带** | 宇称双重带 (严重错误) | 手性双带 (化学偏好，核物理规范用“手征”) |
| Tilted axis cranking | **倾斜轴推转 (TAC)** | 倾斜轴摇动 | 斜轴推转 |

## 2. 实验谱学与探测器技术术语规范

| 英文原名 | 规范中文推荐译名 | 说明与使用语境 |
|---|---|---|
| Photopeak efficiency | **全能峰效率** | 严禁翻译为“光电峰效率”（因全能吸收包含光电效应与多次散射完全吸收总和） |
| Peak-to-total ratio ($P/T$) | **峰总比** | 衡量康普顿抑制屏蔽套性能的核心指标 |
| Ballistic deficit | **弹道亏损** | 成形时间小于电荷收集时间引起的输出幅度亏损 |
| Pole-zero cancellation (PZC) | **极零相消** | 消除前放指数长尾基线过冲的电路网络 |
| Baseline restorer (BLR) | **基线恢复器** | 抑制低频基线波动与热噪声 |
| Leading edge timing | **前沿定时** | 具有显著幅度走动（Walk）的最简单定时方式 |
| Constant fraction discriminator (CFD) | **恒比定时器 / 恒比甄别器** | 通过衰减和延迟脉冲过零点彻底消除幅度走动 |
| Recoil distance method (RDM) | **反冲距离法 / 活塞法 (Plunger)** | 测量 $1\text{ ps} - 1\text{ ns}$ 寿命的标准方法 |
| Doppler shift attenuation method (DSAM) | **多普勒频移衰减法** | 测量 $10\text{ fs} - 2\text{ ps}$ 寿命的标准方法 |
| Differential decay curve method (DDCM) | **差分衰变曲线法** | 消除侧线 feeding 影响的 RDM 高阶解析算法 |
| In-beam spectroscopy | **在束 $\gamma$ 谱学** | 区分于离线放射性衰变谱学（Off-beam/Decay spectroscopy） |

## 3. 中文学术写作句式规范

1. **避免 AI 式欧化长句与倒装语态**：
   - *不规范*：“被测量到的多极混合比展现出了强烈的与理论的不一致性，这提示了模型可能是不完善的。”
   - *规范写法*：“实测多极混合比与理论预言显著失配，表明既有刚体模型未计入非轴对称动力学自由度。”
2. **严格区分“手性”与“手征性”**：
   - 分子化学通常称为“手性（Chirality）”；
   - 在高能物理、场论与原子核自旋拓扑中，全国科技名词审定委员会统一定名为**“手征性（Chirality）”**、“手征对称性破缺”与“手征双重带”。
3. **区分“旋称（Signature）”与“宇称（Parity）”**：
   - 旋称是绕垂直轴旋转 $180^\circ$ 的空间转动对称性（$r = (-1)^I$）；
   - 宇称是关于原点的空间反演对称性（$\pi = (-1)^l$）；
   - 严禁将 Signature partner band 译为“宇称伙伴带”。
