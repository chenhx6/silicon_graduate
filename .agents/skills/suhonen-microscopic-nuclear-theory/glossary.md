# Jouni Suhonen 微观核结构与张量代数专业术语表

### 核心物理术语与规范中英文定义

| 中文术语 | 英文术语 | 符号/公式 | 规范定义与物理内涵 |
|---|---|---|---|
| 不可约球张量算符 | Irreducible Spherical Tensor Operator | $T_q^{(k)}$ | 在 3 维转动下按 $SO(3)$ 的不可约表示变换的算符集合，满足标准角动量对易子关系。 |
| 约化矩阵元 | Reduced Matrix Element | $\langle j_f \|\| T^{(k)} \|\| j_i \rangle$ | 剥离了空间取向（几何磁量子数）后的内禀跃迁振幅，完全包容了微观径向与轨道动力学。 |
| 表面 Delta 相互作用 | Surface Delta Interaction (SDI) | $V_{\text{SDI}}$ | 局域于核表面的接触零程相互作用，解析给出反对称化两体耦合矩阵元。 |
| 准粒子 | Quasiparticle | $a_{jm}^\dagger, a_{jm}$ | 通过 Bogoliubov-Valatin 线性正则变换混合粒子与空穴自由度的微观元激发。 |
| 能隙参数 | Pairing Gap Parameter | $\Delta$ | 配对凝聚能量标度，等于破坏一个库珀对所需克服的凝聚束缚能的二分之一。 |
| 占据振幅 | Occupation Amplitude | $v_j, u_j$ | $v_j^2$ 表示单粒子能级 $j$ 被配对核子占据的概率，$u_j^2 = 1 - v_j^2$ 为非占概率。 |
| 准粒子无规相位近似 | Quasiparticle RPA (QRPA) | QRPA | 在两准粒子激发构型空间包含前向 $X$ 与后向基态关联 $Y$ 的谐振集体激发模型。 |
| 质中无规相位近似 | Proton-Neutron QRPA (pnQRPA) | pnQRPA | 作用于质子准粒子与中子准粒子对之间、描述核荷电交换激发（$\beta^\pm$ 衰变）的模型。 |
| Ikeda 求和规则 | Ikeda Sum Rule | $S_- - S_+ = 3(N-Z)$ | 无论相互作用形式如何，由质中自旋同位旋算符对易子微观导出的严格守恒恒等式。 |
| 粒子-粒子相互作用常数 | Particle-Particle Strength | $g_{\text{pp}}$ | pnQRPA 中重整化粒子-粒子声子重叠强度的无量纲参数，敏感控制双 $\beta$ 衰变矩阵元。 |
| 维斯科普夫单粒子单位 | Weisskopf Unit | W.u. | 假定跃迁由单核子在均质球核边界内跃迁产生的标准单粒子电磁多极折合跃迁率。 |
| 有效电荷 | Effective Charge | $e_{\text{eff}}$ | 为补偿壳模型紧凑构型空间截断，由核芯极化（Core Polarization）诱导的经验增强电荷。 |
