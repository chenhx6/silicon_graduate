# Suhonen Ch 13–14: BCS 配对平均场、Bogoliubov 变换与准粒子谱

### 核心物理定位
解决开壳层偶偶核与奇质量核超流配对凝聚与准粒子单体演化。

### 关键解析公式
1. **BCS 基态波函数**：
   $$|\text{BCS}\rangle = \prod_{j, m>0} [u_j + (-1)^{j-m} v_j c_{j m}^\dagger c_{j, -m}^\dagger] |0\rangle$$
2. **准粒子单粒子哈密顿量**：
   $$H_{\text{qp}} = E_0 + \sum_{j m} E_j a_{j m}^\dagger a_{j m}$$
3. **奇质量核单准粒子激发能**：
   $$E_{\text{ex}}(j) = E_j - E_{j_0} = \sqrt{(\varepsilon_j - \lambda)^2 + \Delta^2} - \sqrt{(\varepsilon_{j_0} - \lambda)^2 + \Delta^2}$$
