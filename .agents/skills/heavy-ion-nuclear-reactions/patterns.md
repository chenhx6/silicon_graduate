# Reasoning Patterns: 重离子核反应动力学与实验设计分析范式

提炼自林承键《重离子核反应》与 Bertulani《Introduction to Nuclear Reactions》的 5 大重离子核反应动力学推导与在束实验工程设计范式。

---

## Pattern 1: 实验入射束能优化与熔合蒸发激发函数极大值计算范式

- **核心法则**：在束 $\gamma$ 谱学寻找特定高自旋带（如手征双重带、摆动带）时，所选用的反应通道通常是 $4n$ 或 $5n$ 蒸发道。束能过低会导致熔合截面指数跌落，束能过高则引发通道转移（如变为 $6n$ 或产生大量带电粒子竞争），且容易诱发裂变截断。必须精准反推激发函数峰值对应的实验束能。
- **标准推算程序**：
  1. **确定目标剩余核与中子蒸发步数 $x$**：
     $$A_{\text{CN}} = A_p + A_t, \quad Z_{\text{CN}} = Z_p + Z_t \implies \text{Target Residue: } (A_{\text{res}} = A_{\text{CN}} - x, Z_{\text{res}} = Z_{\text{CN}});$$
  2. **估算复合核最适宜激发能 $E_{\text{opt}}^*$**：
     每个蒸发中子平均带走中子分离能加蒸发热动能 $\sim 2T$（通常每个中子消耗 $\sim 10.5 - 11.5\text{ MeV}$）：
     $$E_{\text{opt}}^*(xn) \approx \sum_{i=1}^x S_n^{(i)} + 2 x \cdot T + \Delta E_{\text{rot}}(I_{\text{target}}),$$
     其中 $\Delta E_{\text{rot}} \approx \frac{\hbar^2}{2\mathcal{J}} I_{\text{target}}(I_{\text{target}}+1)$ 为目标高自旋能级所在的 Yrast 能量偏置；
  3. **反算质心系动能与实验束流能量 $E_{\text{lab}}$**：
     $$E_{\text{c.m.opt}} = E_{\text{opt}}^* - Q_{\text{fus}}, \quad E_{\text{lab}} = \frac{A_p + A_t}{A_t} E_{\text{c.m.opt}};$$
  4. **核验 Bass 熔合势垒相容性**：
     计算 Bass 势垒 $V_B$。若 $E_{\text{c.m.opt}} < V_B$，截面将受到指数压低（必须权衡提高 1 个蒸发中子通道或更换较非对称弹靶组合以压低库仑势垒）。

## Pattern 2: 弹性散射菲涅耳 1/4 截面点与核相互作用半径反演范式

- **核心法则**：在重离子强库仑场与强吸收极限下，弹性散射角分布在小角度几乎严格等于纯 Rutherford 散射；随着散射角增大越过掠射角后，由于进入核力吸收区，比值 $\sigma(\theta)/\sigma_R(\theta)$ 发生陡峭下降。在比值降为 0.25 处的特定特征角 $\theta_{1/4}$ 严格给出强吸收接触半径。
- **标准反演程序**：
  1. 计算实验束能对应的 Sommerfeld 参数 $\eta = 0.1574 Z_1 Z_2 \sqrt{\frac{A_{\text{red}}}{E_{\text{c.m.}}}} \gg 1$；
  2. 测定弹性散射角分布比值曲线，精确插值确定 $\frac{d\sigma}{d\Omega} / \left(\frac{d\sigma}{d\Omega}\right)_R = 0.25$ 所在的散射角 $\theta_{1/4}$；
  3. 由半经典菲涅耳衍射理论反演相互作用接触半径 $R_{\text{int}}$：
     $$R_{\text{int}} = \frac{\eta}{k} \left[ 1 + \csc\left(\frac{\theta_{1/4}}{2}\right) \right], \quad k = \sqrt{\frac{2\mu E_{\text{c.m.}}}{\hbar^2}};$$
  4. 提取唯象接触间距因子 $d_0 = \frac{R_{\text{int}}}{A_1^{1/3} + A_2^{1/3}}$。中等质量核碰撞中通常 $d_0 \a1.40 - 1.48\text{ fm}$。

## Pattern 3: Rowley 熔合势垒分布二阶导数反演与形变耦合道解耦范式

- **核心法则**：核形变与振动在深次垒区对熔合截面有高达数个数量级的增强效应，其实质在于内禀自由度与相对运动耦合导致单势垒分裂为具有不同权重的势垒流。通过对实测激发函数求二阶导数，可无模型依赖地直接成像核势垒空间分布结构。
- **标准反演程序**：
  1. 高精度密集测量近垒区的熔合截面 $\sigma_{\text{fus}}(E_i)$，测量步长控制在 $\Delta E \le 1.0\text{ MeV}$；
  2. 构造变换能量加权截面 $Y(E) = E_{\text{c.m.}} \cdot \sigma_{\text{fus}}(E_{\text{c.m.}})$；
  3. 采用三点或五点数值点阵滤波算法计算二阶导数：
     $$D_{\text{fus}}(E_i) = \frac{Y(E_{i+1}) - 2 Y(E_i) + Y(E_{i-1})}{(\Delta E)^2};$$
  4. **核结构信息解耦**：
     - 若所得曲线为单对称峰，半高宽 $\text{FWHM} \a0.56\hbar\omega_B$，证明碰撞核属于球形无强耦合系统；
     - 若呈现明显双峰分裂结构（能量间距为 $\Delta V_B$），双峰面积比反映了长椭核在对头（Tip-to-Tip，势垒低）与侧向（Side-by-Side，势垒高）碰撞的空间几何几率权重，直接无偏提取靶核的真实基态四极形变参数 $\beta_2$！

## Pattern 4: 反冲核运动学、靶厚阻滞与多普勒展宽控制范式

- **核心法则**：在重离子熔合蒸发实验中，初生复合核具有可观的前向动量。若靶核过厚，束流在靶内经历剧烈能损 $\Delta E$，使得核反应发生在宽能区上导致通道混叠；若无衬底，反冲核在真空中高速飞行退激将导致极严重的运动多普勒展宽（Doppler Broadening）并引发真空退取向效应（VDE）。
- **标准控制程序**：
  1. **计算复合核反冲初动能与初速度**：
     $$E_{\text{recoil}} = \frac{A_p}{A_{\text{CN}}} E_{\text{lab}}, \quad \beta = \frac{v_{\text{recoil}}}{c} = \sqrt{\frac{2 E_{\text{recoil}}}{M_{\text{CN}} c^2}};$$
  2. **优化靶核有效厚度**：
     利用 SRIM 或 Ziegler 阻止本领曲线，将靶内能损控制在 $\Delta E_{\text{loss}} \le 2 - 3\text{ MeV}$（对稀土和中等质量靶，典型自支撑靶厚度为 $0.5 - 1.0\text{ mg/cm}^2$）；
  3. **选择匹配的背衬材料（Backing）**：
     - **DSAM 寿命测量或常规在束谱学**：采用厚金（Au，$\sim 15 - 20\text{ mg/cm}^2$）或厚铅（Pb）衬底，利用高 $Z$ 介质强大的电子与核阻止本领在 $\tau_{\text{stop}} \sim 1 - 2\text{ ps}$ 内使反冲核完全静止，使较长寿命态在完全静止后发射尖锐无展宽的 $\gamma$ 峰；
     - **RDM 活塞反冲距离法**：必须采用自支撑薄靶（Thin target，$\sim 0.5\text{ mg/cm}^2$），使反冲核以恒定速度飞出靶面进入真空漂移区，经过微米尺度位移后再在可调活塞拦截器中完全停止，形成分立的分离多普勒双峰。

## Pattern 5: 深部非弹性碰撞（DIC）能量耗散与大角动量转移评估范式

- **核心法则**：当碰撞动能显著高于库仑势垒且碰撞角动量越过完全熔合极限时，核接触表面经历剧烈相互摩擦与核子交换，系统进入深部非弹性散射机制。此时能量与轨道角动量发生巨量耗散，适合用于布居熔合蒸发难以到达的丰中子近球形或微弱形变核的高自旋同核异能态。
- **标准评估程序**：
  1. **计算粘滞接触阶段的最大角动量转移极限**：
     在强粘滞旋转极限下，双核体系像哑铃刚体一样绕质心旋转，轨道角动量向两核自旋的转化分额严格由转动惯量比值确定：
     $$\Delta l_{\text{int}} = l_i \left[ \frac{\mathcal{J}_1 + \mathcal{J}_2}{\mathcal{J}_1 + \mathcal{J}_2 + \mu R_{\text{int}}^2} \right] \approx (0.28 - 0.35) \cdot l_i;$$
  2. 对于典型重离子碰撞（如 $^{136}\text{Xe} + {}^{208}\text{Pb}$），入射角动量可达 $l_i \sim 150 - 200\hbar$，单次深部碰撞向产物碎片注入高达 $I \sim 40 - 60\hbar$ 的巨额自旋；
  3. **结合出射总动能损失（TKEL）选择符合选通窗口**：通过测量散射轻碎片动能，利用 Wilczynski 鸟嘴轨迹将全耗散深部非弹事件从准弹性本底中完全剥离，高效重构大自旋碎片的退激能级纲图。
