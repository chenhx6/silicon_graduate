# 中英文术语导航

这些是工作译名；标准中文教材的实际用语与页码须在阅读时继续核对，未核验的译法不冒充原书用语。

| English | 工作译名 | 必须区分 |
| --- | --- | --- |
| Triaxiality | 三轴性 / 三轴形变 | 形状参数与转动惯量非同一对象 |
| Wobbling | 摆动运动 | 谐近似与广义进动的术语适用域 |
| Transverse / longitudinal wobbling | 横向 / 纵向摆动 | 几何分类与有限自旋能量趋势 |
| Tilted precession | 倾斜进动 | 不同作者的命名与波函数分类 |
| Chiral doublet bands | 手征双重带 | 同宇称手征伙伴与宇称双重带 |
| Multipole mixing ratio | 多极混合比 | 有符号辐射振幅比与 B(E2)/B(M1) |
| Alignment | 角动量对齐 | 总角动量投影与扣除 Harris 参考后的对齐量 |
| Kinematic / dynamic moment of inertia | 运动学 / 动力学转动惯量 | J(1) 与 J(2) 不可反写 |
| Signature partner | 旋称伙伴 | 物理竞争解释，不是“小 δ”的同义词 |
| Dual-root ambiguity | 双根歧义 | 可能二根、重根、无实根或线性退化 |
