# Reasoning Patterns: 现代微观壳模型前沿分析与计算范式

提炼自《The Nuclear Shell Model 70 Years after Its Advent》（Gargano 等编，2023）的 5 大微观单极壳演化、连续谱共振、大规模算法与同位旋破坏分析范式。

---

## Pattern 1: Otsuka 单极张量力对偶矩阵元与 ESPE 壳演化计算范式

- **核心法则**：原子核壳隙并非静态常数。当质子在轨道 $j_p$ 中填充时，通过两体单极张量力对中子轨道 $j_n$ 施加强烈的微分拖拽，导致中子有效单粒子能级（ESPE）发生微观漂移。自旋-轨道同向轨道（$j_>$）与反向轨道（$j_<$）之间展现互补的吸引与排斥对偶性。
- **标准推算程序**：
  1. **识别质中自旋-轨道轨道对**：
     - 质子填充轨道：区分属于 $j_{p>} = l_p + 1/2$ 还是 $j_{p<} = l_p - 1/2$；
     - 中子观测轨道：区分属于 $j_{n>} = l_n + 1/2$ 还是 $j_{n<} = l_n - 1/2$；
  2. **应用 Otsuka 张量力对偶性判据**：
     $$V_{j_{p>} j_{n<}}^{\text{tensor}} < 0 \quad (\text{强吸引}), \quad V_{j_{p>} j_{n>}}^{\text{tensor}} > 0 \quad (\text{强排斥});$$
     $$V_{j_{p<} j_{n>}}^{\text{tensor}} < 0 \quad (\text{强吸引}), \quad V_{j_{p<} j_{n<}}^{\text{tensor}} > 0 \quad (\text{强排斥});$$
  3. **计算单极引起的自旋-轨道能隙演化**：
     $$\Delta_{\text{SO}} = \epsilon(j_{n<}) - \epsilon(j_{n>}) \implies \frac{d\Delta_{\text{SO}}}{d n_p} = V_{j_p j_{n<}}^{\text{mono}} - V_{j_p j_{n>}}^{\text{mono}};$$
  4. **核结构实验实证（以氧同位素 $N=16$ 产生与 $N=20$ 淬灭为例）**：
     当从 $^{28}\text{O}$（$Z=8, N=20$）向 $^{30}\text{Si}$（$Z=14$）增加 6 个质子进入 $1d_{5/2}$（$j_{p>}$）轨道时：
     $1d_{5/2}$ 质子对中子 $1d_{3/2}$（$j_{n<}$）产生强单极吸引，使中子 $1d_{3/2}$ 能级大幅向下扎入，消除了中子 $2s_{1/2}$ 与 $1d_{3/2}$ 之间的天然能隙（淬灭 $N=16$ 幻数），并恢复了 $N=20$ 传统闭壳！
     反之在极端丰中子氧同位素中，由于缺少 $1d_{5/2}$ 质子，中子 $1d_{3/2}$ 被高高抬升抛入连续谱，使得 $^{24}\text{O}$（$N=16$）成为坚硬的新幻数滴线核，而 $^{28}\text{O}$（$N=20$）直接沦为滴线外的非束缚共振核。

## Pattern 2: Berggren 复能量基底构建与共振宽度 $\Gamma$ 提取范式

- **核心法则**：当最外层核子处于滴线外或极弱束缚时，原子核处于开放量子体系。单体径向波函数在空间外围不满足渐近平方可积性（呈向外辐射出射波发散）。必须将径向波函数坐标变换到复动量平面，利用 Berggren 围道正交归一化。
- **标准计算程序**：
  1. 在单粒子复波矢平面 $k = k_r + i k_i$ 上寻找出射波边界条件极点（Siegert 极点）：
     $$E = \frac{\hbar^2 k^2}{2\mu} = \frac{\hbar^2 (k_r + i k_i)^2}{2\mu} \equiv E_r - i \frac{\Gamma}{2};$$
     实部 $E_r = \frac{\hbar^2 (k_r^2 - k_i^2)}{2\mu}$ 为共振极值能量，虚部 $\Gamma = -\frac{2\hbar^2 k_r k_i}{\mu} > 0$（要求极点位于第四象限 $k_r > 0, k_i < 0$）；
  2. **选取 Berggren 积分围道 $L^+$**：使复动量积分路径沿着下半平面绕过所有被选中的离散束缚态与准束缚共振极点，确保连续态积分收敛；
  3. **复对称哈密顿量对角化**：采用厄米对偶的复正规化标量积：
     $$\langle \tilde{\phi} | \phi \rangle = \int_0^\infty \phi_n(r) \phi_m(r) dr = \delta_{nm} \quad (\text{注意无复共轭符号！});$$
  4. 由复本征能量虚部严格解析输出目标核素的粒子自发发射衰变全宽度 $\Gamma$ 与半衰期 $T_{1/2} = \frac{\hbar \ln 2}{\Gamma}$。

## Pattern 3: MCSM 能量方差外推与全空间真实特征能级反演范式

- **核心法则**：在大规模蒙特卡罗壳模型（MCSM）计算中，由于选取的变分形变基矢数目 $N_{\text{basis}}$ 有限（通常为数十到数百个），所得变分能量 $\langle H \rangle$ 必然高于全组态 Hilbert 空间的真实基态本征值。利用哈密顿量方差 $\Delta H^2 \to 0$ 极限进行外推，可获得完全无偏的严格能级基准。
- **标准外推程序**：
  1. 对一组递增的变分基矢数（如 $N_{\text{basis}} = 20, 40, 60, 80, 100$），分别计算当前变分物理态 $|\Psi\rangle$ 的哈密顿量一阶期望值与能量方差：
     $$E_k = \langle \Psi_k | H | \Psi_k \rangle, \quad \Delta E_k^2 = \langle \Psi_k | H^2 | \Psi_k \rangle - \left( \langle \Psi_k | H | \Psi_k \rangle \right)^2;$$
  2. 在二维平面上绘制数据散点图 $(x = \Delta E_k^2, y = E_k)$；
  3. **线性与微扰二次多项式拟合**：
     由于当 $|\Psi\rangle$ 趋近于真实本征态时，能量偏差与方差满足严格的一阶微扰正比关系：
     $$E(\Delta E^2) \approx E_{\text{exact}} + c_1 \cdot \Delta E^2 + c_2 \cdot (\Delta E^2)^2;$$
  4. 外推至方差为零的截距点：$E_{\text{exact}} = \lim_{\Delta E^2 \to 0} E(\Delta E^2)$。高精度消除数十亿维大空间截断引起的系统误差。

## Pattern 4: 镜像能级差 MED 与核子 Coriolis 顺排重构范式

- **核心法则**：在同位旋多重态镜像核（如 $^{49}\text{Mn}$ 与 $^{49}\text{Cr}$）中，沿转动带自旋 $J$ 上升时，若发生某一核子对的 Coriolis 旋转解耦顺排，由于质子携带电荷排斥而中子不带电，质子对顺排会破坏库仑配对能，使得镜像能级差 $\text{MED}(J)$ 呈现特征的跳跃折返。
- **标准重构程序**：
  1. 测定镜像核对（如 $T_z = -1/2$ 与 $T_z = +1/2$）的高自旋转动带激发能谱；
  2. 计算关于自旋 $J$ 的镜像能级差：
     $$\text{MED}(J) = E_x(J, T_z = -1/2) - E_x(J, T_z = +1/2);$$
  3. **微观成分分解分析**：
     $$\text{MED}(J) = \Delta E_C^{\text{monopole}}(J) + \Delta E_C^{\text{multipole}}(J) + \Delta E_{\text{nuclear}}(J);$$
     - **库仑单极项**：反映转动拉伸导致的均方电荷半径微弱变化；
     - **库仑多极配对项**：当一对高-$j$ 质子从 $J=0^+$ 配对对解耦为全顺排时，质子之间的空间重叠度急剧减小，使得两质子间的微观库仑斥力减小约 $100 - 200\text{ keV}$；
  4. **核子顺排微观时序判定**：
     - 若 $\text{MED}(J)$ 在自旋 $J_c$ 处展现急剧的**向下载荷凹陷**，证明在质子过剩核中该自旋发生的是**质子对顺排**；
     - 若展现平缓上升，证明发生的是**中子对顺排**。直接在原子核能谱中实现单核子顺排微观组态的排他性无歧义时序反演。

## Pattern 5: $0\nu\beta\beta$ 闭合近似微观核矩阵元与模型空间不确定度评估范式

- **核心法则**：无中微子双贝塔衰变核矩阵元（NME）由两体核流算符通过交换虚马约拉纳中微子诱发。其计算精度强烈依赖于中间虚态能量积分闭合近似、两体短程关联（SRC）以及多体关联模型空间的完备性。
- **标准评估程序**：
  1. **构建闭合有效两体中微子势算符**：
     $$\hat{\mathcal{O}}_{0\nu} = \sum_{a < b} \tau_a^+ \tau_b^+ \frac{R}{r_{ab}} H_{\text{eff}}(r_{ab}, \bar{E}) \cdot \left[ \sigma_a \cdot \sigma_b + S_{ab} \right];$$
     其中中微子势函数 $H_{\text{eff}}$ 包含微观轴矢量、弱电矢量与弱磁辐射形状因子；
  2. **施加短程关联 (SRC) 与有限核子尺寸截断**：
     引入 Jastrow 关联函数 $f(r) = 1 - c e^{-a r^2} (1 - b r^2)$，消除极短距离下（$r < 0.5\text{ fm}$）核力强排斥硬芯造成的奇异发散；
  3. **比较 CD-Bonn 与 Argonne 势修正**：
     评估软芯（CD-Bonn，压低 $\sim 5\%$）与硬芯（Argonne，压低 $\sim 15\%$）引入的系统不确定度；
  4. **全空间 Lanczos 计算总矩阵元**：
     $$M_{0\nu} = \langle 0_f^+ | \hat{\mathcal{O}}_{0\nu} | 0_i^+ \rangle = M_{0\nu}^{\text{GT}} - \left(\frac{g_V}{g_A}\right)^2 M_{0\nu}^F + M_{0\nu}^T;$$
  5. 明确报告考虑微观 $g_A$ 有效淬灭因子（$q = g_A^{\text{eff}} / g_A^{\text{free}} \a0.7 - 1.0$）下的严格 NME 物理置信区间，为下一代吨级高纯锗（GERDA/LEGEND）与液氙实验提供权威半衰期灵敏度下限。
