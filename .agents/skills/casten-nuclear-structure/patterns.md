# Reusable Patterns

## Start with a two-state control model
**When to use**: two nearby bands, configurations, or Routhians appear to interact.
**How**: define unperturbed separation, coupling, observed splitting, and mixing amplitudes; test the weak and strong limits before using a multistate diagonalization.
**Trade-offs**: transparent and falsifiable, but incomplete when several states overlap.

## Audit transition strength separately from mixing
**When to use**: a mixed configuration is inferred from a weak or strong interband E2/M1 link.
**How**: expand the transition amplitude, retain relative phases and diagonal moments, and test whether cancellations make the observed link small.
**Trade-offs**: prevents overinterpretation, but needs reliable lifetimes, branching and multipolarity information.

## Use an observable matrix for collectivity
**When to use**: comparing vibrational, rotational, gamma-soft and triaxial interpretations.
**How**: combine level ratios, consecutive gamma-band staggering, absolute B(E2), quadrupole moments and model calculations; record which assumption each observable adds.
**Trade-offs**: slower than a single-ratio label, but robust against degeneracies.

## Stage Coulomb-excitation information
**When to use**: extracting E2 matrix elements or quadrupole collectivity.
**How**: stay below the nuclear-contact regime, control distance of closest approach and scattering angle, start from known low-lying matrix elements, then fit multistep excitation with signs and virtual paths retained.
**Trade-offs**: direct electromagnetic interpretation, but multistep feeding and coupled matrix elements create a nonlinear inverse problem.

## Match reaction to structure question
**When to use**: planning an experiment.
**How**: use Coulomb excitation for electromagnetic matrix elements, complete spectroscopy/ARC for level inventory, fusion-evaporation for high spin, and heavy-ion transfer for single-particle occupancy and spin selectivity.
**Trade-offs**: each reaction emphasizes a different population function and has its own completeness and model limits.
