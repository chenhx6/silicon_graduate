## 1. 任务与边界

用户已结束补下载。以当前可读原件为基础，由 Agent 逐来源深入学习、核验和知识回写；不要求用户逐篇审核，不继续把缺件清单当作用户待办。目标是重建实验与理论的证据链，形成能解释、比较、迁移和自我纠错的核结构知识，而不是批量生成论文摘要。

范围包括历次问答取得的论文、本地既有研究相关原件、新旧学位论文、HDR 和相关书籍。不是只学本次 P–δ 文献，也不是只学国外学位论文。新增获取暂停；只有关键论证确实依赖缺失材料，才记录影响并优先寻找本地证据，不自动重新开启大搜索。

不执行 PDM 重算，不代替用户选择可计算核素，不修改投稿原稿、用户分析输入或根目录 PLAN.md，不启动定时器、后台无限任务或新模型基础设施。公开数据的小型公式核算只用于学习核验，不冒充独立实验或事件级复现。

## 4. 执行任务与验收

### 任务一：统一作品身份、阅读覆盖和实验依赖

消费：上述原件账本、旧本地文献目录、knowledge/sources/ 和实际文件。

产出：outputs/literature-acquisition/20261119-deep-learning/reading-queue.jsonl，以及同目录的 progress.json。只在需要时更新被忽略的馆藏缓存，不修复无关旧锁、不改原件。

每条队列记录：work_id、title、raw_files、edition_basis、source_note、source_role、related_experiment、covered_sections、remaining_sections、topic、next_unit、evidence_gaps。标识用于内部续接，不要求用户面对庞大技术表。

先按可信 DOI/arXiv、作者题名、学位身份和原件核对归并作品；哈希仅识别字节副本。论文、SI、学位论文、HDR 收录文章和同一实验的后续论文保留关系。已有 source 不等于读完，阅读标记不代替 Covered scope；历史 review 状态不参与排序。

验收：不把 383 份 query PDF 宣称为 383 篇未学文章；不把 Lv/Zheng 的另一个文件算新增；每项能回答“读过哪里、还欠哪里、下一步读哪里”。缺件保留原有 7 条，不阻塞可读材料。

### 任务二：逐来源建立问题—方法—证据地图

消费：任务一确认身份的来源。

每篇依次阅读摘要、引言、结论和目录，随后完整理解正文主线；列出作者真正解决的问题、实验/模型设计逻辑、主张对应的图表和附录。学位论文按章形成可续接单元，但保持整篇问题链，不能拆成互不相干的摘要。

教材和学位论文的重复基础介绍先与已有知识对账；已覆盖且无变化的内容可合并记录覆盖依据，但新增研究、独有方法、附录和限制必须读。HDR 的自述与其收录论文分开；引用的实验结果不得重新算独立实验。原件扫描和乱码页走视觉/OCR，不靠模型补文本。

验收：每条核心主张能定位 PDF/印刷页、节及图表/公式；没有定位的主张不进入确定性总结。只读目录或局部章节时，如实标记范围，不将整篇置为 read/deep-read。

### 任务三：沿证据链深读，而非沿关键词摘句

实验来源重建：反应与布居 → 装置/触发 → 标定与符合/门 → 实测量 → 拟合与误差 → 跃迁/组态判断 → 结构解释。检查必要伴随跃迁、污染、侧馈、探测阈值和替代指认。

理论来源重建：自由度 → 哈密顿量和对称性 → 近似/截断 → 参数来源与拟合数据 → 矩阵元和可观测量 → 实验比较 → 失效区域。区分预测、拟合、示意图和作者解释。

对 P–δ 专题，区分 P、Δ、Q，单 γ 角分布与 γγ 角关联，ADO/DCO/Rac 的实际矩阵定义与门条件；保留 δ 分支、符号约定、误差和原文选支理由。

σ/I 分类以最终估计程序为准：固定、扫描、联合估计、profile、边缘化、仅画曲线、未报告、不适用。不能仅因某条绘图曲线固定 σ/I 就断言最终 δ 估计固定，也不能把未报告当作不适用或固定。最终允许证据支持、限制或反驳最初判断。

验收：所有会改变物理结论的数字、分支、公式条件和关键图表都回原件核查；常规信息另做抽查。实验报告、作者解释、模型结果和本任务推断分别记录。

### 任务四：用小型核验检验“是否真正懂了”

消费：任务三的真实公式、数值、单位、约定和适用条件。

优先检查量纲、纯多极/对称性极限、δ 正负与 E2 份额的关系、寿命到强度的分支/ICC 因子、简单可复核的误差传播和模型极限。只有原文输入明确时才做数值核算。

产出：有必要时在 tmp/ 保存计算草稿，已验证且可复用的方法与结果回写对应 knowledge 页面。未实现的不写成测试通过；不自动运行 PDM，不替用户拟合私人数据，不把小型核算称为复现实验或完整模型计算。

验收：能够指出方法在哪些条件下有效，并解释一个可证伪边界；无可靠依据时不强行制造反例或“新课题”。

### 任务五：按自然问题完成跨来源综合

同一问题已具备理论、原始实验、方法/误差和必要竞争解释后，即形成专题综合，不机械等待读满若干篇，也不等待全部馆藏读完。

产出：更新最相关的既有 knowledge 概念、核素、方法或综合页；确无合适页面时才建立新页。综合应含已知约束、来源依赖、冲突原因、尚不唯一的解释、下一项最有区分力的观测。不把“多篇引用同一实验”写成独立证据增强。

审稿相关总结只是一个下游出口；不以检索命中比例直接证明整个领域“通常固定 σ/I”，也不为了支撑既有投稿措辞而筛掉反证。

验收：能解释跨来源差异来自不同数据、几何、统计处理、模型还是版本；能明确本轮是否修正了既有 Wiki 认识。

### 任务六：完成与续接

每个最小阅读单元完成后，只更新必要 source/知识页和队列进度；不为每个 PDF 生成冗长重复报告。不逐篇请求用户审批，也不把执行压回用户。

单来源完成条件：研究主线已理解；关键证据已核；必要附录/SI 已读；适用条件、未覆盖范围和知识影响已记录。若关键材料不全，允许输出有边界的局部知识，但不标记全文精读完成。

收束时检查 raw 路径/哈希、locator、链接和 git diff --check，遵守现有摄入与发布门。阶段结果与操作回执分开：长期事实在 knowledge/，进度与运行记录在 outputs/。

3. Worker 交付必须含请求 ID/章列表、已覆盖/未覆盖、主张—locator、图表/公式待核项及证据边界。脚本检查是否遗漏请求项；有效 JSON 不代表任务完整。先前 22 项只返回 10 项的问题不得重演为静默通过。
4. Codex 审核改变结论的证据和跨来源推理，回看必要原页而不是重新整篇读一遍。补正仅发送缺失章节/错误单元，不重跑已合格全文。
5. Gemini 的自核与 Codex 的审核不是两份独立科学证据。关键核验必须回原件。模型失败/截断如实记录；不能静默换成高成本 GPT 全文重读并宣称原分工不变。

不先承诺每天若干篇或固定几天读完。先以首个完整专题单元测量实际阅读/核验成本，再估后续工作量。没有运行中的任务就不声称会后台持续学习。
