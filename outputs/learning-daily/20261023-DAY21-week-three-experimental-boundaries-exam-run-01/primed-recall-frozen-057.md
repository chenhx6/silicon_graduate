# Checkpoint057 原件前回忆冻结（primed）

2026-10-23：
目标：核对133Ce多重手征双重带（MχD）原件（Ayangeakaa 2013 PRL 110, 172504 与 Ayangeakaa 2016 PRC 93, 054317），审计“跨核寿命借用”的推断漏洞与能级间距非排他性边界。

记忆与待核事实：
1. Ayangeakaa 2013在PRL第3页明确声明：本实验未能测量能级寿命（"lifetime measurements were not feasible for bands reported here"），因此未能测得任何绝对B(E2)或B(M1)跃迁几率。
2. 为了支撑手征双重带解释，作者提出了一项跨核推理：同中子素135Nd具有相同的πh11/2^2 ⊗ νh11/2^-1组态且已在DSAM实验中测得对称的B(E2)，因而主张133Ce负宇称带也应具有手征对称性。
3. 该推理面临根本性的证伪风险：同中子素134Pr的反例（Petrache 2006）早已确证，即便在同中子素（N=75）且仅差一个质子的体系中，内禀四极矩比值亦可分化高达2倍（Q0比2.0(4)）；绝对不能用135Nd的对称性担保133Ce的对称性。
4. 负宇称Bands 5–6的能级劈裂高达约400 keV，完全落在常规单粒子激发与γ-振动能量尺度之内；在缺乏寿命的前提下指认为“单声子手征振动”具有强模型依赖。
5. 在2016年发表的完整在束谱学长文中，能级纲图扩展至11条四极带和9条偶极带，作者对MχD的措辞明显弱化（强调不能排除以及轴取向竞争），反映了随着观测网络完备化而收缩的推断边界。
