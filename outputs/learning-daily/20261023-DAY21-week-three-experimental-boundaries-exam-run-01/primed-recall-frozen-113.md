# 113来源前回忆（primed）

在135Nd手征微观TAC+RPA计算中，RPA声子能量趋于零常被误当作实验测得的静态相变点。需核对原刊PRC 83, 054308全文与Appendix A：(1) 小角展开线性项2phi相对有限旋转sin(2phi)在30度和40度分别偏高20.9%和41.8%，说明大振幅角摆动下谐振子近似严重破缺；(2) 论文作者明确指出RPA能量软化趋零是小振幅近似在均场临界点附近的理论发散，模型本身计算的声子能量比实验更快趋零，必须引入大振幅非谐效应；(3) 135Nd本核参数交由Mukhopadhyay 2007并在本篇“not shown here”，奇奇邻核计算不能直接填补135Nd微观预测域；明确RPA软化点非实测相界。
