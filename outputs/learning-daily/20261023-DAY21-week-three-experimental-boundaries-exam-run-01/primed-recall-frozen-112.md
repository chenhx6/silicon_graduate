# 112来源前回忆（primed）

在Qi 2009关于135Nd的全量子PRM计算中，三轴手征几何常被视为微观完全闭合。需核对原刊PLB 675, 175第6页讨论与Figs. 2-4：(1) 流体惯量比在gamma=22.4度下为6.8:2.6:1.0，转子角动量主要沿惯量最大的中轴，价质子沿短轴，价中子沿长轴；(2) 论文作者明确承认带外跨带B(E2)在PRM和TAC计算中均被系统性低估；(3) 图中三轴角动量分量为均方根值sqrt(<Jk^2>)，属正定期望值，单靠RMS非零不能作为直接测得带符号经典手征矢量的排他性实验证据；(4) 模型采用固定刚性转子形变，忽略了真实核的gamma软性与动力学形状涨落。
