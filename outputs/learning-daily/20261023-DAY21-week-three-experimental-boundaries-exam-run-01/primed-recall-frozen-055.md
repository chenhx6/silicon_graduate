# Checkpoint055 原件前回忆冻结（primed）

2026-10-23：
目标：核对135Pr横向摇摆争议双方原件（Matta 2015 PRL 114, 082501 与 Lv 2022 PLB 824, 136840）的多极混合比与跃迁强度数据，纠正旧草稿中未经原件支持的“带间 B(E2) < 0.05 W.u.”表述。

记忆与待核事实：
1. Matta 2015在Table I中报道747.0与812.8 keV跃迁的大模混合比（delta = -1.24与-1.54），得出E2份额为60.6%与70.3%，并以正向偏振不对称度作为支持，据此指认为横向摇摆带。
2. Lv 2022指出ΔI=1角分布拟合天然存在|delta|>1与|delta|<1双解，正偏振不对称度在特定角分布下同时相容于两解；利用JUROGAM II同时测量P与Rac，联合二维chi2唯一锁定了小模解（delta = -0.47, -0.37, -0.31），对应82%、88%、91%的M1磁偶极性质，从而推翻了E2主导的摇摆解释。
3. Lv 2022还测量了退激至旋称伙伴带与基带的分支比：B(E2; 747)/B(E2; 526) = 0.7(+0.7/-0.5)，直接违背了纯摇摆声子跃迁禁止退激至旋称伙伴带的选择定则。
4. 关键边界：Matta 2015与Lv 2022均未测定能级寿命tau，也未测定以W.u.为单位的绝对跃迁强度；旧草稿中的“带间 B(E2) < 0.05 W.u.”系未经原件支持的外推，必须在方法页和源页面中予以纠正，回归纯实验观测量（混合比、相对分支比与多极成分）。
