  在经典的幻数识别中，研究人员通常绘制二中子分离能系统学曲线 $S_{2n}(N)$；在闭壳 $N=82$ 处，$S_{2n}$ 表现为陡峭的断崖式跌落，其二阶差分指标：

     在非闭壳核（如 $^{131}\text{Ba}, N=75$）中，三点奇偶交错指标 $\Delta^{(3)}_n = [2M(^{131}\text{Ba}) - M(^{130}\text{Ba}) - M(^{132}\text{Ba})]/2 = 1166.88\text{ keV}$ 广泛被作为 BCS 配对能隙 $\Delta_{\text{pair}}$ 的实验测量值。然而，泰勒展开证明：三点差分不可避免地混入宏观质量面的二阶导数：$\Delta^{(3)}_n = \Delta_{\text{pair}} + \frac{1}{8} \frac{\partial^2 E_{\text{smooth}}}{\partial N^2}$。在 $A\approx 130$ 区，平滑曲率项贡献了约 $140\text{ keV}$（占实测值的 $\sim 12\%$）。若不采用四点或五点差分滤波器（如 $\Delta^{(4)}$ 或 $\Delta^{(5)}$）消除平滑曲率，提取的配对能隙存在固有系统性虚高；
  4. **最小二乘全局平差质量网络非对角协方差的遗漏边界：**
