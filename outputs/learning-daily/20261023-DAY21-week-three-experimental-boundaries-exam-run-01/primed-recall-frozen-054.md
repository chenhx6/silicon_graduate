# Checkpoint054 原件前回忆冻结（primed）

2026-10-23：
目标：核对Starosta 2001 PRL 86, 971原件中关于134Pr的原始主张与数据血缘，同Petrache 2006的反例及Mukhopadhyay 2007的135Nd正例形成严格对账。

记忆与待核事实：
1. Starosta 2001将134Pr作为N=75同中子素中手征转动岛（chiral rotation island）的中心，依据是低自旋约0.19 MeV的劈裂在I=14处降为近简并（约30-40 keV），且3D TAC计算给出约30 keV的最高鞍点势垒Eb。
2. 但Starosta 2001中的134Pr实验能级并非新测，而是直接引用自Petrache 1996（Nucl. Phys. A 597, 106）。
3. Starosta 2001未测定任何能级寿命或绝对电磁跃迁几率，其手征指认完全建立在能谱近简并、排列交错和3D TAC模型计算之上；作者在结论中明确使用了有条件的修辞：“If the chiral doublet interpretation is correct, this would be the first direct evidence for stable triaxial shapes in nuclei”。
4. 2006年Tonev等（PRL 96, 052501）测量134Pr寿命，Petrache等（PRL 96, 112502）通过两带解混合严格证明两带内禀四极矩比值高达Q0(1)/Q0(2) = 2.0(4)（允许区间1.6-2.4），且近简并源于四准粒子与两准粒子组态交叉，从而否定了理想手征带解释。
5. 与此形成鲜明对照的是Mukhopadhyay 2007在135Nd中的测量：寿命差2倍（tau_B/tau_A ≈ 2），但带内B(E2)高度对称（约0.88），证明寿命相等并非手征的必要条件。

待核目标：从Starosta 2001 PDF第3-4页精确提取Table I中134Pr的TAC数值及数据来源文字，建立严格的可证伪对照账本。
