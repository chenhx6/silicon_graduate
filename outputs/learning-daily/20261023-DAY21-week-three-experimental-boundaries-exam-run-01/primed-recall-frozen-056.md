# Checkpoint056 原件前回忆冻结（primed）

2026-10-23：
目标：对Case Study 2（34Si质子气泡表象与35Si双体自旋-轨道力对偶性）展开严格的文献原件对账，核查Burgunder 2014 PRL 112, 042502与Mutschler 2017 Nature Phys 13, 152及Yao 2012 PRC 86, 014310的微观推断阶梯。

记忆与待核事实：
1. Burgunder 2014通过34Si(d,p)35Si反应测得2p主碎片劈裂从37S的1.992 MeV表观降至1.134 MeV（降幅43%）；Baranger质心解折叠后真实单粒子劈裂减小为378 keV（25%）。
2. 移走质子主要来自于2s1/2轨道（Δn=1.47）；由于ℓ=0，单极矩阵元的张量分量K=2严格为零；中心力K=0对两支等量平移；因此25%的劈裂减小100%由双体自旋-轨道力K=1承载，完全符合角动量迹定理 (2j>+1)V_SO(j>) + (2j<+1)V_SO(j<) = 0。
3. Mutschler 2017测定34Si单质子敲出截面，推导2s1/2质子占据数为0.17(3)（对比36S的1.7(4)），宣称确立了质子密度气泡；但谱因子提取依赖程函反应模型，非直接空间密度观测量。
4. Yao 2012超越平均场GCM计算表明，四极形变涨落与配对动力学使点质子密度亏空从HF的41%降至21%，卷积有限质子电荷半径后中心电荷亏空不足10%（0.09）。
5. 对偶性边界：单体场气泡引起的势阱斜率变缓与壳模型价核子双体自旋-轨道相互作用在物理上是同一相互作用的不同理论表象；现有转移或敲出实验均未直接观测静态空间电荷密度。
