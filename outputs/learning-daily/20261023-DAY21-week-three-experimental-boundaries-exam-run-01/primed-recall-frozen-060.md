# Checkpoint060 原件前回忆冻结（primed）

2026-10-23：
目标：对135Nd手征研究的完整文献谱系与数据血缘进行终极闭环核对，核定Mukhopadhyay 2007 PRL 99, 172501中承诺的Ref. [32]（"D. Almehed and S. Frauendorf, to be published"）的实际落地情况，以及该核电磁跃迁数据的唯一原始出处。

记忆与待核事实：
1. Mukhopadhyay 2007在正文第4页两次引用Ref. [32]说明微观TAC+RPA理论计算与倾斜角theta演化的细节；文末Ref. [32]标注为to be published。
2. 经Crossref与arXiv全文比对，该理论后续正式发表为Almehed, Dönau, Frauendorf, PRC 83, 054308 (2011)（arXiv:0709.0969v2），该文回引了Mukhopadhyay 2007作为135Nd实验来源，但未在正文中重印135Nd的逐行参数；
3. Mukhopadhyay未在PRC发表关于135Nd实验寿命的长文（其2008年PRC长文系关于136Nd）；因此PRL 99, 172501 Table I是该Gammasphere厚靶DSAM数据集的唯一原始发表记录；
4. 135Nd手征研究形成了五位一体的完整谱系：Zhu 2003 (能谱拓扑) -> Mukhopadhyay 2007 (寿命与B(E2)对称) -> Qi 2009 (全量子PRM) -> Almehed 2011 (微观TAC+RPA) -> Lv 2019 (JUROGAM II重分析与MχD)；
5. 这一闭环确立了后续研究的证据边界：在没有作者未公开原始分析作业或电子记录的前提下，Table I发表值即为历史实验输入的极限，不得臆造未测矩阵元。
