# Day19恰好下一卡的无学分primed回忆

本段先于本次打开Radeck/Nolan source/raw；承认既有Wiki/Day13与刚才KL99定向companion的强priming，不是blind test或正式19交付。不重冻Day18初回忆，不用旧checks授分。

1. DSAM在衰变时速度变化可解析时用多角γ谱/centroid关联τ；停止、feeding、角/能量响应耦合，不能只按fs标签选方法。
2. RDDS把飞行时间映到靶—stopper距离；shiftedfeedinggate/DDCM可削弱未知feeding，但finite-stopper与低spin deorientation可能留下方向/时间响应。距离标定、相对效率和速度仍是时钟输入。
3. fast timing的观测是含prompt response/能量walk/门/背景的时差卷积。centroid小于单event分辨率不必无信息，但prompt calibration或gate/feeding错可主导，不能以统计N大认证精度。
4. TDPAD的扰动角分布同时依alignment、hyperfine场/电子过程与核衰变，不能当普通相同setup的单指数时差。具体时间范围须来源核查，我目前不给普适阈值。
5. 设计同1–2ps寿命时，RDDS有限stop会重要，DSAM需可靠stopping；无实际response不直接判谁更优。对更长寿命fasttiming可能适用，但需以prompt与tail以及producer统计验证。
6. 希望Radeck原件回答deorientation如何通过实际电子/核响应进入RDDS，是否单靠abovegate或τ(x)平坦可诊断全部误差；希望Nolan回顾提供实际时间域/方法响应和限制，不能从年代/综述标题猜正文结论。
