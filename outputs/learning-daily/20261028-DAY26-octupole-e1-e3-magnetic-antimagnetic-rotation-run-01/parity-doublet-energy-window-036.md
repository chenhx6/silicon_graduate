# Unit 036 — $^{225}$Ra/$^{225}$Ac 能量窗配对误导审计

## 算法

复用 Unit030 的已归档 ENSDF level 输入。对同一数值 $J$ 的每个负宇称态与正宇称态构造全笛卡尔组合，保留 $|E_-−E_+|\le W$ 的候选，分别取 $W=50,100,200$ keV。`?` 带标签只影响 bookkeeping 的 `named_band_candidate_count`，不改变物理候选计数。

## 最近能级的误导示例

- Ra 的 3/2−(B, 31.56 keV)–3/2+(A, 42.77 keV) 仅差 11.21 keV，但另外还有 C/D 带的 3/2 态；最近值不等于同一构型。
- Ra 的 5/2−(D, 260.2 keV)–5/2+(E, 236.25 keV) 差 23.95 keV，却是高能 D/E 组合，不能替代低能 A/B 候选。
- Ac 的 5/2− A–5/2+ B 差 34.78 keV，同时 C–D 差 34.83 keV；按能量最近无法唯一选带。
- Ac 的 7/2− A–7/2+ B 差 27.88 keV，C–D 差 29.11 keV；轻微能量差不能取代带连接证据。

## 结论边界

能量窗只产生候选列表。A–D 带标签来自评价方案，不能证明共同内禀波函数；没有原实验带连接、寿命、E1/E2/E3 分支和微观组态计算，不能选择一个物理配对，也不能由候选数或最近差值判定静态梨形形变。
