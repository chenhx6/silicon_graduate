# 低能轨道剪刀与高自旋MR定向研究审计

已建立独立知识笔记，完成共同M1算符、两转子约化惯量、横向倾斜密度、推转阻塞参考态及强度口径的推导。当前证据支持比较两类机制，尚不支持普适的同一本征模连续转化。

## 关键修正

- 轴对称核低能K=1剪刀是两流体对称轴的相对倾斜；绕共同对称轴转动密度不变。
- 低能模的跃迁电流不能直接当作高自旋被阻塞态的静态流；MR跃迁仍需相邻投影态之间的矩阵元。
- MR不是把一个谐振小角增大即可生成；需要检验配对、占据、形变、取向及新参考态。

## 原件与定量结果

取得Pai2016的50Cr原始研究10页PDF，聚焦读取pp1–2、4–7、9；取得Heyde2010综述59页PDF，仅聚焦咨询pp1–7及p58。没有把下载等同于全部阅读。原件签名、哈希、页数和覆盖在JSON中。50Cr跃迁流计算偏向赤道内部反相流，而不是普适的刚体椭球摆动。

50Cr向上B(M1)=1.113(49) μN²，对应向下0.371(16) μN²。TableIII给出的QRPA/LSSM轨道—自旋干涉项分别为0.71/0.390 μN²，约占总强度47%；不能将两个单独强度直接相加。数值程序和SVG同时给出轴定义与强度干涉图。示例转子参数是人为假设，没有模拟任何核素的剪刀到MR转变。
