# $^{110}$Cd：Roy 2011 Table 1 的寿命与 $B(E2)$ 中心值审计

## 来源与问题

本审计定向重读 Roy *et al.*, *Phys. Lett. B* **694**, 322–326 (2011) 的 p.323 线形拟合段与 p.324 Table 1，复核已有 `cd110-frequency-centering-and-lifetime-022.json`；另直接读取 NNDC ENSDF `110048001,110CD` Adopted Levels, Gammas 的 $16^+$–$24^+$ L/G/S/B 固定栏记录。ENSDF 对 Roy 2011 寿命有明确引用，因而是同一实验谱系的评价记录，并非五个独立复测点。

## 寿命定义先行

Roy Table 1 的 $\tau$ 是线形拟合后跨角度和门平均的**平均寿命**。ENSDF L 记录的 `T` 是**半衰期**，直接核对：$16^+$ 的 $0.250/\ln2=0.3607$ ps 对 Roy $0.36(3)$ ps；$18^+,20^+,22^+,24^+$ 分别有 $0.159,0.118,0.15,0.19$ ps 的 ENSDF 半衰期，对应平均寿命 $0.2294,0.1702,0.2164,0.2741$ ps，与 Roy $0.23,0.17,0.21,0.27$ ps 的舍入值一致。因此 7–11% 的 $B(E2)$ 中心值差异**不能用误将 ENSDF 半衰期当 Roy 平均寿命解释**；那会造成 $1/\ln2$ 或 $\ln2$ 量级的错误。

标准辐射率 $\lambda_\gamma(E2)=1.2239\times10^9 E_\gamma^5(\mathrm{MeV})B(E2)(e^2\mathrm{fm}^4)\ \mathrm{s}^{-1}$、$1e^2\mathrm b^2=10^4e^2\mathrm{fm}^4$ 给 $B(E2)=0.0817/[E_\gamma^5\tau_\mathrm{mean}]$，采用既有 022 的舍入系数 $0.0816$。对于任意分支与内转换，应再乘 $I_{\gamma,t}/\sum_k I_{\gamma,k}(1+\alpha_k)$；该分母需要同一次谱学的完整分支账本。

## 分支、内转换与评价对象的差异

ENSDF 对五条 E2 的总内转换系数依次给 $9.73,7.47,6.56,6.63,6.32\times10^{-4}$。这只带来约千分之一的修正，无法独自解释约一成的中心值差异。对于 $16^+,18^+,20^+,24^+$，所读 Adopted L 记录各只列一条强度 100 的相应带内 E2；不能凭空填入未列的约 8–13% 侧支作为解释。

$22^+$ 是独立的来源分歧。ENSDF Adopted 同时列 $1314.1$ keV 的 RI=100(4) 和 $1100$ keV 的 RI=37(11)，据此保留 $1314.1$ 支线约 $0.73$ 的总分支份额并列 $B(E2)=22(8)$ W.u.；但同一评价注释明确记载 Roy 2011 在 $\gamma\gamma$ 符合门中**未确认** $1100$ keV 线，采用 $T_{1/2}=0.15(5)$ ps。若把评价的 $1100$ keV 分支强加给 Roy 的 Table 1，会混合两个不一致的分支选择，不能据此“修正”其 $0.09(3)$。Roy 原文也没有给本表完整 $B(E2)$ 换算输入或可重放的线形/feeding 协方差。

ENSDF 对 $16^+,18^+,20^+,24^+$ 带内 E2 列约 50(5)、41(6)、38(7)、21(6) W.u.；这些采用评价寿命/分支规则，与独立公式的条件值数量级相合，不能作为 Roy Table 1 中心值“实为另一个数”的证明。区别还受评价版本、舍入和原文未列出的提取输入限制。

## 结论与下一步

可以排除单位/半衰期误用和已列内转换系数作为主要差异成因；$22^+$ 另有评价保留但 Roy 未确认的 $1100$ keV 支线。Roy 打印的五个 $B(E2)$ 与条件反推值应并列保留，不静默覆盖。要定位约一成的中心偏移，仍需 Roy 的逐门寿命/feeding、实际采用的分支和 $B(E2)$ 换算表或作者更正；本审计没有取得可复算的补充材料。科学状态为**中心值归一来源未定，正式统计一致性不可判定**。
