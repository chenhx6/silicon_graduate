# Ba–Ra微观机制定向研究回执

长期推导见 [[ba-ra-blocking-cancellation-operator-boundary]]；本文件仅记录执行与边界。

新来源：Engel2003与Dobaczewski2005预印本暂存tmp，未写raw。签名、哈希、页数、阅读覆盖及描述性解耦拟合全部载于同名JSON。

主要发现：八极驱动的d5/2–h11/2及f7/2–i13/2纯球形通道不能直接承载rank1 E1；相消必须回到完整过渡密度与投影核。阻塞影响的方向不能由v²唯一决定。225Ra的四点三参数解耦拟合只能描述交错，截距不是实测隧穿；064的排他性物理措辞不可沿用。
