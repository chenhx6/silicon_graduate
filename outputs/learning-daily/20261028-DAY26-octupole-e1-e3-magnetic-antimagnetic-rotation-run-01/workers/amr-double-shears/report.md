# AMR double-shears/core-coupling result

Command: `python3 amr_double_shears_core.py`

The geometry grid gives `max|C21| = 0`, `max|T22 - 2 sin^2(theta) exp(2 i phi)| = 8.01e-16`, and `max|mu_perp| = 0` for equal blades. With Roy's literal 110Cd parameters, the solved shears angles for 16+–24+ are 70.0°, 62.6°, 54.2°, 44.3°, and 31.1°. The corresponding literal model B(E2) values are 0.141, 0.112, 0.078, 0.043, and 0.013 e2 b2, compared with the Table 1 values 0.14(1), 0.12(2), 0.11(2), 0.09(3), and 0.06(2).

For beta2 = 0.12, the uniform-charge K=0 estimate at I=20 is 0.0737 e2 b2 for 110Cd and 0.0628 e2 b2 for 104Pd. This is a scale estimate for a possible core E2 amplitude; it is not an experimental core fraction, and coherent amplitudes cannot be replaced by an incoherent sum of B values.

For 104Pd the Table I data are 0.26(2), 0.22(2), 0.19(1), 0.13(1), 0.07(1), and 0.02(1) e2 b2 for 16+–26+, with reported J(2)/B(E2) = 112.3(8.6), 140.9(12.8), 334.2(17.6), 282.3(21.7), and 554.3(79.2) for 16+–24+. Rather's full arXiv Table I is the direct locator for these values.
