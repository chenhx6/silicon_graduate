# Octupole damping of actinide backbending

This worker contains a reproducible mechanism calculation for the Day 26
question: how a nonzero reflection asymmetric coordinate can turn a sharp
high spin band crossing into a broad upbending response.

## Model

For each cranking frequency, the solver diagonalizes

```text
H'(ω) = [[E_A(ω), V_pair + V_3 β_3],
         [V_pair + V_3 β_3, E_B(ω)]] .
```

`A` is a paired reference configuration and `B` an aligned two-quasiparticle
configuration. `V_3 β_3` is the leading matrix element generated by the
octupole field between the Δl=Δj=3 partners `π(1f7/2,1i13/2)` and
`ν(1g9/2,1j15/2)`. The pairing gap is reduced as
`Δ_eff=Δ_0/(1+6β_3²)` to expose the requested pairing weakening. The avoided
crossing, however, is dominated by octupole mixing for β3>0; this is what
spreads the alignment transfer over frequency.

The observables are `I=-dE'/d(hbarω)` and
`J^(2)=dI/d(hbarω)`, evaluated by second order finite differences on a
uniform 0–0.8 MeV grid. Run:

```bash
python3 solve_backbending_damping.py
```

Outputs are `scan.csv`, `scan.json`, `backbending_damping.svg`, and a PNG.

## Interpretation and boundary

At β3=0 the residual coupling is only 0.03 MeV, so `J^(2)` has a narrow
crossing peak. Increasing β3 increases the avoided-crossing gap and the
aligned configuration weight changes continuously; the peak broadens and its
height falls, which is the model definition of backbending damping. The
calculation is a controlled two-configuration demonstration, not a
self-consistent HFB/CRMF prediction and not a fit to the full Th/Ra isotope
chains. Pairing reduction and octupole mixing are kept as separate knobs so
their distinct effects can be audited.
