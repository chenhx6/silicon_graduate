# Odd-A octupole Coriolis inversion worker

This worker is a transparent effective model for the $^{225}$Ra and
$^{225}$Ac low energy parity partners.  The input energies are the adopted
ENSDF values recorded in `knowledge/sources/nndc-2009-ra225-adopted-parity-doublet.md`
and `knowledge/sources/nndc-2022-ac225-adopted-parity-doublet.md`.

Run:

```bash
python3 solve_odd_a_coriolis.py
```

Outputs are `level_fit.csv`, `microscopic_scan.csv`, `results.json`, and
`parity_splitting.svg`.

## Model

For a same-spin opposite-parity pair, the fitted signed displacement is

`Delta(I) = d0 + dA [I(I+1)-K^2] + dC (-1)^(I+1/2)(I+1/2)`.

The last term is active at first order only for `K=1/2`.  For `K=3/2` its
kernel is identically zero, so the Ac comparison uses only `d0,dA`.  The
three fitted quantities have the effective interpretation `d0` (mean offset),
`dA` (inertia difference), and `dC = A [a(+) - a(-)]` (decoupling difference).

Microscopically, parity conservation gives the exact selection rule
`<+,K|H_Coriolis|-,K> = 0`.  An octupole field `V3` can connect Delta-j=3
orbitals of opposite parity; the observable effective term is generated by
the second-order paths `V3 H_C` and `H_C V3`, schematically

`H_eff(+-) = sum_n [<+|H_C|n><n|V3|-> + <+|V3|n><n|H_C|->]/Delta E_n`.

The scan varies a dimensionless `V3/Delta E` proxy and is not an orbital
amplitude extraction.  145Ba is retained as a model-only blocking control
because the local evidence identifies state dependent sdf-IBFM octupole
content rather than an adopted parity-doublet ladder.

The signed alternating displacement function used in the note is

`S(I)=(-1)^(I+1/2) Delta(I)`.

It separates the regular `d0,dA` trend from the Coriolis kernel: a large
`dC` makes the raw Delta values alternate in sign, while `S(I)` carries the
smooth residual trend.  A negative raw Delta at 3/2 and 7/2 in Ra is therefore
an apparent ordering inversion, not a claim that the nuclear parity quantum
number changes.

All fitted values are model diagnostics.  They do not prove static octupole
deformation, unique band identity, or a measured orbital matrix element.
