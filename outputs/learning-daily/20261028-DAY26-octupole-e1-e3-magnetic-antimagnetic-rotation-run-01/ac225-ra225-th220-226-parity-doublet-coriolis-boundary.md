# $^{225,227}$Ac—$^{225}$Ra 与 $^{220,222,224,226}$Th 八极宇称伙伴审计回执

长期推导见 [[ac225-ra225-th220-226-parity-doublet-coriolis-boundary]]；本文件只记录本轮 NNDC/ENSDF 数据核验与边界。

## 主要结论

- 纯轴对称强耦合公式中，$K=1/2$ 才有一阶对角 Coriolis 解耦项 $A a(-1)^{I+1/2}(I+1/2)$；$K=3/2$ 的该项为零。
- 这解释了 $^{225}$Ac A/B 候选带的平滑低阶差值，但当前 NNDC A/B 配对给出 $E_+-E_- = 40.10,34.78,27.88$ keV（$I=3/2,5/2,7/2$），并不支持“处处正且恒在36–47 keV”的强表述。
- $^{225}$Ra $K=1/2^\pm$ 带的同自旋差值为 $E_--E_+=+55.16,-11.21,+94.95,-42.24$ keV，交错由一阶解耦项驱动；已有四点描述性拟合给出 $A\delta a=-20.43$ keV。
- NNDC $^{226}$Th Adopted 表列出 $K=0^-$ 八极振动带的 E1 多极性和分支，但没有负宇称态寿命，因而不能仅由该表给出绝对 $B(E1)$。

## 数据定位

- $^{225}$Ac：40.09-keV $E1$，$B(E1)=0.00171(15)$ W.u.；A/B带低自旋差值见 `nndc-2022-ac225-adopted-parity-doublet`。
- $^{227}$Ac：27.36-keV $3/2^+\to3/2^-$ E1，$B(E1)>3.9\times10^{-5}$ W.u.；A/B $K=3/2$候选带差值在高自旋处可穿越零。
- $^{222}$Th：评价明确称246-keV $K=0^-$带与$K=0^+$基带为八极宇称双重态；列出 $B(E1)/B(E2)\sim1.1\times10^{-4}$–$3.4\times10^{-4}$。
- $^{224}$Th：E1/[E1]带间线和 $D_0/Q_0=(6.7$–$10.0)\times10^{-4}$ fm$^{-1}$；部分带归属带问号。
- $^{226}$Th：$1^-\to0^+$ 230.37-keV、$1^-\to2^+$ 158.18-keV以及后续 $K=0^-$—基带 E1线；绝对强度缺负宇称寿命。
- $^{220}$Th：5−带头993.77 keV，评价列出多条E1连接，但没有绝对 $B(E1)$。
