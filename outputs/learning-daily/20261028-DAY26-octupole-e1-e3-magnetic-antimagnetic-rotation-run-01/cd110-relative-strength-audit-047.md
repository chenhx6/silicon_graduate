Roy 数值来自 PDF p.3 Table 1；τ 是平均寿命，ENSDF T1/2 是半衰期。二者由 ln2 连接。RI 是谱产额，不由这些跨母态 RI 推出绝对 B 或 B 比。

22+ 下 1100(1)-keV 线在 HI,XNG 中 RI=1.0(3)，无多极性/显式末态。Adopted lines2485–2504 列 RI=37(11)、[E2]、BE2W=20(10)，同时注明 Roy 2011 未在符合门谱中确认该线：包括该线所得 T1/2=0.11(4) ps，与作者未确认情况下 0.15(5) ps 不同。1100-keV 能量差接近另一条 20+ 能级；不是自动与 1314-keV 同末态。

HI,XNG 没有数值化结构字段 B(M1)/B(E2)、BE2W 或 BM1W；adopted 的相关 yrast 记录含 BE2W，其它带含 BM1W。标题提及推导项目并不提供本序列的 M1/E2 数字；也不构成 M1 绝对零值的上限。

Roy p.2 对1323/1314 的自旋标签出现倒置，故保留拟合流程表述歧义；Table1、Fig2 caption与能级差优先用于跃迁身份。停止本领系统误差约可达20%，不在表列拟合误差内。
