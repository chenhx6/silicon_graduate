# MR/AMR observable matrix 037

This matrix separates **necessary inputs**, **supporting evidence**, and **non-identifying measurements**. It does not define a single sufficient hard gate.

| Observable | MR use | AMR use | Main non-identifiability |
|---|---|---|---|
| Intrinsic current residual | Self-consistency/model check after fixing density and axes | Test a specified double-shears cancellation | 017/034 toy residuals cannot assign a nuclear mode |
| M1/E2 multipolarity | Establish ΔI=1 M1 links and E2 crossovers | Verify candidate ΔI=2 E2 sequence and other links | Multipolarity alone is not a mode assignment |
| Absolute B(M1) | Quantify shears strength and g-factor geometry | Test predicted transverse cancellation | Requires lifetime; large/small values are not unique |
| Absolute B(E2) | Measure weak core collectivity | Test E2 evolution with spin | Weak E2 has termination and mixing alternatives |
| B(M1)/B(E2) | Comparative magnetic dominance | Comparative weak-E2 clue | Ratio cannot separate numerator/denominator changes and is not dimensionless |
| J^(2) | Locate alignment/crossings | Kinematic response for comparison | No universal J^(2)/B(E2) threshold |
| Polarization/DCO | Assign M1/E2 character | Assign E2 sequence and competing links | Does not measure intrinsic current |
| Lifetime/feeding | Convert intensities to absolute B values | Establish absolute E2 trend | One lifetime or absent shift is insufficient |
| Configuration/alignment/termination | Required for shears interpretation | Required for two blades and core sharing | Energy fits alone do not fix configuration |
| S(I), level regularity | Regularity/crossing map | Candidate ΔI=2 structure | Smooth energies and near-degeneracy have competing explanations |
