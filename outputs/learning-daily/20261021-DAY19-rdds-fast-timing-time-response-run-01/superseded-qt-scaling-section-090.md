1. **四极矩平方根敏感性律（Square-Root Law）**：由于能级寿命严格与阻止本领标度因子反比（$\tau \propto 1/k$），而约化电四极跃迁几率正比于寿命倒数（$B(E2) \propto k$），内禀跃迁四极矩 $Q_t \propto \sqrt{B(E2)}$ 严格服从平方根标度律：
   $$\frac{d\ln Q_t}{d\ln k} \equiv +0.500$$
   当介质阻止本领存在 $\pm 10\%$ 的理论标度误差时，提取的跃迁四极矩 $Q_t$ 仅产生 $\pm 4.88\%$ 的半幅漂移；阻止功率低估 $20\%$ 时，$Q_t$ 仅被低估 $-10.55\%$。这表明四极矩对阻止功率模型系统误差具有优良的平方根阻尼效应；
2. **双比值尺度不变性定理（Scale Invariance Theorem）**：在核结构鉴别中，跨自旋或跨能带的双交叉比值（如 $^{136}\text{Nd}$ 带交叉四极跃迁比值 $D = R(17)/R(18) = 19.25$ 与 $^{106}\text{Ag}$ 双带 $S(15)/S(17) = 7.2863$）由于分子分母包含等阶次的 $B(E2)$ 或 $B(M1)$ 因子，全局阻止本领常数因子 $k$ 在代数上严格对消：
   $$\frac{d D}{d k} \equiv 0, \quad \frac{d S}{d k} \equiv 0$$
   这在数学上证明：即便在阻止功率存在高达 $20\%$ 整体标度未知偏差的情况下，双比值所确立的能带反转、手征对称性破缺与结构跃变结论依旧保持绝对数学刚性与实验可靠性。
