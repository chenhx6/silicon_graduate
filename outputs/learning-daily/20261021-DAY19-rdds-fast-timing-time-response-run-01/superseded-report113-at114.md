### checkpoint113：阵列合并权重与对齐平移消去条件

基于 `day19_gcd_pooled_weighting113.py` 的解析与独立合成控制（`gcd-pooled-weighting-result-113.json`，1200次MC与解析方差自洽比1.009），建立多探测器合并GCD（Régis 2015 Eq. 11/Sec. 3）的数据处理合同边界。

对齐平移消去条件：对每对探测器施加的常数时移 $s_i$ 在单对 $\Delta C_i$ 中自然抵消；但在多对合并质心差 $\Delta C_{\text{pool}} = \frac{\sum w^+_i C^+_i}{\sum w^+_i} - \frac{\sum w^-_i C^-_i}{\sum w^-_i}$ 中，平移项严格抵消的充要条件是 start 与 stop 谱的对权重严格相等（$w^+_i = w^-_i$）。在角色不对称权重下（如 $w^+=[0.8, 0.2], w^-=[0.2, 0.8]$），未校正的平移导致 36 ps 表观偏差，平移不变性被破坏。

校准均值PRD的样本匹配条件：若校准级联与目标级联在各探测器对间的产额比例不同，必须使用目标级联的匹配权重对各对 PRD 加权；若误用标量无权均值，在两对模型中产生 9 ps 的系统偏差。简单计数叠加仅在各对事件数相等时等价于无权式。新 RG15-9 与 canonical 笔记记录该合同边界，不断言原 EXILL&FATIMA 实验存在违约。
