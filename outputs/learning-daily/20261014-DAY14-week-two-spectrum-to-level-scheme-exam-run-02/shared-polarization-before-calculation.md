# Shared doublet 偏振：来源后、计算前预测

- 本题延续HE15-9/10与N193-5，不是新的盲测，也不打开Day15/16。
- 把同一校准a下的未分峰计数相加，共同A应是component A按校正计数总量加权的convex mixture；即使counts共享事件，均值代数仍成立，统计covariance另算。
- 因而shared negativeA可以限制“两个component在该门/geometry/alignment下都非负”的joint命题，但不能标出哪条有负A，更不能无条件把某条标为M2。
- a(E)在0.6keV之间的斜率差预计太小，不能独自解释-0.076；原数据缺joint calibration/gate/background计数，不给实验significance。
- 初始magnetic-substate population和stretched assumption决定electric/magnetic的sign预期；需要先检验纯E2在不同合法ρ下的P范围，再与Rexp联合看。Point-detector/unobserved-final-state模型不是JUROGAMresponse。
- 逐峰Iγ不是polarimetry mixture weight；δ/meanτ不从sharedA或Q标签生成。
