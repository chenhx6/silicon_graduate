## 三层级联与门（先写后查）

```text
E_u, J_u^π_u
      │ γ_a（上→中）
      ▼
E_m, J_m^π_m
      │ γ_b（中→下，参考门候选）
      ▼
E_l, J_l^π_l
```

1. `gate γ_b → spectrum γ_a` 与 `gate γ_a → spectrum γ_b` 支持同一衰变路径，但单一两重符合不能独立证明a/b顺序，也不能排除同门重叠线、污染核素、随机符合或分支。至少需要不同上下游门、交叉/旁路、能量闭合与强度/延迟约束。
2. 初步能量关系是`E_u-E_m=E_a`、`E_m-E_l=E_b`；若只知道两条γ能量而没有锚点，整体绝对能量可平移。传播误差须保留公共calibration协方差；不能把打印的圆整值当独立高精度测量。
3. DCO放在逐条γ边：写清参考门多极性、两个角组、归一化、alignment/δ和标定。可约束dipole/quadrupole，但经验比值不能跨阵列照搬，不能单靠RDCO从零指定绝对spin。
4. 偏振放在同一条γ边：测量非对称A与电磁性质之间需要几何修正a(E)及响应Q(E)；应核原文平行/垂直与符号。DCO+偏振+已知Jπ锚点才有条件沿图递推；δ/非stretched分支仍可能多解。
5. 寿命放在母能级：总τ并非一条γ的partialτ。强度/branch要效率校正、ICC/feeding/时间窗；得到B值还需Eγ、多极性与混合比。未知分支/τ时不能由箭头宽窄宣称collectivity。
6. 反证：换一个干净下游门后疑似γ_a消失，而旁路/另一核素门内增强，或时间关系与拟定顺序相反，应先重查transition identity/placement。非观测须给灵敏度，不能直接判不存在。
