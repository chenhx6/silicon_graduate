| 提示 | 来源前回忆 | 信心/待核验 |
|---|---|---|
| fusion-evaporation | 入射道捕获后形成高激发复合核，系统把入射能量和角动量分布带入复合核；统计蒸发粒子改变残核的激发能、质量/电荷和自旋布居。 | 中；各反应道分支及具体布居须查原文/反应模型。 |
| compound nucleus / evaporation residue | 复合核经中子、质子或 α 等粒子蒸发以及 γ 去激发，留下特定核素残核。实际被分析的蒸发残核是入口反应道选择后的子样本。 | 中；竞争道和探测接受度会改变样本。 |
| γ cascade / high-spin entry | 高自旋残核可沿连续 γ 级联降到较低能态；反应角动量提供可布居高自旋态的入口，但可见最高自旋还受反应道、级联、分支和统计限制。 | 中；不能从“看见高自旋带”反推唯一反应机制或绝对布居。 |

| side feeding | 被观测能级上方未完全解析的级联/带外路径向该态供给布居，会影响强度和寿命/线形分析；它不等同于该态能级归属错误。 | 中；需要明确 gate、侧馈模型及数据才能定量校正。 |

## Day 12 来源前主动回忆（仅下一卡预习）

记录时间：2026-10-12 18:14 Asia/Shanghai。此处先于打开 Walz 2015、Söderström 2020 和 γγ 符合方法来源；只检查了课程矩阵的 Day 12 任务描述。

| 提示 | 来源前回忆 | 信心/待核验 |
|---|---|---|
| prompt / delayed gate | prompt gate 选择与反应瞬时 γ 级联时间相关的事件；delayed gate 用时间差或衰变关联挑出异构态/延迟衰变路径。 | 中；需核实际 trigger/window、isomer lifetime 与采集条件。 |
| coincidence / random | 真符合来自同一事件或级联中处在符合时间窗内的 γ 对；随机符合来自两个无关 singles 偶然落进同一窗口，率会随 singles 率和窗口宽度上升。 | 中；具体 random subtraction 和归一化需查原文。 |
| Compton background | γ 光子在 Ge 中发生 Compton 散射后只沉积部分能量，形成连续背景；反符合屏蔽、能量门和多重符合可抑制部分背景。 | 中；这些手段不能自动排除所有逃逸、求和或级联混线。 |
| gate bias | 以强跃迁开窗会条件化样本，只保留与门线同级联或共享能级的事件；弱支路、带外 feeding 和效率会让不同 gate 的相对峰强改变。 | 中；需区分门的用途与按门谱作绝对强度推断。 |

初始审计设想：先核母核/目标核 gate，再查互符合和能量和，之后看 prompt/delayed 时间、效率归一化与 off-time/random 控制；对弱峰检查 511-keV escape、sum peak、Compton、random coincidence 和错误级联。上述为来源前工作假设，尚未绑定到任何论文 claim。

## Day 13 来源前主动回忆（不计课程学分的预习）

记录时间：2026-10-12 21:35 Asia/Shanghai。此处先于打开 Doppler correction 方法页、Mavela 2019 论文页和在束实验来源；已读 Day 13 矩阵卡与其下一次运行 prompt。

| 提示 | 来源前回忆 | 信心/待核验 |
|---|---|---|
| Doppler shift 与角度 | 移动发射体沿探测器方向运动会蓝移、逆方向会红移；非相对论一阶近似含 `β cosθ`，角度应相对核反冲速度而非仅束流轴。 | 中；符号依赖角定义，需核洛伦兹变换和实验 convention。 |
| recoil velocity | 完全熔合残核的纵向速度可由入口动量守恒估算，但中子蒸发会携走动量，实际残核速度有事件间散布。 | 中低；不能把 beam velocity 当作逐事件 residue velocity。 |
| stopping history | 在靶内减速时发射的跃迁产生速度分布积分后的线形；停止后发射不再保留反冲 Doppler shift。 | 中；靶厚度、寿命和 stopping power 决定可见线形。 |
| event-by-event correction | 逐事件校正需要探测器角度/位置和对该事件源速度的估计；用单一平均 β 校正会留下由速度和角分辨造成的残余宽度。 | 中；需查速度重建法、响应和校正残差。 |

初始练习路线：在低速近似下取 `E_lab≈E_0(1+β cosθ)`，再用一阶误差传播检查 `σβ` 与角度误差怎样影响 corrected energy；须由 Day 13 原文确认公式、角度约定及是否需要 relativistic correction。
