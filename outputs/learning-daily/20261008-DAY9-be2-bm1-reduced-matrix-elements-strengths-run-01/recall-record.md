## 初答

- 母态平均寿命 `τ` 是总衰变率 `λtot` 的倒数；半衰期 `T1/2 = ln(2) τ`，所以 `T1/2` 与 `τ` 不是同一个时间量，反算为 `τ = T1/2/ln(2)`。数值单位必须一致，例如 ps 转成率时要用 `1 ps = 10^-12 s`。
- 对一条光子支路，若 `bγ` 确实是“每次母态总衰变产生该跃迁 γ 光子的概率”，则 `λγ = bγ/τ`，辐射部分寿命 `τγ = τ/bγ`。只给归一化 γ 相对强度时，不能自动把它当作绝对每衰变光子分数；若分支是含转换电子的总跃迁分支，需要用适用的完整转换账本换成 `bγ`。
- 对固定多极 `XL`，`Tγ(XL) ∝ Eγ^(2L+1) B(XL)`，`B(XL; Ji→Jf) = |<Jf||M(XL)||Ji>|²/(2Ji+1)`。因此由寿命得到 B 值必须明确能量、多极性、分支 basis、约化矩阵元约定及 B 的单位。
- 同一跃迁若含两种允许多极，mixing ratio 的平方给相应辐射部分率之比，例如 E2/M1 的 `δ² = Tγ(E2)/Tγ(M1)`；它不是 branching fraction。强度或 B 的平方量信息不能单独给出相对振幅符号。
- 若把寿命和支路误差视作独立输入，传播可先按 `λγ=bγ/τ` 对数微分；但 branch 归一化协方差、共享寿命、能量误差、feeding 与 stopping 相关性都需单独交代，不能自动假设独立。
