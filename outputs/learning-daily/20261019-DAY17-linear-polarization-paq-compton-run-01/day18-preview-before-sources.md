# Day18无学分知识预习：来源前主动回忆

本日身份固定Day17，Day18只partialpreview，不授分/不打开19。已在Day9寿命/BE2和Day13Doppler等读过DSAM相关知识；本session也已暴露Day18卡标题与165Tm/136Nd source名称，非独立盲测。尚未本session打开这两source正文或raw。

主动回忆：DSAM观测的是随角/门变化的γ能谱，tau由初速/靶停止、sidefeeding时间分布、response和背景的联合前向模型拟得，不是谱图直接读值。F(t)=v(t)/v0；centroidF(tau)和fullshape是不同统计对象。若feeding未知，leveltau和feedingdelay常退化。stopping/速度的变化可模仿tau；不能只说statfiterror就是总误差。

换算：总tau的1/tau是所有衰变率和；某gamma的lambda_gamma=b_total/[tau(1+alpha)]，或用已归一photonbranch f_gamma/tau且分母必须一致。mixedM1/E2时delta²/(1+delta²)给photonE2份额，需energy/multipole/phase和ICC合同。BE2~lambda_E2/Egamma^5；Qt由rotationalCG、K和axial rotor assumptions换算，bandmixing/triaxialrotation使Qt不是直接几何beta。tau短一些BE2/Qt大；common stopping error使多level correlated，不可按独立weightedtrend压小系统误差。

本次要核：Jensen2001真实reaction/array/gates、带/transition lifetimes/Qt，作者fit和实测层；Mukhopadhyay2008真实136Nd数据/统计/sidefeeding/stopping模型和形变interpretation；定量任务从actualtable重算一条tau→partialrate→BE2→Qt，缺branch/MR/ICC则如实readiness，不用adoptedpure标签补。反证优先feeding/stopping替代能否改作者解释、同实验复用/模型共源。先读原件完整主线/关键图表/误差，不从旧Wiki行兑换新阅读信用。
