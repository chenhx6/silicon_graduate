# 时角联合合同：推导和计算前冻结

来源已priming：本sessionDR70全文与Gaussian/actualTableI已核，Eq7只给积分权重。新问题是一项解析辨识设计，不补当前核实验输入，不用更多MC。

构造两个物理允许的targetJ2密度：qA由parentJ4/M0经purestretchedE2完整求迹，qB由parentJ4isotropic同样求迹；两者均positive/normalized。两个路径以相同权重.5进入同target，第一路径立即注入、第二路径经过meanτf的等待，target自身meanτ。比较在两条路径间交换qA/qB的两个联合模型。它们总时间密度和积分targetρ完全相同，预期逐时间/逐角谱不同，不能声称当前核真实有这种相关。

gd(t)=exp(−t/τ)/τ；gf为feedingwaiting与targetwaiting的卷积，同τf=τ时t exp(−t/τ)/τ²。用已有CG核求qA；分析β(t)/β0=exp(−t/ts)的idealpointcentroid，Ld=1/(1+τ/ts)，Lf=Ld/(1+τf/ts)。不调用实验stop参数，τ=τf=ts=1仅无量纲展示。需要pointθ60（cos非0）和其它boundedcontrols，fullangular平均、equalρ/equaltime、τf→0/ts∞/ts0。16/32角投影、独立数值时间quad核解析Laplace；直接模型/交换模型积分AD和total time一致。任何conditionalF差只模型，禁止转真实τbias/P/Q/experimentalCI。

一般operator合同ΔN=.5∫(gd−gf)Tr[(ρA−ρB)K(t)]dt；K若时间无关则为0。时间响应不同时，单独marginalAD+时间密度不足。Compton实测A/P/Q尚需matchingenergy/selectionresponse，本文不造真实Q。
