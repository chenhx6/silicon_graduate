# 明确壳层的ICC伴随观测：来源前回忆（primed）

1. ICC为某conversion电子rate对同gamma辐射rate之比。K、L、total必须同量比较；angle-integrated ICC与有限接受electron/gamma计数之比还隔着效率和各自angular response。理论ICC不是实验观测。
2. M1/E2归一radiationdelta给alpha_mix=(alpha_M1+delta² alpha_E2)/(1+delta²)，前提是同能量同壳层、radiativecomponent定义、所用angle积分模型适用；δ符号通常不进总标量ICC，不能拿ICC判相位sign。
3. 14+→14+满足E0的ΔJ0/同parity选择规则；E0无single-gamma分支却可增加conversion。E0可能破坏把所有电子归给M1/E2的绝对strength模型。sourceST99两point hypotheses的ICC设计需声明是否排除E0；查既有source支持与模型适用性，不把此推断写作者报告。
4. scalar核选择规则不决定atomicvacancy、shellbinding、penetration、pairconversion或finite detector接受。BrIcc FO/NH的具体处理、uncertainties和domain必须从方法原件核，不能靠code名记忆补。
