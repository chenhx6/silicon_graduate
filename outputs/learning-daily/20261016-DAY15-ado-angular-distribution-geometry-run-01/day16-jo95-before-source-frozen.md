已经读过本session中Compton方法页的Jones摘要，也已为选择companion而读JO95旧source页；已见197/1368等Q值和旧B=.29/C≈.003表述。未在本段打开原PDF。这是primed recall，不是独立测试或Day16正式成绩。

1. Q=A/P，A是计数/响应不对称，P是电场偏振；P若由同套角分布/alignment拟合得出，不能当无误差外部真值。Q取决于energy、accepted散射角、threshold、geometry及selection。
2. 旧页列197/415/423/845/1368keV五点；415和423的Q印值不同，可能因不同setup/误差或响应身份，未核原件不能说是急剧energy依赖或矛盾。旧曲线B/C及能量单位必须原式核，不能凭Wiki参数猜。
3. threshold会改acceptedCompton几何和效率；figureofmerit要有具体ε定义。提高Q不自动提高统计信息εQ²。relativeNaI photopeakefficiency不是polarimetry事件效率。
4. ST99声称标定曲线小系统差可能由threshold/collimator，不足以认证Jones95与ST99 Q可任意交换；先检查是否不同采集、哪些角分布/模型/仪器共享。
5. 失败控制：同一个实际器件/knowntransition在matchedthreshold与geometry下复校Q；P公式必须保留有限角/子态模型不确定度。若只由未知δ同时求P和Q，会出现识别问题。
