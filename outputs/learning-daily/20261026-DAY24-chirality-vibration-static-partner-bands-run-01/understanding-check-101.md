1. **左右手均场极小与有限核静态手征如何区分？**

TAC在指定固定输入下的非平面解可有左右手均场简并；有限量子PRM仍可因隧穿形成有劈裂的本征态。静态regime描述局域化/小隧穿的近似，不把实际非简并本征态称永久固定一手，也不把RPA零频、均场分岔、有限核能隙及实验最近接近点当同一阈值。FM97-4（PDF11–12隧穿原claim）、MU07-D24-002、主map“近似阶次练习”已有该边界。

2. **135Nd两partner总寿命不同，是否直接反证其带内B相近？**

不能。τ⁻¹为该母态所有衰变出口的总率；指定成分的B还含该支的辐射份额和Eγ^(2L+1)，两带的全网络/能量不同。主map I31/2−打印τA=.75(8)、τB=1.46(2) ps，而B(E2)A=.32(3)、B=.28(3) e²b²，中央τB/τA≈1.947、B_E2B/A=.875能同时成立。这些来自同一实验派生链，不作为两次新证据；没有完整BR/ICC/Cov，不给显著性或独立误差乘积。

3. **134Pr长文是否已经唯一证明了形状涨落，否定一切静态手征/形状共存？**

没有。TO07-D24-004/005/006/009/010的TQPTR能谱/交叉支持而EM失配，IBFFM主要EM支持而能隙/I15 crossing和部分率失败；后者当前数据参与H/EM定标、部分模型赋名也用EM。β/γ概率为模型分布，作者保留未揭示内禀对称性；I>16的原2qp空间失效是作者配置解释。不能把同一数据用于选态又作独立holdout，不能将两个论文计成两独立采集，不能用此核参数给135Nd/133Ce补输入。

4. **伙伴g未知是否能从纯j、内禀gK或128Cs bandhead补齐？**

不能。135Nd所读MU07未给逐partner g，写unknown。纯j或渐近gK是指定极限，三轴混合态没有无条件唯一good-K标签；需实际态/算符/单位及相应磁矩或g预测/测量身份。128Cs g与高spin寿命的母态/采集不同，更不能跨核搬值。按标准定义，B由相干态与正确算符归一下的RME模平方乘初态统计因子1/(2Ii+1)给出（如WK22 Eq3.21/PDF48），不把B直接等同裸RME平方；δ符号进一步要E2/M1相对相位，不把gK定义成跨态signed RME。

5. **133Ce当前最容易把哪个能差/光子线误当同母分母或互链？**

1409.8−592.1=817.7 keV只是候选能差，没有可确认同母out E2 reference；历史817.3已观测未指认线不能绑定它。正宇称另有两个13/2+：1459.9与1445.8差14.1；Table5.4的412.4和767.7均来自1445.8，分别到Band2 1033.4/11/2+与678.1/9/2+，不是两13/2+各发一条。没有原门/实际producer就不造强度/上限或混合矩阵元、ωc。WK22-20/34/44/46为canonical定位。
