# Day24源后理解校核（非盲测，不评分）

这是一轮已经完整读过主线和Wiki后的整合短答，受到本日source与034提示的priming；不称独立考试或开源前active recall。只检查现有物理联系，不制造新测量或课程信用。长期知识仍在[[135nd-chiral-partner-resolved-evidence-map]]；下列答案随后按列出的既有原件定位核对。

1. **三根角动量与本核对象。** 理想图像是高j粒子、空穴和转子分别偏短轴、长轴和中轴，三者非共面时可组成两种手性。在135Nd的负宇称三qp解释中，两个h11/2质子共同贡献粒子侧，一h11/2中子空穴贡献空穴侧，再加core R；三qp不是必须画成三根互不重叠的单核子箭头。Pauli耦合、实际取向随spin变化及总I=R+jπ+jν均属具体模型。能谱、τ/分支和由此提取的B是实验输入；三根精确方向不是本实验直接摄影或模型无关测量。FM97结论还说明高j三分量只是实现手征TAC的一种机制，不能倒置为所有候选普适硬门。

2. **有限体系static与左右平均。** 经典aplanar左右极小、量子能量本征态、局域wavepacket是不同对象。对本日声明的反射对称一维模型，非简并偶/奇本征态的φ奇量均值为0，仍可有双峰密度和小但有限隧穿劈裂；将两态相干组合才可形成一时局域packet并随相对phase演化。不能把此模型反射直接叫实核antiunitary C本征值，也不能把单态RMS分量当有符号手性测量。“更static”的有限核解释不等于永远只留一手、严格零gap或任意更高spin都更static；Qi/集体模型有有限窗口及高spin转回其它动力学。

3. **五种起始/阈值。** 固定gyro经典onset是指定惯量和角动量输入下均匀转动分岔；TAC meanfield双解是其实际变分空间的对称破缺；RPA零频是局部二阶近似软化且临界附近谐展开失效；有限量子双带gap还含隧穿与其它关联；实验最近接近点只是已观测带谱的事实。五者可在具体模型中联系，不能相互改名。MU07的39/2−附近行为可以支持作者转变解释，但不是实验独立测出一个普适静态临界spin。OL02的.514639MeV更不是135Nd的实测阈值。

4. **τ差与B近合不矛盾。** 总寿命决定所有退激渠道的总率，指定B(XL)经Eγ^(2L+1)、photonbranch及ICC才接到它。相同B的不同能量/出口网络可有不同τ；MU07 TableI中A/B的τ在一段相差约两倍而published带内B近合，是实质支持与网络差别并存。由publishedB/τ逆算一个组合因子只是代数条件，不能恢复唯一逐门Iγ、所有未见branch、混合分量δ或jointCov；原normalizer缺口不抹掉原论文已报告B支持。

5. **同I、共同ω及共享曲线。** EB(I)−EA(I)在同I比较；共同ω的routhian差在两条E′=E−ωJ上比较，所对应J未必相同，须按Legendre及各模型spin约定映回。AL11 Fig3明确用共同ω插值量，不能拿来无条件替同I gap。MU07近谐0/1声子共享TAC基态给相同带内EM基线是该阶近似的结构，不是两份独立模型验证；实验两partner各自的τ及其派生B仍提供真实支持；所报告带内B在误差内相近不要求总τ相近，不能因共享理论曲线将实验支持一并否定。

6. **四替代路线与伴随量的量词。** crossing可在邻核PE06分析中造成局部近合/混合，但未执行四套135Nd替代fit；AL11 RPA模交叉也不同于实验组态crossing。configuration纯relabel没有新预测，同H空间的state mapping须过Jπ/全links，增加原空间未含的qp组态或换shape/定标则改变模型；在原有空间内多取一个本征态本身不等新增空间。MU07最低模小γ混入不测出完整γ分布；CH16的θ/φ取向softness不是γ形状softness。bandmixing可在PE06假设内重分配EM，但当前135Nd没有全signed闭块/独立混合模型胜负。能改变判断的是本核跨段逐态/组态连续性、可绑定absoluteEM/分支及冻结输入的可分辨预报；现有缺口依旧unknown。128Cs低spin isomer的g属于不同核/态/clock，不能填135Nd两partner g；独立g若实际可测且预测可分可增加约束，却不是每个模式的普适必需终判。
