## 原件 δ 链条：shared α2、非单值反演和形状推断前提

PDF4的通式为`W(θ)=1+Σ[k≥2] αk(Ii) Amax_k(Ii,L1,L2,If) Pk(cosθ)`；**§4实际忽A4**，只选wellresolved/statisticsgood的A2exp。delayedlines在137Nd/135Ce的11/2isomer之下取αk=0作isotropiccheck，不是133Ce所有prompt态都无alignment。α2从已认定pureE2的bandtransitions相对fullyaligned(Yamazaki)理论值求；作者未见spintrend，故按核平均来降低scatter。

Fig11针对**170.0(11/2→9/2)、384.7(13/2→11/2)**：solidcurve是complete-alignment理论A2，hatched区域是实验A2经attenuation修正。横轴是`x=|δ|/(1+|δ|)`，**不是E2fraction**；正负branch分开，negativebranch非单调，同A2通常可对应不同|δ|。粗略负δ及“(50±25)%E2”是本AD模型下的作者总括，未附逐lineδ表/likelihood/Cov、不能当逐线68%CI或固定ratefraction。采用通常photonradiation定义时`fE2=δ²/(1+δ²)`，所以x=.5才对应|δ|1和f=.5；一般x≠f。这个定义识别不等本任务新fit。

后续prolate论证再加**rotationalband formula**：

\[
\operatorname{sign}\delta=\operatorname{sign}\frac{g-g_R}{Q_0},\qquad K\ne\tfrac12.
\]

放大已核原字：Nakai规则说g−gR对oddproton正、oddneutron负，**provided I≥7/2**（不是I≥j）。作者由这些oddneutronbands负δ推Q0>0→prolate。这里未直接测每态g或Q0，也未测γrigidity/handedness；rotationalformula/g规则/K域/ADassumptions都须保。不能将这个historicalband-sign推理用于现代跨带三线，或据负δ直接认证wobbling、chirality、静态三轴。
