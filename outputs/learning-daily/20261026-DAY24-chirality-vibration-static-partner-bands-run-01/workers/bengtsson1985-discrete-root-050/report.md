## 130Ce的优先核查：不是133Ce的3qp输入

physicalPDF60–61/printed73–74，§8.4/Fig30，实验Refs63/77为当年到32+（负到30−）的谱。模型在I10–22有ε约.25的nearprolate/γsoft路线，I15–40中另有ε.35/γ0极小，后者约I25变yrast。这些是nonpaired模型的竞争极小，不是实验直接测了两个刚性形状。

已观测的prolate Eγ可由**继续保持ε约.25组态**的thinbranches符合到高spin；理论globalyrast换到ε.35后画出的主曲线与实测discrete路不相同。正宇称源解释为πh11²，负宇称为再从Nrot4提升一个质子到第三h11 orbital；这是130Ce特定configuration，不迁给WK22的133Ce低spinν1qp。负/正family各spin/links不能只按Ce核名合并。

source在(+0)calc/exp都见I28 backbend，归因填neutron h9/2–f7/2([5411/2])轨道；(-0)exp到I30而calcbackbend在I32，不能写成双方相同spin都验证。J2尤其正带不佳，作者留alignment过程可能不同。continuum的J_band^(2)约52ℏ²/MeV（ℏω>.62），discrete(+0)约45：作者由此**推断**cascade可能相当部分经过moredeformedbands，明确希望观测到这些带内transitions。不能把这个continuum inference转为已resolved的ε.35band，更不是实际133Ce独立clock/shape测量。不可移植52/45作为本核Harris。

## 非配对系统的一般图像及量词
