### 两带混合正交不变量定理与奇异值手征判据

物理本征跃迁矩阵 $M_{fi} = R_f^T Q_{fi} R_i$ 无论初末态混合角 $\theta_i, \theta_f$ 是否相同，均恒等满足以下正交变换代数守恒律：
1. **Frobenius 范数守恒（总四极强度守恒）**：$|M_{fi}|_F^2 = \text{Tr}(M_{fi}^T M_{fi}) = \text{Tr}(Q_{fi}^T Q_{fi}) = q_1^2 + q_2^2 + 2q_{12}^2$。态混合仅在两带内与两跨带通道间重分配跃迁几率，总四极集体性不变；
2. **绝对行列式守恒**：$|\det M_{fi}| = |q_1 q_2 - q_{12}^2|$；
3. **奇异值谱守恒与手征退化判据**：在完整2×2跃迁幅度矩阵、相位、响应和归一化合同均闭合且正交混合模型适用时，$\sigma_k(M_{fi}) \equiv \sigma_k(Q_{fi})$；分裂奇异值说明该理想等形变假设或选定子空间失配，仍需独立结构观测量判断形状共存。

### 概率密度映射法（PDM）提取多极混合比的测度守恒与基准对账

吸收 raw/writing/pado/（Chen et al., 2026）手稿，建立无预设自旋取向度 $\sigma/I$ 提取 $\delta(E2/M1)$ 的概率密度映射法（PDM / P-ADO）：
1. **紧致角坐标与微元测度守恒**：定义 $\xi = \arctan\delta \in (-90^\circ, +90^\circ)$ 消除纯 $E2$ 极限发散；雅可比行列式 $J(\xi, \sigma/I) = \det [\partial(R_{\rm ADO}, P)/\partial(\xi, \sigma/I)]$ 满足微元面积变换 $dA_{\mathcal{O}} = |J|\, dA_{\mathcal{P}}$，未归一条件映射密度为 $f_{\mathcal{P}}(\xi, \sigma/I) = f_{\mathcal{O}}[F(\xi, \sigma/I)] \cdot |J|$；
2. **Outside 构型与全局折叠双解**：各向同性点 $\mathbf{o}_0 = (1, 0)$ 位于响应曲线外部时，曲面在投影面发生全局折叠，同一对测量值 $(R_{\rm ADO}, P)$ 产生两组独立物理参数解分支；对 $\sigma/I$ 连续边缘化积分后提取 68% HDI，多峰时分别报告各分支概率质量；
3. **多核基准与模式裁决**：PDM给出的是依赖响应函数、测度、对齐域与权重及误差模型的条件密度；原稿只报告多数区间包含文献值，并非八条全部严格重叠。$^{187}\text{Au}$与$^{135}\text{Pr}$结果支持小负、M1主导分支并强烈抑制E2主导解释，但不单凭PDM确立带身份；带内比值仍须结合 $1/(1+\delta^2)$ 因子。

   - 辐射混合比 $\delta$ 与约化矩阵元比值转换需经由 Paul 1991 的 $0.835 E_\gamma$ 因子（平方为 $0.697 E_\gamma^2 \approx 0.7 E_\gamma^2$），代码采用 Yamazaki (1967) 相位规范；WK22 正文称 582.7 keV 具有“~30% E2”系 $\delta^2 = 0.3025$ 误写作份额，真实光子份额为 $23.225\%$；
   - 高自旋跃迁在大 $|\delta| > 5$ 纯 E2 渐近区存在局部 $\det J = 0$ 奇异曲面，证伪手稿普适非零 Jacobian 断言；但在实验解 $\delta = -0.55$ 处正则可逆；
   - AFRODITE 阵列几何（$45^\circ/90^\circ/135^\circ$）与 P-ADO 硬编码（$26^\circ/90^\circ$）失配，$^{133}\text{Ce}$ 缺乏线偏振度 $P$ 测量，且下游 YAnalysis.py:98 的 np.trapz 在 NumPy 2.5.3 下失效；
   - 582.7 keV out/out 分母 817.7 keV 在 Table 5.2 与能级纲图中完全缺失，名义反演产额自相矛盾（1.19 vs 0.88），保持未闭合。

### 133Ce Band 4 跨带混合比自旋演化与 E2/M1 份额急剧猝灭（checkpoint015）

对 WK22 Table 5.2 与 Table 6.11 中三条跨带连接线开展定量多极混合比演化分析（脚本与结果见 ce133-mixing-ratio-evolution-015.py/json）：
1. **624.6 keV（13/2- -> 11/2-）**：$\delta = -1.5_{-5.7}^{+0.97}$，$\delta^2 = 2.25$，导出光子份额 $f_{E2} = 69.231\%$、$f_{M1} = 30.769\%$。若粗糙假设 $\delta=0$，提取的 $B(M1)/B(E2)$ 比值将被虚假高估 $+225.0\%$；
2. **582.7 keV（17/2- -> 15/2-）**：$\delta = -0.55_{-0.25}^{+0.12}$，$\delta^2 = 0.3025$，导出光子份额 $f_{E2} = 23.225\%$、$f_{M1} = 76.775\%$，修正因子 $1/(1+\delta^2) = 0.76775$（$\delta=0$ 假设高估 $+30.25\%$）；
3. **464.4 keV（19/2- -> 17/2-）**：$\delta = -0.17_{-0.20}^{+0.09}$，$\delta^2 = 0.0289$，导出光子份额 $f_{E2} = 2.809\%$、$f_{M1} = 97.191\%$，修正因子 $0.97191$（$\delta=0$ 假设仅高估 $+2.89\%$）；
4. **物理演化机制与集体性解耦**：从 13/2- 到 19/2-，跨带跃迁由 E2 占主导（69.2%）急剧转变为几乎纯 M1 跃迁（97.2%）。这在微观上证实了三轴粒子-转子模型中随着自旋增加，核芯转动角动量 $R$ 单调增大，推动总角动量向转轴对齐，波函数重叠迅速收缩并猝灭了跨带集体电四极矩阵元，而单粒子横向磁偶极矩算符 $\vec{\mu} \propto (g_j - g_R)\vec{j}$ 保持主导。这一急剧猝灭特征排他性排除了全带保持 E2 占优（$|\delta| \gg 1$）的三轴摆动（wobbling）模式，有力支撑了单粒子倾斜进动（TiP）轨道激发图景；
5. **对同位素 131Ce 假设的约束**：Alwaleedi 2013 在分析 $^{131}\text{Ce}$ 负宇称带时普遍假定 $\delta = 0$；若带入同位素测得的真实混合比 $\delta \in [-0.55, -0.17]$，其提取的 $B(M1)/B(E2)$ 实验曲线将向下平移 $23.2\% \sim 2.8\%$，显著缩减实验与 Dönau-Frauendorf 半经典模型之间的系统偏差，无需人为引入过大的科里奥利衰减。

最小组合按具体问题选取：身份/响应→匹配absoluteEM尺度→固定空间/参数的可失败预报→有分离预报的独立结构holdout。缺身份则暂缓对应matched比较；缺clock且无其它绝对约束则只得relativeEM；缺BR/ICC/response则复算仍条件化；缺独立holdout则保留等效解释。g/Qs只是可选互补量，完整组合也不保证唯一模式。

此外，Heyde & Wood 2011的两态混合公式表明，$E0$ 对混合与电荷分布差异敏感；非零 $E0$ 可证明存在非零单极矩阵元及相应电荷分布差异，但不能单凭此量唯一分解混合角、形状共存与其它组态效应。$g$因子仍需结合具体模型和自旋窗口解释。
