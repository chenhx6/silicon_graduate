## 3. 维度一：过强量词与推断边界深度审计

在 companion matrix 与关联 source 页面中，审计识别并纠正了以下可能出现的过度量词风险：

### 134Pr：区分“解混合参数容许区间”与“直接实验形变测量”
- **过强量词风险**：将 PE06 中 $Q_{0,1}/Q_{0,2} = 2.0(4)$ 宣称为“实验测得两带核形变相差两倍”，或宣称“彻底证伪了 134Pr 的手征性并证实了刚性形状共存”。
- **原件 locator 事实**：PE06（printed 112502-2–3）明确该比值是在假定**非对角 E2 矩阵元严格为零（$q_{12}=0$）**以及两自旋态相互作用常数 $V \approx 14–17$ keV 保持不变的前提下反演出的两能级模型参数容许区间（1.6–2.4）。作者在结论（printed 112502-4）中使用的词句是审慎的提问（"The question arises if and to what extent a reminiscence of the chiral geometry is present"），并强调所用跃迁矩并不建立在刚性形状假设之上；Tonev06/07 则提出 IBFFM 形状涨落下的“动态手征”。
- **审计裁决**：禁止使用“实测形变两倍”或“排他性证伪手征”，必须表述为“在无非对角 E2 的简化解混合模型下，两带内禀跃迁四极矩比值的容许区间为 1.6–2.4，对理想静态手征伙伴图像构成实质反证”。

### 135Nd：严防跨宇称组态的“证据偷换”与全核全称量词
- **过强量词风险**：使用“135Nd 成功证实多重手征双重带（M$\chi$D）”等全称肯定句，将负宇称 D5/D6 的电磁对称性转移或借调给正宇称 D3/D4。
- **原件 locator 事实**：LV19 原文（arXiv PDF p. 5, Figs. 5–6）表明，正宇称候选手征对 D3/D4 **完全没有任何能级寿命测量，也缺乏绝对 $B(E2)$ 与 $B(M1)$ 强度**；整条 D4 带甚至没有测出任何带内/带间分支比，D3 也仅有一个单点比值（$I=29/2\hbar$）。此外，Table I 存在 334.4 keV 线宇称标记残余异常（$27/2^- \to 25/2^+$）及 D2 行 30 keV 闭合差。
- **审计裁决**：正宇称 D3/D4 必须降级定性为“缺乏态寿命及伙伴相对比值的谱学候选对”；绝对不能将 MU07 负宇称对的寿命实验证据借调给正宇称对。

### 136Nd：杜绝“非共面模型解”与“相对比值实验”的跨对嫁接
- **过强量词风险**：将 PE18 中 D5/D5-chiral 的两带对称实验比值与负宇称 D3 的 3D TAC 非共面偏转解（$\phi > 0$）拼接，声称“136Nd 全面证实了偶偶核三维非共面手征旋转”；或反向使用 MU08 宣称“彻底推翻了 136Nd 的所有手征带”。
- **原件 locator 事实**：PE18 识别的 5 对带中，**仅有正宇称六准粒子带 D5/D5-chiral（组态 C）**在双带内均测得了重合的 $B(M1)/B(E2)$ 实验比值（Fig. 3）；但 PE18 的 3D TAC-CDFT 显式非共面解（$\phi > 0$）**仅针对负宇称组态 $D^*$（对应 D3）进行展示**（Fig. 6），并未计算 D5 的 3D 偏转角！其余 4 对弱伙伴带缺乏带内比值测量。MU08 测量的 Band 1 与 Band 2 对应后来的负宇称主带 D4 与 D3，其 $B(E2)$ 巨大差异直接推翻的是 D4 与 D3 互为手征对的旧假设，并不直接覆盖 D5/D5-C 或 D3/D3-C。
- **审计裁决**：严禁跨对证据拼接。D5 拥有实验相对比值对称性，但缺态寿命与 3D 非共面模型计算；D3 拥有 3D TAC 非共面解，但其伙伴 D3-C 缺乏实验比值。MU08 是旧主带假设的反证，不是全核手征的整体证伪。

## 4. 维度二：共享实验依赖与伪重复验证网络解构

跨核综合与系统学比对中最易出现的科学陷阱是将同一次实验束流、同一套探测阵列或相互引用的谱学分析误当成多次“独立实验验证”。本审计全面梳理并固化了三大同源实验池谱系：

```
                              [高自旋手征实验同源依赖网络]

    |                                      |                                      |
[Vivitron Euroball IV]            [JYFL JUROGAM II 152 MeV]            [Gammasphere 175 MeV]

    |                                      |                                      |
    +---> Tonev 2006 (PRL 短报)            +---> 136Nd (4n): PE18 PRC(R) 2018     +---> 135Nd (5n): MU07 PRL 2007

          (非独立实验!)                    +---> 136Pr (1p3n): LV25 PRC 2025      |     (MU07 图上无光子能量)
                                                 (同实验池, 见LV25 Sec.II)
```

1. **Vivitron Euroball IV 134Pr 依赖池**：Tonev 2006 与 Tonev 2007 是完全相同的实验采集与线形分析；PE06 的寿命输入直接引自 Tonev 2006（Ref. [9]）。在伴随矩阵中，三者只能计为**一次实验测量加一次唯象分析**，不得计作三次独立证据。
2. **JYFL JUROGAM II 152 MeV 依赖池**：LV19（$^{135}\text{Nd}$ 5n 道）、PE18（$^{136}\text{Nd}$ 4n 道）、吕冰峰 2019 博士论文以及 LV25（$^{136}\text{Pr}$ 1p3n 道）全部源自 JYFL 的同一次运行，共享 $5.1 \times 10^{10}$ 符合事件池、探测器效率曲线与能量标定。在跨核比对中，它们属于**同次 campaign 下的不同反应道分支**，其系统误差高度相关，绝非跨实验室或跨周期的独立验证。
3. **Gammasphere 175 MeV 依赖池**：MU07（$^{135}\text{Nd}$）与 MU08（$^{136}\text{Nd}$）使用相同的 175 MeV 束流能量、相同的靶与背衬条件、相同的 SRIM 阻止本领与 LINESHAPE 拟合框架。不能将它们作为独立的阻止本领系统误差控制组。
4. **Zhu 2003 纲图继承性**：MU07 图 2 与图 3 的带间跃迁数据点依赖 Zhu 2003（Ref. [8]）建立的纲图结构；MU07 本身未打印带间光子能量，其跃迁指认属于继承性推断。

## 5. 维度三：缺失反证与竞争物理机制检视

审计核实，在以往的讨论中，部分关键竞争物理机制与模型反证未得到充分展示，必须在矩阵中完整补全：

### 134Pr：非对角 E2 干涉与竞争模型双重受挫
- **非对角 E2 干涉敏感性**：PE06 假设两带原始基底之间无非对角跃迁矩（$q_{12}=0$）。若引入有限的非对角元 $q_{12} \ne 0$，其与对角跃迁矩产生量子力学干涉。前向检验计算表明，在适当的相对相位下，即使对角本征四极矩完全相等（$q_1 \approx q_2$），干涉效应也能重现分支比的不对称性。这证明 PE06 的 $Q_0$ 比两倍结论具有强烈的模型假设依赖性，不能排他性地证明两带内禀形变必须不同。
- **IBFFM 与 TQPTR 模型双重受挫**：Tonev 2007（PRC 76, 044313, Sec. V-F）诚实指出了现有理论的两难困境：
  1. 考虑核形状涨落的 IBFFM 模型能够很好地再现带内 $B(E2)$ 2–3 倍不对称和平滑的 $B(M1)$，但它严重高估了带间能隙，并且完全无法重现实验在 $I=15$ 处观察到的锐能带交叉；
  2. 刚性三轴 TQPTR 模型能够很好地重现能谱走势与 $I=15$ 交叉，但在跃迁强度上严重失配。
  这一反证表明：134Pr 既不能简单归为刚性三轴手征，也不能认为形状涨落模型已经完满解决了问题；机制依然开放。

### 135Nd：寿命不对称补偿与低自旋倾斜进动竞争
- **寿命不对称 vs 跃迁几率对称的反常补偿**：MU07 Table I 记录的物理事实显示，在自旋 $31/2^- - 37/2^-$ 区间，Band B 的寿命系统性地比 Band A 长约 2 倍（$\tau_B \approx 2\tau_A$），但两者的带内 $B(E2)$ 却高度对称（$0.28$ vs $0.32$ $e^2b^2$）。这意味着必须由全退激网络中的偏率因子（$\Gamma_\gamma \propto E_\gamma^5 B(E2)$）以及分支比产生精确的 2 倍补偿。这一反常的补偿机制不能直接等同于“理想手征对称性”，必须作为重要的物理约束保留。
- **低自旋倾斜进动（TiP）竞争解释**：针对 $^{135}\text{Nd}$ 的负宇称带，Lawrie 2020（PLB 811, 135795）与 Lv 2021（PRC 103, 044308）提出倾斜进动（Tilted Precession, TiP）模型，成功解释了低自旋区 M1 主导的 $\Delta I=1$ 序列。这说明在该质量区低自旋段，单准粒子进动是极具竞争力的替代解释，不能先验地将所有同宇称近简并带都假定为手征振动。

### 136Nd：高自旋回弯能带交叉与多准粒子重组
- **多准粒子能带交叉竞争**：PE18 明确指出，D2、D3、D4 在高自旋端均出现回弯（backbend），且 TAC-CDFT 无法再现回弯处的比值急剧上升。作者将其归因于未包含在固定组态模型中的 8-qp、6-qp 和 6-qp 能带交叉。这表明近简并现象很有可能源自多准粒子组态交叉排斥，而非纯粹的核芯取向手征对称性自发破缺。
- **MU08 对旧主带伙伴假设的直接证伪**：MU08 测得的 Band 1 与 Band 2（对应后来 PE18 中的 D4 与 D3 主带）具有极其显著的 $B(E2)$ 差异（0.26 vs 0.51 $e^2b^2$）和 $Q_t$ 差异（1.73 vs 2.42 $eb$）。这构成了对早期将这两条主带指认为手征伙伴带的直接证伪事实。
