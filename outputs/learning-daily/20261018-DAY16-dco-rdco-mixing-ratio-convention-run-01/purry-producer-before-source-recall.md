# Purry producer原件：来源前回忆

本session已读1998Pu01的NSR/Crossref、S2/OpenAlex元数据及2009ENSDF转述；1998paper 46页与1997thesis均未取得/打开。此记录明确受评价数值和既有研究priming，不是盲测。

回忆问题：reported alphaKexp必须对应同一921-keV branch，K-electron与photopeak的效率、角接受、背景、门/分峰和归一recipe决定它如何与BrIcc angle-integrated alphaK比较。1090 pureE2同母态是candidate reference，但不能因为它同在表里就认定它是原实验calibrator。原alphaKexp是否已使用某套理论表或某条E2 reference归一，决定theory/experiment误差是否独立。

原件获取后先核实验装置、electron spectrometer/能量校准、source/beam与selected-event cuts、K-shell辨认、gamma normalization、table value/units/error和competing assignment；读清作者如何使用AD/ce/DCO及哪些Jpi或mixing结论为假设。若原件仍未给recipe，就保持缺口，不能从评价标签补出Counts/Cov或独立校准。

1995PRL/1997thesis/1998paper若重用同一80MeV CAESAR实验，按依赖谱系，不计三次独立实验。1999Cullen Gammasphere对象另核采集与共享reference；年份/引用次数/多种处理本身不证明独立。公开存储库/合法全文获取是下一路线；返回metadata、验证页或下载失败都不称已读原件，不绕过访问控制。
