# Fagg–Hanna1959 开原件前回忆与问题

本次是带priming的旧source复读：Wiki入口/本sessionrg已显示Fagg-Hanna题名、DOI和历史桥梁摘要，SU59/B15也都引用该综述；已读大量现代DCO/PDCO/Stokes合同。不是独立盲测。

1. 要区分electricvector相对反应平面/法线、两个散射plane、gamma1/gamma2、emission/absorption；相同P/x/δ名字不足以同号替换。SU59normal轴已被原件明确，不能假定FH59自动同轴。
2. Pureelectric和puremagnetic的偏振符号依spinsequence/布居，不能用electricpositive口号，必须找原件具体例和counterexample。
3. Comptonp/response与计数asymmetry为不同层，threshold、finiteangle、pairproduction与多scatter能使magnitude下降；unpolarizednull只检某些偏置，不提供绝对p。
4. 核取向、P(m)、混合multipole的phase及独立companion要看原式/表。暂不回忆任何实际FH59 equation/table编号或numericalresult，防止把现代公式误归作者。
5. 完整读review mainline，逐项区分作者理论/转述旧实验/本文推断；若只二手转述BR定义，不当BR原件已读，也不新增独立实验。明确未取原producer/rawCov。
