# Jones2002 calibration：原件前主动回忆

当前受Day15 JO95/Day16 SG98/Morse/L25/L26与Co60源模型priming，不是盲测。已知P为光子态、A为instrumentalcut后的调制、Q取决于响应和定义。纯4→2→0且point偏振等效率reference的P90=1/6是声明模型极限；不能因此声称实际tagger/cascade geometry全符合这个数。绝对calibration可能依赖独立knownpolarization、有限门/散射角积分或reaction分布，原Jones2002采取哪种路线尚未知。

需要读原mainline：如何制备reference，target/gate/θ/ψ/归一和counterterms；是否同时拟P与Q、引用何种原测量；source/samplegeometry与beamresponse如何关联；报告统计/系统与未给Cov；对纯极限/选择/背景/多scatter有何反证。原数值、图表、装置不从记忆补。若原件获取失败只记readiness，不重复用Co60更多toy替代。该条仅Day17无学分知识预习，正式仍Day16。
