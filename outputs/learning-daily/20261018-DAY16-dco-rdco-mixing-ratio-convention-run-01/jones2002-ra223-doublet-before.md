# 223Ra Table1的同能标线：补充问题冻结

Jones2002 Table1视觉确认两条314.78：母态376.28的7/2−→7/2+给理论P90=−.94；母态445.00的9/2+→9/2+、M1标签给+.96。不能只靠Eγ匹配sourcecalibration，需alpha能门/母态和response；表里的两项a2实验.52(.04)/.34(.09)、理论同.48而P同幅异号，不是同条gamma的新两测量。尚未打开1998原实验或当前223RaENSDF验证，不把两个printedenergy误当新resolveddoubletmeasurement。

可做声明设计：若两分量同response且权重为接受后光子数，Stokes相加给P_eff=f*(−.94)+(1−f)*.96；求zero点与污染偏差，不能把来源a2系数/谱强度直接作这些权重，也不认证未知actualQ。下一需原α能门/response/gamma分离与dataset谱系，若未得只保留matchingboundary。
