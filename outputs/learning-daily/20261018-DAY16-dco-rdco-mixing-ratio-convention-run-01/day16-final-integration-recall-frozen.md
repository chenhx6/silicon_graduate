1. **δ与百分比。** 在这里的real radiative E2/M1坐标，E2辐射份额为δ²/(1+δ²)，但符号与相干项不能从份额读出。新D66点约99.04%E2仍有显著二阶干涉；不能据强度dominant把P当pureE2，也不能把δ直接当B(E2)/B(M1)。

2. **DCO数据身份。** 必须给target、reference/gate、两个角组、计数/效率/归一、background、spin路径、alignment/feeding和响应/Σ。交换同一条件下两个角位置可出现倒数；换了gate transition或reference spin就不是同一交换。纯E2门也不使某个R阈值成为普适spin判据。本日178W921原角组和两个R数值我此刻不凭记忆填，须回已交付worksheet再引用。

3. **相位约定。** emission/absorption标签、初/终态左右顺序、EM operator和RME归一、Lprime/L顺序、first-B/last-A角色要一起固定。KS定义下第一光子的B和后光子的A有不同线性干涉号；BR1953不是Rose–Brink1967。已检查的相邻L source桥可有δ翻号，但核也须同步变换，物理observable保持。δ0/∞端点没有干涉，不能单独查出错phase。

4. **P、degree、A、Q、a。** 物理平面上的signedP是选定Stokes分量/强度，sqrt(Qs²+Us²)/I是非负degree；两者不能互换。detectorcount asymmetry A或Δ需要几何校正a(E)，再用匹配的polarimeterQ转换。核发射θγ90相对beam，ComptonθC90相对入射光，不是同一角。M=εQ²丢失Q号，不能校准handedness。

5. **取向转移。** nonnegative CG²/column-stochastic map可以给负U，负tensor不是负population。C96 literal U正范围不能当任意spin/j恒等式；一般absU≤1。我们证的rank2保号充分域是Ji/Jf≥5/2、L1/2且完整未观测；方向门/大j/低spin/外场都需另核。u2、μ2、statistical B2/U2及alpha=p/B归一不同，不能用同字母直接移植。

6. **回到实验前提。** Rh99 sourceAD/P的任意正q box有两EMfamily条件解，lowm额外条件才可能排same-parity分支。该条件并未由本run测得；sameparent reference还要已知阶次混合、同trigger/gate/feeding与response，列出一条同母态线并不等于测出了u2。P00反应用110MeV31P+74Ge，1994Ref8才16O+89Y，不能混淆。

7. **网格与连续域。** exactcentral可有孤立根，grid0不能排除；有误差的marginalbox也不是jointCI。D66新11/11点是实际粗网格漏解，后来九free/三lowm属于声明模型的数值覆盖，不是199Tl实验允许spin数。16个负子问题/23叶及MP80余量支持数值必要域，不写formalexactreal证明或原19→5重放。
