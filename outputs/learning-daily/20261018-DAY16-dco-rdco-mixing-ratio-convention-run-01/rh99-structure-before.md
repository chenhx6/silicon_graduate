# Rh99同母态reference：来源前主动回忆（明确primed）

原P00主线、表中1117和刚发布freeq/lowm分析已暴露，旧交接指向Ref8 RaviKumar1994；此处不是盲测。未打开该原件或其完整摘要。

1. 当前要证的是同一发射态的u2符号，而非其它核素或其它自旋的一条正a2。原1117的Ji23/2、Jf21/2仅来自P00；记忆里3710母态尚待原结构图核。
2. 同母态reference须已知multipolarity，且有相容的trigger/gate/feeding/取向对象与实际响应。相近能量、同band或参考线校准Q都不足。
3. 轴对称对称正q并不自动满足lowm条件；fusion名称不能证明二阶矩符号。一般Gaussian宽度假设也不等于独立测量。已算的centralM1E2witness均方m约75.85，违反47.92条件。
4. 若同母态无已知purebranch，原能级研究仍可确定所缺reference为何不可得；若有，也先核a2/角组/门。不能把daughter的branch直接当parent布居。
5. 文献结构归属、DCO/AD、模型组态和编译adopted需分层。1994与2000采集是否相同未知；引用链本身不算独立实验。
6. 可推翻当前设计的结果包括：parent身份错误、reference显著混合且未知delta、gate改变条件密度、只给无门/其它态AD、u2符号不确定。遇这些不调Gaussian或Q补齐，只写readiness与更合适companion。
