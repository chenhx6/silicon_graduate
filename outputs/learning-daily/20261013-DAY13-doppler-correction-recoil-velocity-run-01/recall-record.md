# Day 13 来源前主动回忆

回忆时间：2026-10-13T17:18:59.579761+08:00（Asia/Shanghai）。本轮尚未打开 Doppler method 或 Mavela 原文；上轮 Day11 的 Day13 预习已经学习过本主题，当前恢复摘要再次提示了9%/7%和 Appendix C 的输入问题，因此这是 primed recall，不能记作第一次盲学。

1. 运动中的发射核使光子实验室能量依赖 v 与观测方向。若 θ 为实验室 γ 方向与核速度夹角，记忆公式为 E_lab=E_0/[γ(1−β cosθ)]；反演 E_0=E_lab γ(1−β cosθ)。前向蓝移、后向红移，90°一阶速度项消失但二阶相对论项仍在。
2. θ 应是反冲速度与从发射点到探测器交互点的夹角，不能总用探测器相对束轴的名义角；散射/蒸发反冲和顶点分布会让两者不同。
3. event-by-event correction 需要 γ 能量、γ 位置、发射点以及同事件反冲方向/速度估计；粒子击中位置提供方向约束，单有 S3 ring 不保证已测得完整 β 或协方差。
4. 停止介质使 v=v(t)；τ 与 stopping time 相比决定 shifted/unshifted 分量。固定 β 不能将不同发射时刻统一成一个峰，DSAM/RDDS 利用这种分量/线形，而直接校正只为恢复静止系能量。
5. δE/E 在低速一阶约为 cosθ δβ−β sinθ δθ；需推导精确式、角度用 rad，并区分随机 spread 和整体系统偏差。90°角度误差最敏感，不代表最佳总分辨率。
6. 宽峰可能是未校正速度/角度、停止分布、相邻未分辨跃迁或本征响应；窄峰不证明速度输入正确。须比较各角环、同核多条已知线、不同门及停止/校准对照。
7. 未确定：作者约7%使用的 stage、ring20列值是排印还是生产代码、S3 坐标变换，以及两个源是否复用同一数据。来源核验将保留这些边界。

预定练习：E_0=1000 keV、β=0.07、θ=35/90/145°、σβ=0.002、σθ=2°，推导精确Jacobian并用独立有限差分检验；所有数值是自设练习，不当作实验测值。
