# DAY13：有限 bin 与共享误差的设计前回忆

日期：2026-10-14；原 run/session 继续。这是已读 Baker–Cousins 和既有线形练习后的 primed recall，在重新检查原文 locator、实现本轮练习前保存；不是独立盲测。

- Histogram 的预测是 bin 内的期望计数或条件概率。即使连续密度正确，中心值乘宽度也只是积分近似，窄峰、宽 bin、非均匀 bin 或截断 ROI 会使它失效。
- 同一事件重分 bin 不产生独立数据。细 bin 相加应与对应粗 bin 的积分一致；它可检验实现的一致性，但统计信息通常会减少。
- ROI 内归一化得到条件谱。改变 ROI 会改变入选分母，若保留入选数固定的模型，应对预测和真值都条件化；若利用流失计数，则需另建 extended likelihood 和效率项。
- 对同一个 sideband 估计量 B，用于多个投影的减法会使协方差出现非对角项。把背景扣除后的计数直接当成独立 Poisson 数据，还忽略了减法允许负数这一点。
- 有限模板来自同一批模拟事件时，bin 概率的归一化约束、参数扫描点的共同事件和重加权会产生协方差。共用随机数可减少相邻模板之差的噪声，同时使它们相关。
- 可用反证：无减速或长寿命极限下应退化为单 Gaussian；零 bin 宽极限应恢复积分；背景样本变无限大时应消失其贡献；事件相互独立且无共享归一化时不能凭空添加交叉项。

本轮验收：以既有合成 Doppler 核为输入，检查积分/中点、细到粗 bin 的可加性、ROI 条件化、τ/E 拟合；再用独立生成的计数和共同事件模板验证协方差。保留优化失败、Monte Carlo 误差和模型边界，不计算原论文的寿命偏差或 coverage。

## 已选 adaptive bin 子问题的设计回忆（12:31 后续）

这是本轮有限 bin/统计问题的延伸，未打开新来源。若 bin 边界由同一份计数选择，最终边界也携带选择信息；把这些边界当事先固定可能改变 likelihood。可构造 fixed-N 两 bin 的例子：计数太小时合并，保留组的比例会受截断影响。应比较完整“计数+边界规则”的观测模型、忽略规则的模型和独立 pilot 选边界的控制。所有输出 bin≥10 应只是规则性质，不能先当作无偏证明。

随后核对 event-overlap：Poisson 总事件数与 fixed 总事件数的 bin covariance 不同；同一光子在两种 correction/reference 中重复显示，也不产生独立统计量。这两个子问题已经列入当前 bounded analysis，90分钟门之后只收束它们。
