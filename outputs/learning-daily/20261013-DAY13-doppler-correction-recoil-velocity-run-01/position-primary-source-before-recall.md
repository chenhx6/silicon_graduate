- Doppler peak width与position resolution关系依赖emitter velocity/angle、neutron recoil/target spread、instrument response和reconstruction，不能凭图的width唯一反演。
- 若用两体反应可测charged ejectile约束residual vector，或确知post-target velocity，从宽度求position会获得不同识别条件。
- 独立static imaging可校核position响应，却共享PSA/sequence/calibration；measurement/test modality互补不等于所有数据独立。
- 全局isotropic位置smearing可能不足以表示energy/depth/direction-dependent PSA响应；held-out energy/location是必要设计。
- 反证：保留已知reaction/vector与static calibration，若predicted width不能转移到其它angle/energy，再窄化同一line也不能算完成validation。
