# DAY10 来源前回忆

## Recall provenance

这是 **primed recall**，不是 blind recall：Day9 的预习报告、DAY10 计划、课程矩阵和 handoff 已经提供了提示。本记录先独立写下概念，再回到 MU07、GR18、LKH82 原始来源校准；Day9 的预习不充当 Day10 正式交付。

## 初答

- `B(M1)/B(E2)` 是已指定跃迁的约化磁偶极与电四极跃迁概率之比。若以 `B(M1)` 用 `μN²`、`B(E2)` 用 `e²b²` 表示，该商带有 `μN²/(e²b²)` 单位；它不是无量纲量，也不是某一条混合跃迁的 `δ²`。
- 同一多极下、同一母态的带间/带内 `B(out)/B(in)` 是无量纲比；若手中只有 γ 光子计数比，还要知道效率、转移能、多极性、混合、内转换和支路归一后才能换成 B 值比。`Tγ(XL) ∝ Eγ^(2L+1) B(XL)`，故同为 M1 与同为 E2 的能量因子不同。
- 同一条 M1/E2 混合跃迁的 `δ²` 是 E2 与 M1 光子部分率之比。仅有分别列出的带内 `B(M1)`、`B(E2)` 不能给出该跃迁的 `δ`；还需要同一条线的能量、初末态映射和多极分解，且平方量不给相对振幅符号。
- `Qt` 是由跃迁四极强度在转子矩阵元关系下推得的 transition quadrupole moment，不是直接测得的形状。反演依赖确定的 E2 跃迁身份、寿命/分支输入、`K` 与自旋因子和转子近似；不同 `K` 或带混合时不能共用一个未说明的换算。
- 我预期仅靠平滑或相似的 `B(M1)/B(E2)` 趋势无法唯一判定 chiral vibration、static chirality 或 wobbling；signature/configuration mixing 也可能改变 E2 分母或 M1 矩阵元，需结合伙伴带连接、混合比、寿命/绝对强度以及几何相关的独立观测量。

## 来源后差异

- MU07 Table I 的寿命与 `B(M1)`、`B(E2)` 是 DSAM 派生结果；Figures 2–3 将带内和 Band B→Band A 实验点与 TAC/RPA 曲线分开。两类比值复用同一测量链，不能把派生商计成独立观测。
- Table I 按初始自旋列强度，但没有逐行 γ 能量/末态自旋。表列有量纲 `B(M1)/B(E2)` 不是 `δ²`；只有具体跃迁身份和 `Eγ` 经核实后，才可按 LKH82 rate relation 转换。Fig.3 的四个带间 E2 图估 out/in 中心值从约 `0.14` 到 `0.50`，但 `35/2−` 与 `37/2−` 的端点敏感区间重叠，图上也没有 `39/2−` 点。
- 作者将低自旋振动和高自旋 static-chirality onset 联系到 TAC+RPA：RPA mode 在模型中约比实验伙伴带最接近处高一个自旋单位才降至零。该 onset 是模型解释，不是直接测得几何。
- GR18 的 `g=+0.59(1)` 是两个 TDPAD 测量支持的实验量；“bandhead 近乎 planar”来自 PRM+constrained-CDFT 对 `⟨ô⟩≈0.15` 的模型分析，不是 g 因子本身直接给出的几何。该例来自不同核素和反应，作比较控制而非 MU07 的独立重复。
- Suzuki 2008 的 `103,104Rh` 测得强度中 `B(M1)` 随自旋下降，弱 staggering 位于 `B(E2)`，说明相似的比值变化也可由分母驱动。它是不同质量区的机制反例；每核只测候选双带的一侧，且 `B(M1)` 提取假定 pure M1。
