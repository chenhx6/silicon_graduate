# L3: `137Ba` competitive double-γ path discrimination

## Question

Which observables distinguish E2M2/M2E2 from E3M1/M1E3 virtual paths in the `137Ba` competitive double-γ branch?

## Evidence and competing hypotheses

- **Observed branch:** Walz 2015 reports `2.05(37)×10⁻6`; Söderström 2020 independently reports `2.62(30)×10⁻6` and `8.7σ`. The total branch is compatible within stated uncertainties.
- **H1, quadrupole-dominant:** Walz 2015 fits the 72° energy distribution and 144° angular point with a stronger Aqq term; the SI fixes efficiency/gate fractions and acknowledges a two-parameter fit with four smaller paths set to zero (Walz SI pp.5–8, Eqs.13–19).
- **H2, octupole-dipole-dominant:** Söderström 2020 uses five angular groups and energy-sharing slices; the asymmetric energy-sharing distribution favors E3M1 with smaller M2E2 (PDF pp.4–6, Figs.4–5, Table 1).
- **Model uncertainty:** EDF+QPM and MCSM differ in M2 hindrance and orbital occupation; neither theory independently measures an intermediate-state sum (Söderström pp.5–6, Tables 1–2).

## Decision

The existence and order of magnitude of the competitive branch are supported by two experiments. The path ranking is provisionally revised toward E3M1 by the energy-sharing evidence, while sign/order branches and detector-response dependence remain open. A statement that each virtual matrix element is separately measured would exceed the data.

## Discriminating prediction and reverse test

An experiment with calibrated photon-energy sharing over a wider range and an independent polarization observable should separate symmetric M2E2-like from asymmetric E3M1-like distributions, provided the response and residual Compton background are co-fitted. A common re-fit of both published data sets with their response/covariance files could reverse the current ranking if it finds that detector acceptance produces the observed asymmetry.

## L4 readiness and stop

No L4 re-fit is started. The cited Söderström final-data DOI was checked on 2026-09-21 and has no retrievable Mendeley snapshot; the article states that raw data and sorting code are available from authors on request. Raw event matrices, detector-response files and sorting code are therefore still unavailable, and final reported points alone do not permit a complete common likelihood with shared systematics. The L3 literature comparison is complete at this boundary. Reopen only when a public response/data package or a new independent discriminating measurement appears.
