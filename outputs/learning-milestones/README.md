# Learning milestones

本目录保存阶段报告、调度状态、运行回执和研究交代。可复用的四阶段 evidence map、实验判据矩阵、竞争解释矩阵、能力资产和 thesis knowledge 属于 `knowledge/`，由 QMD 和问答 skill 统一检索。阶段结果必须区分直接事实、作者解释、模型结果、跨来源综合和 provisional inference；未完项目用 handoff/WIP queue 续跑。
