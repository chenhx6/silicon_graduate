# Weekly learning records

每周记录覆盖范围、互链缺口、反证、证据独立性、belief revision、下一批候选和 deferred important issues。周记录不以固定论文数量作为达标条件；`continuation-audit` 与 `maintenance` 不冒充 `weekly-learning`。

周报只保存过程交代。新的可复用事实、证据地图、竞争解释、开放问题或研究设计必须同步进入 `knowledge/`，并在周报中回链 canonical 页面和来源 locator；没有新增知识时明确记录 `verified no-op`。
