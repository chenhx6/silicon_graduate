## 1. 核心判决与复核条件

1. 行 149–155 原句：非正交左右态取实重叠 S，H 矩阵取实 k，得到 E±=(h±k)/(1±S)。
2. 若只说两参考态“左右对应”，并不能自动得到矩阵条件；必须定义其关系和作用空间。
3. 取归一化、线性无关的 |L⟩ 与 |R⟩=C|L⟩，其中 C 反幺正、C²=1、CHC⁻¹=H、H 厄米。
4. 则 h=⟨L|H|L⟩ 是实数，⟨R|H|R⟩=h；这是由对称关系及厄米性给出的等对角元。
5. 若 |R⟩ 不是对称变换的像，或有效 H 不保持 C，对角元相等必须另加假设。
6. 定义 S=⟨L|R⟩、k=⟨L|H|R⟩，二者一般均为复数；独立态要求 |S|<1。
7. 态的相位可调整一个复数为实，但一般不能同时令 S 和 k 为实；二者的相对相位是关键。
8. 对 |L⟩→e^{iφ}|L⟩、|R⟩→e^{-iφ}|R⟩，S 与 k 都乘 e^{-2iφ}。
9. 更一般的两态独立重定相也使 S、k 乘同一个相位；因此 kS* 的虚部是否为零不因重定相改变。
10. 当 S≠0，能同时实化 S、k 的充要条件为 Im(kS*)=0；S=0 时可单独定相使 k 实。
11. 实对称二态模型是合法的额外条件近似；可通过实际矩阵元检验条件，或引入满足相应性质的线性左右交换对称性。
12. 特别地，线性幺正交换 P、P²=1、[H,P]=0、|R⟩=P|L⟩ 足以使 S、k 均实。
13. 这包括 R3 note 的宇称恢复例子；其 P 是线性算符，不能把证明原封不动套到反幺正 C。
14. 此模型的 ± 仍可作为已选基和额外线性对称性的分支标签；不是 C 的规范不变 ± 本征值。
15. 正交极限 S=0 下，即使只给 C 对称，也可选择左右相位令 k 实并采用正交两态式。
16. 与此不同，非正交时 k 的相位相对 S 的相位有物理上可影响广义本征谱的内容。

## 2. 二维抽象反例（本任务推导）

17. 取 C=K 为标准复共轭，H=[[0,1],[1,0]]，它是实对称厄米矩阵，且 CHC⁻¹=H、C²=1。
18. 令 |L⟩=(√3/2, i/2)ᵀ，|R⟩=C|L⟩=(√3/2, −i/2)ᵀ，二者均归一且线性无关。
19. 直接算得 S=⟨L|R⟩=1/2，h=⟨L|H|L⟩=⟨R|H|R⟩=0。
20. 而 k=⟨L|H|R⟩=−i√3/2，所以 Im(kS*)=−√3/4≠0。
21. 这正是 S 已实、k 仍复，且无法通过左右定相使二者同时实化的例子。
22. 原有正交坐标下 H 的精确本征值为 −1、+1；一般广义本征方程也应得到它们。
23. 若硬将该 k 当实数使用 E±=(h±k)/(1±S)，会得到复数；并非厄米系统的能量。
24. 此反例只是二维线性代数控制，不把 H、S、k 当成真实核结构模型或数据。

## 3. 一般广义本征式、能隙与能量零点（本任务推导）

25. 写 N=[[1,S],[S*,1]]、H=[[h,k],[k*,h]]，h∈ℝ，S,k∈ℂ，|S|<1。
26. 一般久期方程为 det(H−EN)=(h−E)²−|k−ES|²=0。
27. 展开为 (1−|S|²)E²−2[h−Re(kS*)]E+h²−|k|²=0。
28. 令 A=1−|S|²>0、B=h−Re(kS*)，则 E_high/low=[B±√(B²−A(h²−|k|²))]/A。
29. 非负物理能隙为 ΔE_phys=2√(B²−A(h²−|k|²))/A≥0。
30. N 正定、H 厄米保证该根号非负；可将广义问题变换到正交基看出这一点。
31. 先选定相使 S 实时，ΔE_phys=2√[(Re k−hS)²+(1−S²)(Im k)²]/(1−S²)。
32. 因此即便 Re k=hS，非零 Im k 仍能使两个本征值分裂。
33. 上述反例给 A=3/4、B=0、h²−|k|²=−3/4，故 E=±1，ΔE_phys=2。
34. 如果再有 k 实，原稿式 E±=(h±k)/(1±S) 正确，对应系数方向 (1,±1)ᵀ。
35. 此时 E−−E+=2(hS−k)/(1−S²) 是带号分支差，未必非负。
36. 正能隙为 2|hS−k|/(1−S²)；谁是高能态由 hS−k 的符号决定。
37. 例如 S=0、h=0、k=1 时原稿带号差为 −2，但能隙为 +2。
38. 若规定 k=−t 且 t>0，正交模型才有 E+=h−t、E−=h+t，能隙 2t。
39. |S|=1 时 N 奇异，两参考态线性相关，以上二维分式不适用。
40. 正交两态能隙 2|k| 不自动证明全部劈裂都是可观测的独立隧穿矩阵元；它是该截断中的参数解释。
41. 把物理算符平移 Ĥ→Ĥ+c1̂ 后，在该非正交基中 H 矩阵变为 H+cN。
42. 因而 h→h+c、k→k+cS，而不是对矩阵 H 仅加 c 个普通单位矩阵。
43. E_high/low 均加 c，k−hS 保持不变，能隙及 det(H−EN) 的相应变量平移保持一致。
44. 如果限制空间内 Ĥ=h1̂，则 H=hN，k=hS，两个广义本征值相等。
45. 这里“限制空间内恒等”是精确陈述；单独称“无真实相互作用偏向”需要先定义被投影的模型空间。
46. 其他更大的模型可用正交基、显式投影或直接对角化；广义久期方程是所选非正交有限基的解法，不是唯一量子方法。

## 4. 手征算符作用方向与角动量三重积

47. 行 43 原句：绕选定对称轴转 π 可“将总角动量恢复至原系统的转动方向”。
48. 定义 y=m、x=s、z=l；主动变换态 |ψ′⟩=C|ψ⟩，对实矢量期望值有 (Js,Jm,Jl)→(Js,−Jm,Jl)。
49. 分量结论也可由 C⁻¹ Js C=Js、C⁻¹ Jm C=−Jm、C⁻¹ Jl C=Jl 求出。
50. 所以平面内 Js、Jl 保持，而垂直该平面的 Jm 变号；当 Jm≠0 时，完整总 J 的原方向并未恢复。
51. 可用句：该复合操作把非共面构型映为相反手性、并保持所选主平面内的总角动量投影。
52. 若另选与 J 垂直的旋转轴，可使 T 后的 J 重新指向原方向；该轴一般不等同固定体轴 m，须另外声明。
53. 原作可使用不同轴顺序；比较时必须先写出坐标映射及态/算符的主动或被动约定。
54. 行 27–33 原句：三重积期望非零，且总 J 三个分量均非零即足以诱发自发手征破缺。
55. 在三轴主轴确定且 D₂ 等相关对称性存在的特定稳定 TAC 参考解中，J 的三分量非零表明该参考取向是非主平面的。
56. Frauendorf–Meng 1997 的非平面/平面判别正是在明确对称、平均场及能量面条件下给出；它不由三个数字单独证成。
57. 非零三个分量可来自外加约束、坐标选取、非平稳态或单一矢量取向，不能独自证明粒子、空穴、核芯三矢量的三重积非零。
58. 即使三个分量非零，也须比较 C 变换后的自洽解、对称性、稳定性与势能面；并不自动构成可观测的自发破缺。
59. 对相互独立子空间的厄米角动量，χ=j_p·(j_h×R) 为旋转标量且对 C 变号。
60. 若这三个算符不独立或不对易，应先规定厄米对称化和体轴算符定义，不能默认其乘积可直接观测。
61. 对 C 对称 H 的非简并本征态，C|ψ⟩ 与 |ψ⟩ 只差相位，因此 C 奇的厄米 χ 满足 ⟨χ⟩=0。
62. 简并子空间可以选择破缺态；单个精确态的表述须保留简并与态选取条件。
63. 因此三重积非零是具有明确约束的破缺参考态或波包的指标；对精确实验室本征态应考察涨落、相关函数及对称恢复后的可观测量。
64. 另注意 ⟨j_p·(j_h×R)⟩ 与 ⟨j_p⟩·(⟨j_h⟩×⟨R⟩) 一般不同；后一式是半经典因子化。

## 5. 四极密度、粒子/空穴和惯量

65. 行 3、37、197 原句：所有三轴核的静态密度天然反演和镜面对称；核手征唯有通过转动。
66. 限于纯四极、中心反演对称的椭球参考密度，主轴三平面镜面对称及宇称偶是适当的模型陈述。
67. 三轴四极张量存在并不排斥额外奇多极密度、八极关联或反射不对称内禀形状。
68. 精确宇称本征态的实验室密度对称，与破缺宇称的内禀参考态是不同对象。
69. Liu thesis PDF 80–82、90 实际讨论八极软性与不同模型极小；不可把其升级为已实测稳定静态八极。
70. 可用句：本节先讨论反射对称的纯四极三轴参考形状；若纳入八极自由度，手征与空间反射破缺可以并存或竞争。
71. 行 16–17 原句：轴向低/高 Ω 直接对应粒子沿短轴、空穴沿长轴，且空穴为减少重叠。
72. Ω 是轴对称单粒子角动量的轴投影标签；三轴势通常混合 Ω，不能把它当一般严格量子数。
73. 具体高 j 粒子—空穴模型可给 s/l 优势取向，但顺排还依赖势场、组态、占据、配对和转动频率。
74. Frauendorf 2001 印刷 p.485 说粒子/空穴相应取向使其密度与势场的重叠最大；稿中“空穴减少重叠”不是该原文说法。
75. 缺失粒子的空穴角动量和空穴能量应按孔态定义，不能把被移除粒子的直觉原样等同孔态。
76. 行 13 把流体惯量与刚体措辞连用，且直接推出中间轴一定最大。
77. 无旋流近似可写 J_k=J₀ sin²(γ−2πk/3)，轴编号与 γ 约定必须配对；γ≈30°时中轴大是该模型结果。
78. 刚体椭球绕 k 轴的惯量正比于另外两条半轴平方和；对长>中>短的半轴，刚体最大惯量绕短轴。
79. “垂直半轴平方差”是无旋流模型的理想几何表述，不是刚体惯量；真实动力学惯量还依赖配对与响应。
80. 在固定 |J| 的纯转子经典能 E=ΣJ_k²/(2J_k惯量) 中，沿最大/最小惯量轴分别极小/极大。
81. Bohr–Mottelson Vol.II 印刷 pp.190–193（PDF 212–215）讨论高 I 非轴转子与近似振动；它不指定实核的惯量排序。
82. 耦合体系中的 R 同时受到价粒子约束，不能从纯转子的极值无条件推出严格 R∥m。

85. Koike 2004 PDF 3 中，粒子和空穴在足够高转速趋向中轴，中间自旋区更有利；不能外推成所有核的必经阶段。

90. 角动量守恒、宇称与 C 对称的精确条件均须分别说明；旋转不变性恢复不等同每个内禀对称性的二态恢复。

100. 即使完整 H 保有某对称性，一个选定平均场参考解也可不保有它；这是“方程对称性”和“解破缺”的区别。
101. ΔI=1 跃迁序列本身不等于相邻态必有可观测的能量 staggering；应定义所用能差指标后再判断。
102. 不能把一般 TAC 的有效转轴、体轴 y、角动量 J 与转频 ω 强行视为同一对象。

## 7. S(I)、实验约束与竞争解释

105. 对 E(I)=A I(I+1)，直接相减得 S(I)=A；这是转子代数控制，并非手征唯一指纹。
106. Ayangeakaa 2013 实际 5 页期刊 reprint PDF 3 的 Fig.2 及正文使用 S(I)，但该页未印出其代数定义。
107. 该段将标准指纹引至其 Ref.40；本次未取得或读取 Ref.40，故不能仅从 Fig.2 证明该文使用了稿中的精确公式。
108. Liu thesis PDF 14、16–18 是本次回读的背景范围；提取文字存在严重字形与数学符号问题。
109. 本次未能从所读 Liu 页准确辨认 S(I) 公式及 locator，不能照 ledger 的既有阅读声明把它认证为相同定义。
110. 因此可把公式明确归 Meng；其他论文分别确认原定义后另引，或者只说作者绘制某个 S(I) 指标而不替其补式。
111. 符号 S(I) 与本审计的非正交重叠 S 是不同对象，正文最好显式区分。
112. 行 190、203：绝对 B、DSAM/RDM、DCO/偏振和三维微观模型被写成确立手征的统一必经路线。
113. 可用句：寿命、分支、内转换和多极混合等可共同约束绝对跃迁强度；具体可达精度与反演多解应逐案例检验。
114. DCO 与偏振可约束混合比，但不保证唯一解；还应保留约定、统计响应与竞争分支。
115. 寿命等有价值，但不能仅根据此节来源宣布它们是每个候选的逻辑必要条件。
116. 例如 Ayangeakaa 2013 PDF 3 明说本次几条带寿命测量不可行，同时把寿命/跃迁几率视为重要独立证据。

121. Petrache 2006 PDF 1–3 通过 134Pr 带交叉与两带混合分析质疑理想手征解释。
122. 其 Q₀ 比值来自特定模型假设及分支信息；不能概括为所有不同形状带都是已经实验证实的反例。
123. 近简并、跃迁强度、组态、形状及理论波函数需联合比较，也应保留软核、交叉及准粒子等可检验替代机制。

## 8. Rohoziński 2011 的直接核对

124. 行 186 原句：作者“证实核芯振动与准粒子的非绝热耦合同样可诱发双带和 M1 交错，无需静态非共面几何”。
125. ledger claims 和 competing_explanations 重复这一归因，并把它称作已证实的非手征机制。
