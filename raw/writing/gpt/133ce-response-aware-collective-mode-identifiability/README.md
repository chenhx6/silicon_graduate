# Response-aware collective-mode identifiability in `133Ce`

这是 A≈130 论文候选的独立工作包。它围绕一个问题组织：

> 在真实 gate、prompt timing、detector response、alignment 和 mixing-ratio
> 不确定度被显式保留时，`133Ce` 候选带是否能被唯一识别为 wobbling？

当前状态是 `active-L3 / partial-L4`。工作包可用于本地分析和论文草稿，
尚未代表最终模式判决，也未获得私有数据公开授权。

## 目录约定

- `analysis/`：可复现分析脚本、配置和运行记录；
- `data/`：经过授权可随文章公开的基础数据；私有 raw 原件不复制到这里；
- `figures/`：文章图件；
- `figures/made/data/`：绘图辅助中间数据；
- `sources/`：文章使用的来源清单、claim-to-locator 表和归档指针；
- `main.tex`、`references.bib`：在 evidence gate 通过后生成的投稿源码。

外部来源的原件保存在 `raw/papers/gpt/query/20261105-*`，不把 URL 或摘要
当作已归档全文。South Africa 原始数据仍只从 `raw/data/SouthAfrica/` 读取。

## 当前创新边界

文章只保留一个主创新：**response-aware mode-identifiability test**。
能级图、邻核系统学、模型图和数据处理方法都服务于这个主问题。

## 公开性状态

当前使用的 South Africa 数据标记为 `local-only-unpublished-user-data`。
在用户明确批准数据释放和作者/合作署名边界前，文章包中的派生结果不得
自动作为公开数据集或远端发布材料。
