# Source provenance and coverage map

This page is a deliberate graph-owner registry for source pages that were previously reachable only from `knowledge/index.md`. It provides provenance navigation; it does not promote a source claim, create an independent experiment, or replace a domain page. The registry is Codex self-audit, not human review.

## Registry rule

A source is listed here when no domain page currently links to it. The hub is an intentional inbound edge so source discoverability is not confused with scientific relevance. Domain ownership can later be refined without changing source identity or review status.

## Research Question

Which source pages are currently reachable only from the global index, and what explicit provenance boundary should be preserved while a domain owner is pending?

## Current Hypotheses

- Index-only reachability is a graph-coverage issue, not evidence that the source is scientifically irrelevant.
- A deliberate provenance hub is safer than adding generic links to unrelated scientific pages.

## Evidence Available

The registry is generated from the source frontmatter, extracted-page links and the whole-library link audit. Each listed source retains its own raw hash, locator table and review status.

## Risks and Blockers

This registry does not certify claims, resolve citation-key identity, or establish independent experiments. Domain ownership remains pending where no target page is justified by the source itself.

## Next Actions

When a source gains a justified nucleus, band, method, experiment or project owner, add that specific relation and retain this registry as the provenance fallback. Do not clear `needs_review` solely because a graph edge was added.
