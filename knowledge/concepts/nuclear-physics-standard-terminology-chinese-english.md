# 低能核物理与核结构核心中英文标准术语与概念体系规范

## 1. 建立背景与学术规范意义

在当代理论与实验核物理研究中，绝大多数前沿原始文献以英文发表；然而在撰写中文开题报告、国家自然科学基金/青年基金申请书、博士学位论文以及向国内权威中文期刊（如《中国科学: 物理学 力学 天文学》《物理学报》《原子核物理评论》）投稿时，必须使用严谨、地道、公认的中文学术规范术语。

本规范综合《原子核物理（修订版）》（卢希庭等）、《重离子核反应》（林承键）、《原子核物理实验方法》（吴治华）以及全国科学技术名词审定委员会规范，对低能核结构、在束核谱学与集体运动前沿的核心术语建立统一对齐标准。

## 2. 核心术语分类对照矩阵

### (1) 核形变、集体激发与三轴前沿

| 英文术语 (English Term) | 推荐标准中文 (Recommended Chinese) | 习用/别称 (Alternative) | 典型物理语境与定义 |
| :--- | :--- | :--- | :--- |
| **Triaxiality / Triaxial deformation** | **三轴形变** | 非轴对称形变 | $\beta \ne 0, \gamma \ne 0^\circ, 60^\circ$ 的非轴对称空间三向椭球形变 |
| **Axial symmetry / Axially symmetric** | **轴对称** | - | 椭球体具有轴对称性（$\gamma=0^\circ$ 拉长 / $\gamma=60^\circ$ 扁长） |
| **Prolate / Oblate** | **拉长形 / 扁长形** | 长椭球 / 扁椭球 | 四极形变两极伸展或赤道展宽 |
| **$\gamma$-softness / $\gamma$-rigidity** | **$\gamma$ 软度 / $\gamma$ 刚性** | $\gamma$ 柔软核 / $\gamma$ 刚性形变 | 势能曲面中关于 $\gamma$ 角自由度的势阱深度与零点涨落幅度 |
| **Shape coexistence** | **形状共存** | - | 同一原子核在相近激发能下并存具有显著不同形变的态 |
| **Wobbling motion** | **摆动运动** | 摇摆运动 / 摇动 | 三轴非对称转子绕主转动惯量轴的进动与量子激发 |
| **Transverse / Longitudinal wobbling** | **横向摆动 / 纵向摆动** | - | 准粒子角动量垂直或平行于最大转动惯量轴 |
| **Chiral doublet bands** | **手征双重带** | 手性双重带 | 三轴核中由三个非共面角动量构成的左手系与右手系简并能带 |
| **Chirality / Chiral symmetry breaking** | **手征性 / 手征对称性破缺** | 手性破缺 | 旋转坐标系下空间反演与时间反演联合对称性破缺 |
| **Signature / Signature splitting** | **旋称 / 旋称劈裂** | 标识量子数 | 绕转动轴旋转 $180^\circ$ 的离散对称性量子数 $r=e^{-i\pi \alpha}$ |
| **Signature inversion** | **旋称反转** | 标识反转 | 随自旋增加，有利旋称态（favored）与不利态（unfavored）能级交错反转 |
| **Magnetic rotation / Shears mechanism** | **磁转动 / 剪刀机制** | 磁转动能带 | 弱形变核中正宇称质子空穴与中子粒子构成的阶梯形 $M1$ 跃迁带 |
| **Backbending** | **回弯现象** | 转动回弯 | 随角速度 $\hbar\omega$ 增加，Coriolis 力促使单核子对解耦导致惯量跃增 |
| **Yrast line / Yrast state** | **Yrast 线 / Yrast 态** | 极冷态 / 最下沿能态 | 给定角动量（自旋 $I$）下的最低激发能态 |

| 英文术语 (English Term) | 推荐标准中文 (Recommended Chinese) | 习用/别称 (Alternative) | 典型物理语境与定义 |
| :--- | :--- | :--- | :--- |
| **Directional Distribution (AD)** | **方向角分布** | 角分布 | 单个探测器相对于束流轴测量计数角响应：$W(\theta)$ |
| **Directional Correlation of Oriented nuclei (DCO)** | **定向核方向角关联比值** | DCO 比值 | 束内双探头重符合下探测角度几何相关的特征强度比 |
| **Angular Distribution from Oriented states (ADO)** | **定向态角分布比值** | ADO 比值 | 特定两个特征角度下的规一化发射计数比值 |
| **Linear polarization** | **线偏振 / 线极化** | 偏振度 | 康普顿散射垂直与平行平面的散射不对称度：$P$ |
| **Multipole mixing ratio ($\delta$)** | **多极混合比** | 混合比 $\delta$ | $\delta = \langle I_f || \mathcal{M}(E2) || I_i \rangle / \langle I_f || \mathcal{M}(M1) || I_i \rangle$ |
| **Orientation parameter ($B_k$)** | **取向参数** | 偏极化参数 | 描述亚磁能级 $m$ 高斯布居展宽 $\sigma/I$ 的取向度 |
| **Deorientation effect** | **退取向效应** | 磁超精细退取向 | 反冲核在真空中受电子壳层非配对自旋扰动引起的角关联衰减 |
| **Reduced transition probability ($B(E\lambda)/B(M\lambda)$)** | **减缩跃迁几率** | 约化跃迁几率 | 剔除跃迁相空间能量因子后的核结构波函数矩阵元平方模 |

| **Peak-to-Compton ratio (P/C)** | **峰康比** | - | 谱仪全能峰峰高与康普顿连续谱平均高度的比值 |
| **Ballistic deficit** | **弹道亏损** | - | 放大器成形时间短于探测器电荷收集时间造成的幅度损失 |

## 3. 常见易混淆概念与规范表述指引

1. **“摆动（wobbling）”与“振动（vibration）”的区别**：
   - 振动是核表面形状随时间的周期性伸缩或扭曲（如声子激发）；
   - 摆动是核自身**刚性或准刚性三轴形变在空间定点旋转坐标系下的进动**（本质上是刚体绕中间惯量轴不稳定、转而在最大惯量轴周围微幅摆动的转动自由度）。
2. **“手征性（chirality）”与“伪手征（pseudochirality）”**：
   - 真正的手征双重带必须满足电磁跃迁特征（$B(M1)$ 与 $B(E2)$ 在两带间呈现近简并或交替劈裂）；不能仅凭能量上的两条靠近的带就宣称为手征带。
3. **“混合比 $\delta$ 的符号约定”**：
   - 必须注明采用 **Rose-Brink 约定** 还是 **Krane-Steffen 约定**（二者相差一个负号：$\delta_{\text{KS}} = -\delta_{\text{RB}}$）。国际常规核数据表（ENSDF）均统一遵循 Krane-Steffen 约定。
