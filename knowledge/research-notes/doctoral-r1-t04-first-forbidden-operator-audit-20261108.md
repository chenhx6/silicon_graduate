## Provisional Reasoning

### 1. 端点、核质量与原子质量

原文 p.2 Eqs.(1)–(2) 给定 \(W=E_e/(m_ec^2)\)，\(E_e\) 包括静能，\(p/(m_ec)=\sqrt{W^2-1}\)，所以积分下限为 1。其 \(W_0=(M_i^{\rm nuc}-M_f^{\rm nuc})/m_e=Q/(m_ec^2)\) 使用母、子**核态**质量，末态激发能已包含在 \(M_f^{\rm nuc}\) 中；这里的 \(Q\) 是允许电子带走的总端点能，而不是惯常中性原子表的纯动能 \(Q_\beta\)。忽略反冲及其他原子激发时，对从母原子基态到子核激发 \(E_x\) 的 β⁻：
\[
W_0=1+\frac{Q_\beta^{\rm atom}-E_x+B_e(Z_i)-B_e(Z_i+1)}{m_ec^2},\quad
Q_\beta^{\rm atom}=[M_{\rm atom}(A,Z_i)-M_{\rm atom}(A,Z_i+1)]c^2,
\]
其中 \(B_e>0\) 为中性原子总电子束缚能；式子直接来自 \(M_{\rm atom}c^2=M_{\rm nuc}c^2+Zm_ec^2-B_e(Z)\)。忽略原子束缚修正则为 \(1+(Q_\beta^{\rm atom}-E_x)/(m_ec^2)\)。因此不能将原子质量差直接代入原文的 \(W_0=Q/(m_ec^2)\) 而漏掉 1；具体原子最终态、屏蔽/激发及反冲有时要求更精细的能量记账。若质量输入已包含激发态能量，不能再重复减 \(E_x\)。该质量换算是本任务条件代数，不是论文逐字表述。

### 2. 吸收形状因子的 f 与传统 log ft

令 \(\rho(W)=F(Z,W)\sqrt{W^2-1}W(W_0-W)^2\)。原文 \(f=\int C(W)\rho(W)dW\)，\(f_0=\int\rho(W)dW\)，\(\bar C=f/f_0\)（pp.2–3 Eqs.2、14、15）。单分支 \(t\) 是 partial half-life，\(ft=K=6146\,\mathrm{s}\)，因此
\[
 f_0t=K/\bar C,\qquad \log_{10}(f_0t/\mathrm{s})=\log_{10}(K/\mathrm{s})-\log_{10}\bar C.
\]
\(\bar C\) 在论文电子康普顿波长的无量纲约定下代入；f 的 log 与一般文献所说不含核形状因子的 \(\log f_0t\) 不可混称。若总半衰期 \(T_{1/2}\) 给出，必须使用该分支总跃迁概率 \(b\)（包括相关转换等定义一致的通道）得到 \(t=T_{1/2}/b\)，且合计率为各分支之和。对于允许纯 GT，\(\bar C=B(GT)\)；禁戒时一般不能取单点 \(C(W)\) 代替加权平均。

### 3. 允许 GT 与相位

p.2 Eqs.(3)–(4)：\(C=B(GT)=(g_A/g_V)^2|\langle f\|\sum_k\sigma_k t^-_k\|i\rangle|^2/(2J_i+1)\)；即本论文的 \(B(GT)\) **已经包含耦合比平方**。另一习惯仅把自旋同位旋约化强度命名为 \(B(GT)\) 时才需额外乘 \((g_A/g_V)^2\)。文中 \(t^-n=p\)，采用对自旋的 Racah 约化、\(g_A/g_V=-1.2701(25)\)。若原文的算符级 \(q_{GT}=0.66\) 作用于已有耦合比的 GT 振幅，强度乘 \(0.66^2=0.4356\)，不能再重复乘一次有效 \(g_A^2\)。纯 GT 的总体相位在强度中消失，首禁戒的相对相位则会影响干涉。

### 4. 首禁戒 rank 与完整系数

p.2 Eq.(5)：\(C=k+kaW+kb/W+kcW^2\)。原式括号上标是核算符 rank，不是这些系数的阶数。取 \(\gamma_1=\sqrt{1-(\alpha Z)^2}\)、\(\mu_1\simeq\lambda_2\simeq1\)，且 \(\xi=\alpha Z/(2R)\)，\(R\) 在同一电子康普顿长度单位中。p.2 Eqs.(6)–(7)：
\[
\begin{aligned}
V&=\xi'v+\xi w',&\zeta_0&=V+wW_0/3,\\
Y&=\xi'y-\xi(u'+x'),&\zeta_1&=Y+(u-x)W_0/3,\\
k&=[\zeta_0^2+w^2/9]^{(0)}+
[\zeta_1^2+(x+u)^2/9-4\mu_1\gamma_1u(x+u)/9
+W_0^2(2x+u)^2/18-\lambda_2(2x-u)^2/18]^{(1)}
+[z^2(W_0^2-\lambda_2)/12]^{(2)},\\
ka&=[-4uY/3-W_0(4x^2+5u^2)/9]^{(1)}-[z^2W_0/6]^{(2)},\\
kb&=(2\mu_1\gamma_1/3)\{- [\zeta_0w]^{(0)}+[\zeta_1(x+u)]^{(1)}\},\\
kc&=[\{8u^2+(2x+u)^2+\lambda_2(2x-u)^2\}/18]^{(1)}+[z^2(1+\lambda_2)/12]^{(2)}.
\end{aligned}
\]
这照录该版 Eq.(6) 的项与符号；如改用复矩阵元，相应乘积应按原约定处理共轭实部，不能无条件把平方当模平方。rank 0 有 \(w,w',\xi'v\) 且 \(\zeta_0w\) 干涉；rank 1 有 \(x,x',u,u',\xi'y\)，含 \(x/u\)、\(Y/u\) 与 \(\zeta_1(x+u)\) 等相对相位敏感项；rank 2 为 \(z\)，单独贡献 \(k,ka,kc\)，在此展开中无 \(kb\)。论文该未极化积分形状因子是各 rank 项之和，并非允许把所有算符振幅不分 rank 先相加平方；更一般的极化/角关联不能由此自动推出。

p.3 Eq.(8) 给出核矩阵元：\(w=-g_A\sqrt3\langle\sum r[C_1\times\sigma]^0t^-\rangle/\sqrt{2J_i+1}\)，\(x=-\langle\sum rC_1t^-\rangle/\sqrt{2J_i+1}\)，\(u=-g_A\sqrt2\langle\sum r[C_1\times\sigma]^1t^-\rangle/\sqrt{2J_i+1}\)，\(z=2g_A\langle\sum r[C_1\times\sigma]^2t^-\rangle/\sqrt{2J_i+1}\)；这里尖括号是对应原文的约化矩阵元，\(C_{1m}=\sqrt{4\pi/3}Y_{1m}\)，不是形状因子。\(\xi'v=(g_A\sqrt3/M)\langle\sum[\sigma\times\nabla]^0t^-\rangle/\sqrt{2J_i+1}\) 为轴荷的非相对论约化，\(\xi'y=-(1/M)\langle\sum\nabla t^-\rangle/\sqrt{2J_i+1}\) 为矢量梯度矩阵元；两者中的 prime 随符号整体写，不是对 v、y 取导数。\(w',x',u'\) 则在对应径向算符加入 \((2/3)I(1,1,1,1,r)\)，其电荷分布权重见 Eq.(10)，通常不能设为无撇量。所有符号、\(g_A<0\) 和 Condon–Shortley 约定必须一致迁移。

### 5. CVC 与有效有限空间

p.3 Eqs.(11)–(13) 在 CVC **且同位旋为好量子数的假设**下给 \(\xi'y=E_\gamma x\)，\(E_\gamma=E_{\rm IAS(i)}-E_f=Q+\Delta E_C-(m_n-m_p)c^2\)，\(\Delta E_C=1.4136(1)\bar Z/A^{1/3}-0.91338(11)\) MeV。\(E_\gamma\) 是同位旋类似态至末态的能差，不是任意观测 γ 射线、\(W_0\) 或电子动能。代入前把 MeV 换成电子静能单位，并保持 Eq.(12) 中 Q 的核质量总端点约定；将原子动能 Q 直接混入会失去一个电子静能及原子修正。

方程约束相关矢量电荷与电流的协同实现；裸 \(g_V\) 的 CVC 保护不意味着有限价空间的单体 \(x\) 矩阵元无需有效算符修正。若在给定实现中先取 \(x_{\rm eff}=q_xx_{\rm bare}\)，再用同一 \(E_\gamma\) 施加 CVC，则必然 \((\xi'y)_{\rm eff}=E_\gamma x_{\rm eff}\)，相对于同一裸 CVC 基准同乘 \(q_x\)；这是条件一致性，不是论文另行列出的独立 \(q(\xi'y)\) 拟合结果。论文没给出拟合协方差或足够实现细节来证明其他处理等价。

### 6. 拟合数据、采用假设与保留的比较

p.4 Eq.(16)：作者假设不同核共用各因子，对 N≈82、126 附近已知 FF 衰变的实验数据作最小二乘，并报告算符振幅因子：\(q(\xi'v)=1.266\)，\(q(w)=q(w')=0.66\)，\(q(x)=q(x')=0.51\)，\(q(u)=q(u')=0.38\)，\(q(z)=0.42\)。Table I（p.5）列出 **20 个跃迁行**：131In 异能态 2、129In 异能态 2、205Hg 5、206Hg 3、207Tl 2、206Tl 3、205Au 3；作者说明沿用铅区 Warburton 所选相似集合并补 205Au 和两个 In 异能态，但没有逐行披露完整目标函数、权重、相关性、数据挑选及各个 q 的逐项灵敏度。因此不能把“20 行”直接等同于“20 个独立拟合约束”，亦不能依据该表凭空断言“16 个”或每个 q 对应某些特定行。Fig.1 展示使用最佳参数的对照，并非独立留出；数据可能共享输入或系统误差。

具体拟合关联例：Table I 的 \(^{131m}\mathrm{In}(1/2^-)\to{}^{131}\mathrm{Sn}(3/2^+)\) 给 \(\log f_0t\) 理论 5.32、实验约 5.1，\(\sqrt{\bar C}\) 理论 65.8、实验 85.4 fm；该异能态被作者明确用于 FF 因子确定，不能当盲验证。表中 129In 亦是 FF 拟合集的一部分。p.5 接着采用 FF 因子并用 \(^{130}\mathrm{Cd}\) 实验半衰期调 \(q_{GT}=0.66\)；Table III（p.9）给实验 \(162\pm7\) ms、理论 164.29 ms，所以这一吻合是**校准样本**，不是独立预测。它的 FF 贡献作者约称 13%；在该处理及其输入中应和 GT 联合解释。

同 Table III 的 \(^{129}\mathrm{Ag}\) 实验 \(46^{+5}_{-9}\) ms、理论 69.81 ms：该总半衰期没有被原文列为上述 q 的直接拟合输入，可作**相对于所披露 q 拟合的外部比较候选**，但不是已证明完全独立的严格留出：核相互作用、质量、先前模型建立和数据选择可能共用信息，原文未给全量 provenance；且理论值高于当时数据。2013 的数据/模型比较不宣称至 2026 无更新。

### 7. 表内自洽和数值边界

论文 Table I 的 \(\sqrt{\bar C}\) 使用 fm；\(\lambda_e=\hbar/(m_ec)\approx386.159\) fm，故按 Eqs.(1)、(14) 有可复核关系 \(\log_{10}(f_0t/\mathrm{s})=\log_{10}[6146(\lambda_e/\sqrt{\bar C}_{\rm fm})^2]\)。例如 131In 第一行理论 65.8 fm 算得 5.326，与表中 5.32 在舍入尺度相符；实验 85.4 fm 算得 5.099，与约 5.1 相符。

**疑似原表内部不一致，不擅自替作者修表：**205Hg→205Tl(3/2⁺₁) 理论 \(\sqrt{\bar C}=18.9\) fm 给 6.409，但表中理论 \(\log f_0t=7.26\)；205Hg→205Tl(3/2⁺₂) 的 10.3 fm 给 6.937，但表中为 6.32。相应实验列 17 fm→6.501 与 6.51(21)、5 fm→7.564 与 7.61(22) 大体相容。静态 `rp.tex` 表行与 PDF 一致，故并非文本抽取偶然错列；仍需核出版最终版、勘误和基础输入后才能判断是排版、错配还是其他原因。206Tl 理论列亦存在值得逐行核查的类似差异。为此不得把受影响的理论数字当无歧义校准记录，也不得据此宣称所有表行不可用。

### 8. 增强的因果边界与 Lanczos

\(q(\xi'v)=1.266\) 是该相互作用、模型空间、数据集与参数化下的**整体振幅**乘数；单独平方约 1.603，不等于含 \(w,w'\) 干涉的 rank-0 整体率增强。作者 p.4 把 Warburton 的增强联系到介子交换，p.5 称其结果确认相对增强；本次未独立分离两体流、芯极化、模型空间截断、波函数或参数相关性，不能从 1.266 唯一测出介子交换贡献。同理 q(x)=0.51 是有限空间有效矢量矩阵元的拟合值，不能归因于唯一芯极化机制，也不与裸流 CVC 构成自动矛盾。

作者 p.5–6 对同 rank 组合使用 Lanczos 构造共同态并保留相对相位；100 次迭代、单算符强度至少 80% 的策略并不证明每个态和各干涉项都收敛。Fig.2 的 199Ta 截断空间、rank-1 部分半衰期：两个 pivot 分别 655、716 ms，与 300 次迭代的 651 ms 约在 10% 内；这是特定核、受限空间和可观测量的控制，不是全核素误差上限。

## Competing Explanations

FF 单态分支的差异可能来自组态混合、价空间截断、Q 值和末态能量、径向波函数、有效一体/多体流、振幅相对相位及实验分支误差；这些效应可能互相补偿。不同 rank 的混合亦使单一半衰期通常无法识别各 \(q\)。拟合产生增强不等于已经分解其物理来源；拟合后表图的残差不是新数据独立验证。

## Transfer Conditions

迁移实现时先固定 \(Q\) 为核总能差还是原子动能差、R 与 E 的单位、\(g_A\) 是否包含在 B 与 FF 矩阵元、相位和约化习惯，然后按同 rank 组合振幅计算 \(C(W)\)，数值积分后才比较 \(f_0t\)。CVC 必须同时说明类似态能量、有效算符与电流处理；以独立未参与参数与相互作用选择的实验数据、Q 和协方差测试迁移。不能把一套统一 q 作为所有模型空间、核区或多体算符的定律。

## Failure Conditions

- 把原子 \(Q_\beta\) 除以 \(m_ec^2\) 直接当总电子能端点，或重复扣激发能；把 \(ft=6146\) 中含 C 的 f 等同于普通 \(f_0\)。
- 对已包含 \((g_A/g_V)^2\) 的 \(B(GT)\) 再乘一次该系数；把 q 视作率而不是振幅因子。
- 丢失 rank-0/1 同 rank 干涉、把 rank-2 写成只有常数项，或者把 \(E_\gamma\) 直接以 MeV 与无量纲 \(x\) 相乘。
- 将表 I、Fig.1 或 130Cd 调参后吻合称为留出验证；将 129Ag 直接称为已证明完全独立；忽略 Table I 的可复现疑似内部不一致。
- 将 \(q(\xi'v)>1\) 等同于单独可测介子交换幅度，或将 \(q(x)\) 唯一归因芯极化；以 2013 数据冒充 2026 最新数据。

## Falsification or Reverse Tests

1. 用核质量差和对应中性原子质量差两条路径计算同一物理末态的端点；纳入相同原子束缚能与反冲后，若不一致则检查电子静能符号、激发能和离子态。
2. 对每条 Table I 行按 \(K/\bar C\) 反算 \(\log f_0t\)，比对标注舍入和实验误差；若持久不一致，追查出版表、勘误、原始数据和变量单位，而非自动调整原文。
3. 令 C 为常数测试积分 \(f=Cf_0\)；保留同一相位约定下独立翻转某一个 rank-1 振幅可检验干涉敏感性，但不能把整个态的共同重相位误当物理改变。
4. 在同一 CVC 和能量约定下对 \(x\) 与 \(\xi'y\) 同步变换；若关系失效，先检查电流、哈密顿量投影、同位旋破缺与能量单位，而非直接断言守恒流失效。
