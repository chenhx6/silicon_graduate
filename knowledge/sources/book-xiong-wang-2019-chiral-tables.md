# B. W. Xiong & Y. Y. Wang 2019 - Nuclear Chiral Doublet Bands Data Tables

## 专著/综述全貌与学术定位

北京大学与北京航空航天大学孟杰团队于 2019 年在《Atomic Data and Nuclear Data Tables》发表的权威全球核手征双重带数据库（ADNDT 125, 193–225）。

该文系统检索并评估了自 1997 年提出核手征性至 2018 年底全球报道的全部手征候选核（涵盖 133 个候选带），按四个质量区（$A\approx 80, 100, 130, 190$）对每一对候选手征带的能级、自旋宇称、带头能量、微观准粒子组态、能量差 $\Delta E(I)$、能量交错参量 $S(I)$ 以及带内/带间 $B(M1)/B(E2)$ 实验比值进行了标准化整理。

## 核心数据矩阵与质量区特征

### 1. $A\approx 130$ 质量区（核心阵地：59 个候选带）
- **典型组态**：$\pi h_{11/2} \otimes \nu h_{11/2}^{-1}$（奇奇核，如 $^{134}\text{Pr}, {}^{126,128}\text{Cs}$）与 $\pi h_{11/2}^2 \otimes \nu h_{11/2}^{-1}$（奇中子核，如 $^{135}\text{Nd}, {}^{133}\text{Ce}$）；
- **形变参数**：中度三轴形变 $\beta_2 \approx 0.18 \sim 0.25$，$\gamma \approx 20^\circ \sim 30^\circ$；
- **手征特征**：手征对称性最为明显、带间跃迁数据最完备的区域。

### 2. $A\approx 100$ 质量区
- **典型组态**：$\pi g_{9/2}^{-1} \otimes \nu h_{11/2}$（如 $^{106}\text{Rh}, {}^{105}\text{Pd}$）；
- **形变参数**：中度软三轴形变 $\beta_2 \approx 0.20 \sim 0.30$。

### 3. $A\approx 80$ 质量区
- **典型组态**：$\pi g_{9/2} \otimes \nu g_{9/2}$（如 $^{78,80}\text{Br}, {}^{74}\text{As}$）；
- **特征**：伴随强烈的八极关联（Octupole correlations），出现罕见的手征-八极四重带（Chiral-parity quartet bands）。

### 4. $A\approx 190$ 质量区
- **典型组态**：$\pi h_{9/2} \otimes \nu i_{13/2}^{-1}$（如 $^{194,198}\text{Tl}$）；
- **特征**：扁椭球三轴核（Oblate-triaxial），Coriolis 相互作用被高 $j$ 轨道强烈主导。
