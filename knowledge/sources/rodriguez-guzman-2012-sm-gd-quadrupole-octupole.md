# Microscopic description of quadrupole-octupole coupling in Sm and Gd isotopes with the Gogny Energy Density Functional

## Summary

本工作利用 Gogny D1S 与 D1M 泛函微观研究了 Sm 与 Gd 同位素的四极-八极自由度耦合。计算发现 146Sm 为八极球形，而 150Sm 具备破缺反射对称性的浅极小（能量增益 105–204 keV），阐明了稀土区中子数增加诱发的八极软化与相界演化。

## Competing Interpretations and Limitations

PES及极小值深度均为给定EDF与变分约束下的模型输出；既不是实验测得势垒，也不等于宇称劈裂。惯性、零点修正、投影与组态混合共同影响动力学；不能把坐标相同误认为不同模型结果已可逐点等价比较。
