# `135Pr`

## Identity

`A=135`、`Z=59`、`N=76` 的奇 A 镨核。当前 Wiki 并列 Matta 2015/Sensharma 2019/2026 的 Gammasphere 支持链、Guo 2021 methodological comment 与 Lv 2022 独立 JUROGAM 反证；wobbling、TiP/realignment、signature-partner 和 chiral interpretations 不作最终合并裁决。

## Production Reactions

[[matta-2015-transverse-wobbling-135pr]] 使用 80 MeV `123Sb(16O,4n)135Pr`，分别在 [[atlas-gammasphere-135pr-o16-80mev]] 和 [[tifr-inga-135pr-o16-80mev]] 获得符合、角分布和偏振数据。

[[sensharma-2019-two-phonon-wobbling-135pr]] 使用相同束流能量和靶核的独立高统计 [[atlas-digital-gammasphere-135pr-o16-80mev]] 数据，未报告偏振测量。

[[lv-2022-evidence-against-wobbling-135pr]] 使用 152 MeV `100Mo(40Ar,1p4n)135Pr` 的 [[jyfl-jurogam2-135pr-ar40-152mev]] 数据，联合测量 angular correlation 与 linear polarization。

[[sensharma-2026-evolution-chirality-transverse-wobbling-135pr]] 使用 80 MeV `123Sb(16O,4n)135Pr` 的 Gammasphere 数据，并与此前同系列数据合并；它新增 DB2→DB1 connecting transitions、对旧 angular distributions 做 χ² branch comparison，但当前 run 没有 polarization measurement。

[[guo-2021-comment-transverse-wobbling-135pr]] 是依赖 Matta 2015 报告的短篇方法学评论，不是新的反应或探测器实验。

## Established Level Structure

Matta 2015 的 Fig.1 给出 [[135pr-yrast-band]]、[[135pr-side-band]]、[[135pr-signature-partner-band]] 和 [[135pr-dipole-band]]；Sensharma 2019 建立 [[135pr-second-side-band]] 及其到 side band 的四条连接跃迁。能级与跃迁的存在和放置属于实验层；zero-/one-/two-phonon、signature partner、magnetic rotation 与 transverse wobbling 是作者解释。

Sensharma 2026 确认 DB1/DB2 的已有放置并报告五条 DB2→DB1 `ΔI=1` 连接；对 642.2、572.9、476.9 keV 三条最低能连接得到小 `|δ|`。该论文把近 `17 keV` 的 DB1/DB2 minimum splitting 和 QTR 角动量分布解释为 chiral evolution，但没有给出新实验的 polarization、absolute lifetime 或 partner-resolved absolute transition strengths。

## Bands

- [[135pr-yrast-band]]：主 E2 序列；
- [[135pr-side-band]]：通过 ΔI=1 mixed transitions 连接 yrast 的侧带；
- [[135pr-second-side-band]]：通过 ΔI=1 mixed transitions 连接 side band 的第二条侧带；
- [[135pr-signature-partner-band]]：较弱的相反 signature 序列；
- [[135pr-dipole-band]]：建立在侧带之上的强 M1 序列。

## Deformation and Collective Features

Matta 2015 的 TAC 对 1qp yrast 得到 `ε=0.16, γ=26°`，对 3qp/5qp 得到约 `ε=0.20, γ=28°`。这些是模型结果，不是直接形变测量。

## Competing Interpretations

Matta 2015 将 yrast/side-band pair 解释为 zero-/one-phonon transverse wobbling；Sensharma 2019 在此前提下把 second side band 解释为 two-phonon extension。Lv 2022 以小 `abs(δ)`、M1-dominated links、能级重组与 QTR realignment 提出反对解释；Guo 2021 进一步指出旧 angular-distribution/polarization 证据的 branch ambiguity。Sensharma 2026 以新 DB1/DB2 links、QTR chiral geometry 和旧数据 χ² 选择回应这些质疑，但其当前实验无 polarization，且没有 absolute lifetime。[[135pr-wobbling-controversy]] 继续保留双方证据和方法差异，不作终局裁决。

## Key Observables

- 747.0、812.8、754.6 keV connecting transitions 的 mixing ratio 与 E2 fraction；
- 747.0、812.8、593.9 keV 的 polarization asymmetry；
- 702.7 keV connecting transition 的 DCO-based dipole assignment；
- `E_wob(I)` 的低自旋下降；
- `B(E2_out)/B(E2_in)` 与 `B(M1_out)/B(E2_in)` 的实验/QTR 比较。
- TW2→TW1 的 450.2、550.5、517.1 keV transitions 的 DCO-like ratio、mixing ratio 与 E2 fraction；
- TW2→TW1、TW2→yrast 的相对 E2 ratios 及 `E_wob(TW2)`。
- Lv 2022 对 747.3、813.2、450.2 keV 的联合 polarization/`R_ac` mixing ratios；
- `B(E2;747)/B(E2;526)` 与 Sensharma TW2 grouping 的重检。
- DB2→DB1 新连接 642.2、572.9、476.9 keV 的 MCMC angular-distribution `δ=-0.10(6), -0.15(3), -0.11(2)`；当前结果是主要 dipole character，且 parity 仍 tentative。
- Sensharma 2026 对既有 746/812/754 keV angular distributions 的 χ² branch comparison；Guo 2021 的双解 comment 与 Lv 2022 的 `P-R_ac` 结果需保持并列。

## Open Questions

- 同一组低自旋带在后续分析中是否仍满足 wobbling 的完整实验判据？
- mixing ratio、偏振与绝对跃迁强度对系统误差和分析假设有多敏感？
- signature-partner 或其他组态解释能否同时说明能量与电磁跃迁？
- 在统一 raw angular-distribution、polarization response、`σ/I`、`R_ac` 和误差协方差后，746/812/754 与 642/573/477 keV links 的 branch 是否仍冲突？
- 是否能获得 DB1/DB2 的 partner-resolved absolute lifetimes 与 `B(E2)/B(M1)`，以区分 chiral-partner 和其它相对 ratio 解释？
