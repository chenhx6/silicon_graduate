# 研究卡模板

这是填写指南，不是研究发现。优先填入现有 knowledge/project 或 research-note；零散低价值想法只留 tmp。
研究问题与状态沿 autonomous-research.md，不创建新自治等级。

| 字段 | 应记录的内容 |
| --- | --- |
| 稳定 ID / 问题 | 本候选想改变哪个具体判断；沿用旧 ID，不把失败重新命名成新想法 |
| 机制与前提 | 哪些结构、响应、统计或模型条件必须成立 |
| 最强替代解释 | 能产生相似结果的竞争机制或测量效应 |
| 证据与依赖 | source、原件定位、claim kind；同次实验的论文/论文集/学位论文标明共同谱系 |
| 区分性预测 | 哪个可观测量或条件变化能区分候选与替代解释 |
| 反驳条件 | 哪项观察、独立计算或必要伴随信号会降低假设可信度 |
| 最小动作 | 一项能改变判断的阅读、复算、敏感性检查或建议测量；给选择理由与成本 |
| 新颖性边界 | 最接近工作、查询/日期/范围和未查部分；没有查到先例不等于首次 |
| 空结果价值 | 缺失信号的统计/效率/gate/分辨率是否足够；空结果能排除什么 |
| 输入与验证 | 输入身份、相位/单位/几何、代码与评测版本；开发材料、确认材料及是否参与选择 |
| 失败与修正 | 此前认识、触发证据、新认识；拒绝原因、可复用约束与复活条件 |
| 下一步 / 停止 | 具体动作、所需材料与有理由停止的条件 |

先发散后评价。按需要选一种方法：前提反转、从目标展开替代路径、测量/统计效应检查、跨核素迁移边界。
实际没有独立上下文或独立复核时如实说明；审查者读取来源，模型角色不增加实验独立性。

多轮执行需要结构化检查时，字段合同和可运行示例见 knowledge/methods/evidence-driven-research-cycle.md。
