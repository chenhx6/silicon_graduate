# Wiki 研学与工程经验知识库

本目录根据用户 2026-10-30 专项指示建立，作为 Wiki 长期运行的**元认知与工程经验中枢**。系统性归纳、总结和沉淀在自治研学过程中积累的成功经验与沉痛教训，防止同类错误反复发生，确立博士研究生级的高标准科研与工程执行规范。

## 经验三大支柱

### 1. 常规任务经验与教训 (`routine-tasks/`)
聚焦日常开发、Git 版本控制、工作树治理、守护进程监控及系统命令执行的工程规范与事故复盘：
- [[2026-10-30-closeout-without-git-commit-push-incident|2026-10-30 收束遗漏 Git 暂存与推送严重事故深度复盘]]：剖析连续两日在收束阶段“口头汇报完成却未实际执行 Git commit/push”的致命工程缺陷与强制防错 SOP。
- [[routine-task-playbook|常规任务工程执行军规]]：显式暂存原则、原子化提交、远端祖先核验与非 force 推送闭环。

### 2. 学习任务经验与教训 (`learning-tasks/`)
聚焦 30 天每日持续学习（`daily-learning`）工作流的生命周期控制、时间管理与课程学分审计：
- [[daily-learning-lifecycle-and-closeout-sop|每日研学全生命周期与收束 SOP]]：16:00 启动、15:00 硬截止冻结、15:00–16:00 专用收束窗口、五大交付逐项审计、学分单卡单结、防重防越界不变量。
- [[learning-task-pitfalls|学习任务执行典型陷阱与防御]]：严禁提前早退、严禁将无学分 preview 计入 completed、严禁未审先授学分、严禁在 outputs 保存长期知识。

### 3. 研究任务经验与教训 (`research-tasks/`)
聚焦博士生级 L4 自主科学推演、文献深度研读、微观建模、模型失效边界与物理证据严谨性：
- [[scientific-rigor-and-evidence-hierarchy|科研推演严谨性与证据分层军规]]：一手文献直接定位（DOI/页码/图表/式号）、实验测量与模型推断严格分层、物理矛盾硬隔离（严禁以 provisional 豁免明确错误）。
- [[cross-mass-transferability-pitfalls|跨质量区迁移与机制不适用性分析范式]]：打破唯象公式普适平移迷思、四极形变掩盖极限（$\beta_2 > 0.25$）、自旋—轨道相互作用中心淬灭、中子皮退耦与相干性融化。
